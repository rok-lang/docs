# E0001: unexpected character in source

The source has a character that starts no token, such as a stray `#` or `$`, or a `#!` line after the first line. Remove it, or write it inside a string or comment.

```rok norun
let price = 5$;
```

```text check=checks/E0001.rok
error[E0001]: unexpected character(s) `$`
  --> main.rok:1:14
   |
 1 | let price = 5$;
   |              ^
```

Remove the stray character, or put it inside a string:

```rok
let price = 5;
println(f"${price}");
```

```output
$5
```
