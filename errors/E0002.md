# E0002: bidirectional control character in source

The source has a Unicode bidirectional control character (U+202A to U+202E, U+2066 to U+2069). These reorder how text is shown, so code can read differently from what the compiler sees. Below, the string `"abcdef"` hides one between `abc` and `def`. Write it as an escape inside a string, `"\u{202E}"`, instead.

```text check=checks/E0002.rok
error[E0002]: bidirectional control character U+202E in source; write it as an escape (`\u{202E}`) instead
  --> main.rok:1:17
```

Write the character as an escape:

```rok
let label = "abc\u{202E}def";
println(f"{label.len()}");
```

```output
9
```
