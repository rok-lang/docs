# E0003: malformed numeric literal

A number literal is not well formed: a digit outside its base (`0b2`), `_` not between two digits, an exponent without digits, a leading `0` on a decimal (`012`), a float without a leading digit (`.5`), or a suffix of the wrong kind (`1.5i32`). Write the number as the message suggests, for example `0.5`, `1_000` or `0o12`.

```rok norun
let mode = 0755;
```

```text check=checks/E0003.rok
error[E0003]: `0755`: a decimal literal can't start with `0`
  --> main.rok:1:12
   |
 1 | let mode = 0755;
   |            ^^^^
   |
   = help: write `0o755` for an octal number, or `755` for decimal
```

Write the number as the help says, here in octal:

```rok
let mode = 0o755;
println(f"{mode}");
```

```output
493
```
