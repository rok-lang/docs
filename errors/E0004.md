# E0004: literal out of range for its type

A literal does not fit its type: `300u8`, `-1` where an unsigned type is expected, or a float too large for `f32`. Use a wider type (`300u16`), a value that fits, or an `int` for a number of any size.

```rok norun
let b: u8 = 300;
```

```text check=checks/E0004.rok
error[E0004]: integer literal `300` out of range for `u8`
  --> main.rok:1:13
   |
 1 | let b: u8 = 300;
   |             ^^^
```

Use a type wide enough for the value:

```rok
let b: u16 = 300;
println(f"{b}");
```

```output
300
```
