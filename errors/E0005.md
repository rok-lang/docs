# E0005: unterminated literal or comment

A string, character, byte string, f-string, raw string or block comment starts but never ends. Add the closing quote or `*/`. A raw string closes with as many `#` as it opened with.

```rok norun
/* the greeting
println("hi");
```

```text check=checks/E0005.rok
error[E0005]: unterminated block comment
  --> main.rok:1:1
   |
 1 | /* the greeting
   | ^^^^^^^^^^^^^^^
```

Close the comment:

```rok
/* the greeting */
println("hi");
```

```output
hi
```
