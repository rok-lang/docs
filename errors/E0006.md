# E0006: invalid escape in a literal

A `\` escape in a string or character literal is not one Rok knows, or a byte string holds a character it cannot. Known escapes are `\n`, `\r`, `\t`, `\0`, `\\`, `\'`, `\"`, `\xHH` and `\u{..}`; a byte string holds ASCII only, so write other bytes as `\xHH` (at most `\xFF`).

```rok norun
println("100\% done");
```

```text check=checks/E0006.rok
error[E0006]: unknown escape sequence `\%`
  --> main.rok:1:9
   |
 1 | println("100\% done");
   |         ^^^^^^^^^^^^
```

`%` needs no escape. For a literal backslash, write `\\`.

```rok
println("100% done");
```

```output
100% done
```
