# E0007: a character literal holds one character

A `'..'` literal holds exactly one Unicode code point, and a `c'..'` literal exactly one byte. For text of any length use a string, `"ab"`; for a non-ASCII byte write `\xHH`.

```rok norun
let c = 'ab';
```

```text check=checks/E0007.rok
error[E0007]: char literal must contain exactly one code point
  --> main.rok:1:9
   |
 1 | let c = 'ab';
   |         ^^^^
```

For more than one character, use a string:

```rok
let s = "ab";
println(s);
```

```output
ab
```
