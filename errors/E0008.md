# E0008: malformed f-string

An f-string's `{..}` holes are not well formed: a `{` without its `}`, a lone `}`, an empty `{}`, a format spec with its own spec, or a hole that spans lines outside `f""".."""`. Write a literal brace as `{{` or `}}`, and put a value in every hole: `f"{x}"`.

```rok norun
let n = 3;
println(f"n = {}");
```

```text check=checks/E0008.rok
error[E0008]: empty `{}` in f-string
  --> main.rok:2:15
   |
 2 | println(f"n = {}");
   |               ^
```

Put a value in the hole:

```rok
let n = 3;
println(f"{n}");
```

```output
3
```
