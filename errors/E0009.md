# E0009: name cannot be a raw identifier

`r#name` keeps a keyword usable as a name, but a few names (`self`, `Self`, `crate`, `super`, `_`) cannot be written that way. Pick another name.

```rok norun
let r#self = 1;
```

```text check=checks/E0009.rok
error[E0009]: `r#self` is not allowed: `self` can't be a raw identifier; write `self` or pick another name
  --> main.rok:1:5
   |
 1 | let r#self = 1;
   |     ^^^^^^
```

Pick another name:

```rok
let me = 1;
println(f"{me}");
```

```output
1
```
