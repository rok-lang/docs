# E001: lexical error

The source text cannot be split into tokens: a string or comment that never ends, an escape sequence Rok does not define, a character literal with more than one code point, a numeric literal with no digits. The lexer runs before anything else, so the rest of the file is not checked until this is fixed.

```rok norun
println("100\% done");
```

```text check=checks/E001.rok
error[E001]: unknown escape sequence `\%`
  --> main.rok:1:9
   |
 1 | println("100\% done");
   |         ^^^^^^^^^^^^
```

`%` needs no escape. The escapes Rok knows are listed in [1.7.1 Escape sequences](../spec/refs-lang/001-lexical/107-string-literals.html#escape-sequences); for a literal backslash, write `\\`.

```rok
println("100% done");
```

```output
100% done
```

Other messages with this code: `unterminated string literal`, `unterminated block comment`, `char literal must contain exactly one code point`, `missing digits in numeric literal`. See [1. Lexical structure](../spec/refs-lang/001-lexical/index.html).
