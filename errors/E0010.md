# E0010: unexpected token

The parser expected one thing and found another: a missing `;`, `,`, `)` or `}`, a keyword where a name goes, or an expression where an item goes. The message says what was expected; write that, or check the line before for something left open.

```rok norun
let x = (1 + 2;
println(f"{x}");
```

```text check=checks/E0010.rok
error[E0010]: expected `)`, found `;`
  --> main.rok:1:15
   |
 1 | let x = (1 + 2;
   |         - unclosed delimiter
   |               ^ expected `)`
```

Close the parenthesis:

```rok
let x = (1 + 2);
println(f"{x}");
```

```output
3
```

A missing `;` reports ``expected `;` `` with ``help: add `;` at the end of the statement``. When a delimiter is left open, a second mark points at it.
