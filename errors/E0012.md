# E0012: syntax from another language

The code uses a form Rok does not have: the `c ? a : b` operator, `++` / `--`, or `let mut`. The message gives the Rok form: `if c { a } else { b }`, `x += 1`, or a plain `let` (variables are mutable).

```rok norun
let mut n = 0;
```

```text check=checks/E0012.rok
error[E0012]: rok has no `let mut`: variables are mutable by default
  --> main.rok:1:5
   |
 1 | let mut n = 0;
   |     ^^^
   |
   = help: drop `mut`: `let n = ..;`
```

Drop `mut`; every variable can be assigned:

```rok
let n = 0;
n += 1;
println(f"{n}");
```

```output
1
```
