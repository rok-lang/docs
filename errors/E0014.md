# E0014: modifiers out of order

Function modifiers go in one order, `unsafe async yield fn`, each at most once, and `throws` goes before the return type: `fn f() throws -> T`. Reorder them as the help shows.

```rok norun
fn parse(s: str) -> i32 throws {
    0
}
```

```text check=checks/E0014.rok
error[E0014]: `throws` goes before the return type
  --> main.rok:1:25
   |
 1 | fn parse(s: str) -> i32 throws {
   |                         ^^^^^^
   |
   = help: write `fn parse(s: str) throws -> i32`
```

Put `throws` before the return type:

```rok
fn parse(s: str) throws -> i32 {
    try s.parse::<i32>()
}
println(f"{try! parse("7")}");
```

```output
7
```
