# E0015: doc comment documents nothing

A doc comment (`///` or `/** */`) goes right before the item it documents. Move it there, or make it a plain comment (`//`).

```rok norun
fn f() {}
/// The answer.
```

```text check=checks/E0015.rok
error[E0015]: doc comment documents nothing: it must come before an item; use `//` for a plain comment
  --> main.rok:2:1
   |
 2 | /// The answer.
   | ^^^^^^^^^^^^^^^
```

Move the doc comment onto the item it describes:

```rok
/// The answer.
fn answer() -> i32 { 42 }
println(f"{answer()}");
```

```output
42
```
