# E0016: visibility where it has no meaning

`pub` was written where it changes nothing: on a function or item inside a block (it is visible only in that block) or on an enum variant (variants take the enum's visibility). Remove it.

```rok norun
enum Color { pub Red, Blue }
```

```text check=checks/E0016.rok
error[E0016]: enum variants take the enum's visibility; remove the visibility keyword
  --> main.rok:1:14
   |
 1 | enum Color { pub Red, Blue }
   |              ^^^
```

Remove `pub` from the variant; to make the variants visible, mark the enum `pub`.

```rok
#[derive(Debug)]
pub enum Color { Red, Blue }
println(f"{Color::Red:?}");
```

```output
Red
```
