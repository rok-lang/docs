# E0017: item in the wrong place

An item or statement appears where it is not allowed: a `static` in an `impl`, a `static mut` outside an `extern` block, a statement in a module body, or a macro import inside a function. Move it where the message says, usually to module level.

```rok norun
mod inner {
    println("hi");
}
```

```text check=checks/E0017.rok
error[E0017]: expected an item in `mod inner`: module bodies are definitions-only; statements belong in `main.rok`
  --> main.rok:2:5
   |
 2 |     println("hi");
   |     ^^^^^^^
```

Module bodies hold definitions; put the statement in a function:

```rok
mod inner {
    pub fn hi() { println("hi"); }
}
inner::hi();
```

```output
hi
```
