# E0018: `return` in top-level statements

A program's top-level statements are not a function, so `return` has nothing to return from. End the program with `process::exit(code)`, or write `fn main() -> i32` and return from it.

```rok norun
let args = 1;
if args > 0 { return; }
```

```text check=checks/E0018.rok
error[E0018]: `return` is not allowed in top-level statements; use `process::exit(code)` or an explicit `fn main() -> i32`
  --> main.rok:2:15
   |
 2 | if args > 0 { return; }
   |               ^^^^^^
```

End the program with `process::exit`:

```rok
use rok::std::process;

let args = 1;
if args > 0 { process::exit(0); }
println("unreached");
```
