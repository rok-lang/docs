# E0019: operators that need parentheses

A chain of comparisons takes its operators from one group: `<` and `<=` (`0 <= i < n`), `>` and `>=` (`a > b >= c`), or `==` (`a == b == c`); each pair is joined with `&&`. Other chains are an error: mixed groups (`a < b > c`, `a < b == c`), `a != b != c`, `x ∈ s == y` and `a..b..c`. Join the parts with `&&` (`a < b && b > c`), or add parentheses to say which you mean. (An index with several parts on a one-axis type, `xs[1:, 0]`, is [E0144](E0144.html).)

```rok norun
let a = 1;
let b = 2;
println(f"{a < b > 0}");
```

```text check=checks/E0019.rok
error[E0019]: `<` and `>` cannot be chained
  --> main.rok:3:18
   |
 3 | println(f"{a < b > 0}");
   |                  ^
   |
   = help: a chain compares in one direction (`a < b <= c`, `a > b >= c`, `a == b == c`); write `a < b && b > c`
```

Join the two comparisons with `&&`; a chain in one direction is fine:

```rok
let a = 1;
let b = 2;
println(f"{a < b && b > 0} {0 <= a < b}");
```

```output
true true
```
