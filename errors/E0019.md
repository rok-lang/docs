# E0019: operators that need parentheses

Some operators do not chain: comparisons in two directions (`a < b > c`), `a != b != c`, `x ∈ s == y`, `a..b..c`, and one `[..]` that both indexes with `,` and slices with `:`. Comparisons in one direction do chain (`0 <= i < n`). Join the parts with `&&`, or add parentheses or separate brackets to say which you mean.

```rok norun
let a = 1;
let b = 2;
println(f"{a < b > 0}");
```

```text check=checks/E0019.rok
error[E0019]: `<` and `>` cannot be chained
  --> main.rok:3:18
   |
 3 | println(f"{a < b > 0}");
   |                  ^
   |
   = help: a chain compares in one direction (`a < b <= c`, `a > b >= c`, `a == b == c`); write `a < b && b > c`
```

Join the two comparisons with `&&`; a chain in one direction is fine:

```rok
let a = 1;
let b = 2;
println(f"{a < b && b > 0} {0 <= a < b}");
```

```output
true true
```
