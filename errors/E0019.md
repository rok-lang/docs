# E0019: operators that need parentheses

Some operators do not chain: `a == b == c`, `a..b..c`, `try? x ?? y`, and one `[..]` that both indexes with `,` and slices with `:`. Add parentheses or separate brackets to say which you mean.

```rok norun
let a = 1;
let b = 2;
println(f"{a < b < 3}");
```

```text check=checks/E0019.rok
error[E0019]: non-associative operator `<` cannot be chained (parenthesise to disambiguate)
  --> main.rok:3:18
   |
 3 | println(f"{a < b < 3}");
   |                  ^
```

Write the comparison as two:

```rok
let a = 1;
let b = 2;
println(f"{a < b && b < 3}");
```

```output
true
```
