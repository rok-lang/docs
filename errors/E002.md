# E002: syntax error

The tokens do not form valid Rok syntax. The message says what the parser expected and what it found instead; a secondary mark points at an unclosed delimiter when there is one.

```rok norun
let x = (1 + 2;
println(f"{x}");
```

```text check=checks/E002.rok
error[E002]: expected `)`, found `;`
  --> main.rok:1:15
   |
 1 | let x = (1 + 2;
   |         - unclosed delimiter
   |               ^ expected `)`
```

Close the parenthesis:

```rok
let x = (1 + 2);
println(f"{x}");
```

```output
3
```

A missing `;` reports ``expected `;` `` with `help: add `;` at the end of the statement`. Defining a name twice in one block (`` `x` is defined twice in this block ``) and using a keyword registered with `#[keyword]` as a name are also E002.
