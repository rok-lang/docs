# E0021: reserved word used as a name

A keyword or a reserved name (a path root such as `rok`, or a keyword registered with `#[keyword]`) is used as a name. Pick another name, or write `r#name` to keep a keyword as a name.

```rok norun
let gen = 1;
```

```text check=checks/E0021.rok
error[E0021]: `gen` is a reserved keyword, not a name
  --> main.rok:1:5
   |
 1 | let gen = 1;
   |     ^^^
   |
   = help: write `r#gen` to keep this name, or rename it
```

Write `r#gen` to keep the name, or pick another:

```rok
let r#gen = 1;
println(f"{r#gen}");
```

```output
1
```

Related: [E0009](E0009.html) name cannot be a raw identifier
