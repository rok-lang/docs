# E0022: `let` without a value

Every `let` gives its variable a value. Write one, `let n: i32 = 0;`, or start it empty with an optional type: `let n: i32 | none = none;`.

```rok norun
let n: i32;
```

```text check=checks/E0022.rok
error[E0022]: `let n` needs a value
  --> main.rok:1:11
   |
 1 | let n: i32;
   |           ^
   |
   = help: give it one, `let n: i32 = ..;`, or start it empty: `let n: i32 | none = none;`
```

Start it with a value, or with `none` and an optional type:

```rok
let n: i32 | none = none;
println(f"{n ?? 0}");
```

```output
0
```
