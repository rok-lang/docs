# E0023: invalid function signature

The function's parameters or return type break a rule: a variadic `...` that is not last, a `ref` parameter on a coroutine or a `fn` value, a `rethrows` without a throwing parameter, or a signature `main` or a test attribute does not allow. The message names the rule; change the signature to fit it.

```rok norun
fn f(a: i32, ...) -> i32 { a }
```

```text check=checks/E0023.rok
error[E0023]: `f`: a C variadic `...` parameter is only allowed on a declaration in an `extern "C" { .. }` block
  --> main.rok:1:1
   |
 1 | fn f(a: i32, ...) -> i32 { a }
   | ^^
```

A C variadic belongs to `extern` declarations. A Rok function takes any number of arguments with `...T`:

```rok
fn sum(xs: ...i32) -> i32 {
    let t = 0;
    for x in xs { t += x; }
    t
}
println(f"{sum(1, 2, 3)}");
```

```output
6
```
