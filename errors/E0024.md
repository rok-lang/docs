# E0024: invalid generic parameters

The generic parameter list breaks a rule: a parameter without a default after one with a default, a const parameter of a type that cannot be a constant, or a `where` clause that bounds something it cannot. Reorder or change the parameters as the message says.

```rok norun
struct Pair<T = i32, U> { a: T; b: U; }
```

```text check=checks/E0024.rok
error[E0024]: generic parameter `U` has no default but follows one that does; defaults must be trailing
  --> main.rok:1:22
   |
 1 | struct Pair<T = i32, U> { a: T; b: U; }
   |                      ^
```

Put the parameters with defaults last:

```rok
struct Pair<U, T = i32> { a: T; b: U; }
let p: Pair<str> = Pair { a: 1, b: "x" };
println(f"{p.a} {p.b}");
```

```output
1 x
```
