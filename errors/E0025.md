# E0025: unsupported ABI

An `extern` names an ABI Rok does not support, or leaves it out. Write `extern "C"` (or `"system"` for the platform's system calls).

```rok norun
extern "fastcall" {
    fn abs(x: i32) -> i32;
}
```

```text check=checks/E0025.rok
error[E0025]: unsupported ABI `"fastcall"` (`"C"`, `"system"`, or `"rok"` for the runtime)
  --> main.rok:1:1
   |
 1 | extern "fastcall" {
   | ^^^^^^
```

Write `"C"`:

```rok
extern "C" {
    fn abs(x: i32) -> i32;
}
println(f"{unsafe { abs(-3) }}");
```

```output
3
```
