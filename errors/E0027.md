# E0027: cannot find value or function

No value or function of this name is in scope. Check the spelling, bring it in with `use` (the help lists the items of that name), or declare it with `let` first.

```rok norun
let count = 1;
println(f"{coun}");
```

```text check=checks/E0027.rok
error[E0027]: cannot find value `coun` in this scope
  --> main.rok:2:12
   |
 2 | println(f"{coun}");
   |            ^^^^
   |
   = help: did you mean `count`?
```

Fix the spelling, or import the item:

```rok
let count = 1;
println(f"{count}");
```

```output
1
```

When an item of that name exists in another module, the help gives the `use` line that brings it in. Assigning to a name that was never declared with `let` is [E0057](E0057.html).
