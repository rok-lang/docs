# E0028: cannot find type or trait

No type or trait of this name is in scope. Check the spelling, or bring it in with `use`; the help lists the items of that name.

```rok norun
let xs: Lst<i32> = [1];
```

```text check=checks/E0028.rok
error[E0028]: cannot find type `Lst` in this scope
  --> main.rok:1:9
   |
 1 | let xs: Lst<i32> = [1];
   |         ^^^
   |
   = help: did you mean `List`?
```

Fix the spelling:

```rok
let xs: List<i32> = [1];
println(f"{xs.len()}");
```

```output
1
```
