# E0029: cannot find enum variant

The enum has no variant of this name. Check the spelling against the enum's definition.

```rok norun
enum Light { Red, Green }

let l = Light::Yellow;
```

```text check=checks/E0029.rok
error[E0029]: enum `Light` has no variant `Yellow`
  --> main.rok:3:9
   |
 3 | let l = Light::Yellow;
   |         ^^^^^^^^^^^^^
```

Use a variant the enum has, or add it to the enum:

```rok
#[derive(PartialEq)]
enum Light { Red, Green, Yellow }

let l = Light::Yellow;
println(f"{l == Light::Yellow}");
```

```output
true
```
