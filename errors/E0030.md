# E0030: unresolved import

A `use` names something that does not exist. Check the path: it starts at the package (`crate::`), a dependency, or `rok::`.

```rok norun
use rok::std::fss;
```

```text check=checks/E0030.rok
error[E0030]: unresolved import: `rok::std::fss` does not exist
  --> main.rok:1:5
   |
 1 | use rok::std::fss;
   |     ^^^
```

Fix the path:

```rok
use rok::std::fs;

println(f"{fs::exists("no-such-file")}");
```

```output
false
```
