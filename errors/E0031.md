# E0031: ambiguous name

Several glob imports (`use a::*;`) or packages provide this name, so it is unclear which one is meant. Import the one you want by name, or write its path.

```rok norun
mod a { pub fn item() -> i32 { 1 } }
mod b { pub fn item() -> i32 { 2 } }
use a::*;
use b::*;
println(f"{item()}");
```

```text check=checks/E0031.rok
error[E0031]: name `item` is ambiguous in module `<root>` - multiple glob imports resolve it: a::item, b::item
  --> main.rok:5:12
   |
 5 | println(f"{item()}");
   |            ^^^^^^
```

Import the one you mean by name:

```rok
mod a { pub fn item() -> i32 { 1 } }
mod b { pub fn item() -> i32 { 2 } }
use a::item;
println(f"{item()}");
```

```output
1
```
