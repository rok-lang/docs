# E0032: conflicting imports

A name is imported twice with different targets, or is both imported and defined in the module. Rename one with `use .. as other;`, or drop one of them.

```rok norun
use shapes::square;
fn square(x: f64) -> f64 { x * x }
mod shapes {
    pub fn square(x: f64) -> f64 { x * x }
}
```

```text check=checks/E0032.rok
error[E0032]: `square` is both imported from `shapes::square` and defined in this module
  --> main.rok:1:5
   |
 1 | use shapes::square;
   |     ^^^^^^ imported here
 2 | fn square(x: f64) -> f64 { x * x }
   | -- defined here, which would hide the import
   |
   = help: import it under another name, `use shapes::square as shapes_square;`, or remove this `use` if the module does not need it
```

Import it under another name:

```rok
use shapes::square as shape_square;
fn square(x: f64) -> f64 { x * x }
mod shapes {
    pub fn square(x: f64) -> f64 { x * x }
}
println(f"{square(2.0)} {shape_square(3.0)}");
```

```output
4 9
```
