# E0033: invalid re-export

A `pub use` breaks a rule: it is wider than the item it re-exports, it re-exports a macro, or re-exports form a cycle. Make the item as visible as the re-export, or change the re-export.

```rok norun
mod inner {
    fn helper() -> i32 { 1 }
}
pub use inner::helper;
```

```text check=checks/E0033.rok
error[E0033]: `inner::helper` is private but re-exported as `pub` - a re-export can't be wider than its item
  --> main.rok:4:9
   |
 4 | pub use inner::helper;
   |         ^^^^^
```

Make the item as visible as the re-export:

```rok
mod inner {
    pub fn helper() -> i32 { 1 }
}
pub use inner::helper;
println(f"{helper()}");
```

```output
1
```
