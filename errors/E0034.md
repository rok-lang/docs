# E0034: item is private

The item, field or method is private to another module (or `pub(pkg)` in another package), so it cannot be used here. Mark it `pub` where it is defined, or use a public item instead.

```rok norun
mod geo {
    fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```text check=checks/E0034.rok
error[E0034]: function `geo::area` is private to module `geo` and cannot be used from `<root>` (add `pub` to expose it)
  --> main.rok:4:12
   |
 4 | println(f"{geo::area(2, 3)}");
   |            ^^^^^^^^^^^^^^^
```

Add `pub`:

```rok
mod geo {
    pub fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```output
6
```

Items are private to their module unless marked `pub` ([5.6 Visibility](../spec/refs-lang/005-modules/506-visibility.html)).
