# E0035: module file problem

A `mod name;` cannot be loaded: its file `name.rok` is missing or unreadable, the module is declared twice, or it is both inline and a file. A module's file is named after the module (Rok has no `mod.rok`), beside the file that declares it.

```rok norun
mod geo;
```

```text check=checks/E0035.rok
error[E0035]: module `geo` body not found at `geo.rok`
   = help: create `geo.rok`, or write `mod geo { .. }` in place of `mod geo;`
```

Create `geo.rok` next to `main.rok`, or write the module inline: `mod geo { .. }` ([5.4 Modules](../spec/refs-lang/005-modules/504-modules.html)).

Related: [E0030](E0030.html) unresolved import, [E0036](E0036.html) invalid program entry point
