# E0036: invalid program entry point

A program starts either at the top-level statements of `main.rok` or at `fn main`, not both; other files hold definitions only. `fn main` takes no parameters and returns `()` or an integer.

```rok norun
fn main(args: List<str>) {}
```

```text check=checks/E0036.rok
error[E0036]: `fn main`: takes no parameters; read arguments through `rok::std::env`
  --> main.rok:1:1
   |
 1 | fn main(args: List<str>) {}
   | ^^
```

Read the arguments through `rok::std::env`:

```rok
use rok::std::env;

fn main() {
    println(f"{env::args().len() > 0}");
}
```

```output
true
```

A `fn main` that returns another type, such as `` `fn main`: must return `()` or `i32` ``, is also E0036 ([4.16](../spec/refs-lang/004-functions/416-entry-point.html)).

Related: [E0018](E0018.html) `return` in top-level statements, [E0023](E0023.html) invalid function signature
