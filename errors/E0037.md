# E0037: invalid dependency

A dependency given to the compiler (`--extern`, or a standard library tier) does not fit this build: it was built under another name or for another toolchain, or it may not be used from here. Rebuild it, or fix the dependency list.

`rok` builds dependencies with the same toolchain and passes them for you, so this comes up when calling `rokc` directly, or after switching toolchains with stale build output. Run `rok clean` and build again, or rebuild the dependency with the current `rokc`.
