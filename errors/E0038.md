# E0038: local declared twice

A `let` declares a name that is already declared in the same scope, or a variable and a nested function share a name. Rok does not let a second `let` hide the first: assign to it (`x = ..`) or pick a new name.

```rok norun
let x = 1;
let x = 2;
```

```text check=checks/E0038.rok
error[E0038]: `x` is already declared in this scope, and rok does not let a second `let` hide it
  --> main.rok:2:1
   |
 2 | let x = 2;
   | ^^^
   |
   = help: to change its value write `x = 2;`, or give the new value its own name: `let x2 = 2;`
```

Assign the new value, or give it a new name:

```rok
let x = 1;
x = 2;
println(f"{x}");
```

```output
2
```
