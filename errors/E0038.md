# E0038: variable named like a nested function

A variable and a nested function in the same block share a name. A nested function is visible in the whole block, so the name would mean both: rename one of them.

```rok norun
fn main() {
    fn step(x: i32) -> i32 { x + 1 }
    let step = 2;
    println(f"{step}");
}
```

```text check=checks/E0038.rok
error[E0038]: `step` names both a variable and a nested function in this block
  --> main.rok:3:5
   |
 3 |     let step = 2;
   |     ^^^
   |
   = help: a nested function is seen in its whole block, so rename one of them: `let step2 = ..` or `fn step2(..)`
```

Give the variable or the function its own name:

```rok
fn main() {
    fn step(x: i32) -> i32 { x + 1 }
    let steps = 2;
    println(f"{step(steps)}");
}
```

```output
3
```

A second `let` of a variable's name is fine: it makes a new variable ([5.1.4](../spec/refs-lang/005-modules/501-variable-declaration.html#514-redeclaration-in-the-same-scope)).
