# E0039: nested item uses an outer local

A nested `fn`, `struct` or `impl` cannot use the locals or generic parameters of the function around it. Pass the value as a parameter, or use a closure, which can capture it.

```rok norun
fn wrap<T>(t: T) -> i32 {
    struct Holder { v: T; }
    0
}
```

```text check=checks/E0039.rok
error[E0039]: `Holder` is declared inside `wrap` and can't use `T`, a generic parameter of `wrap`; declare its own instead: `struct Holder<T>`
  --> main.rok:2:24
   |
 2 |     struct Holder { v: T; }
   |                        ^
```

Give the nested item its own parameter, or declare it outside the function:

```rok
struct Holder<T> { v: T; }

fn wrap<T>(t: T) -> Holder<T> {
    Holder { v: t }
}
println(f"{wrap(5).v}");
```

```output
5
```

A nested `fn` that uses a local of the function around it gets the same code; a closure (`let add = |x: i32| x + base;`) can capture the local.
