# E0041: branches of different types

The branches of an `if` or `match`, the `break`s of a loop, or the return paths of a function without a written return type give values of different types. Rok does not invent a sum type for them: annotate the slot with the sum, `let v: i64 | str = if c { 1 } else { "a" };`, write the return type (`-> i64 | str`), or make the branches agree. An unsuffixed literal takes the other branches' type (`if c { 1 } else { 2u8 }` is `u8`), but an integer literal is never a float: write `1.0`.

```rok norun
let c = true;
let v = if c { 1 } else { "one" };
```

```text check=checks/E0041.rok
error[E0041]: `if` branches have different types `i64` and `str` - rok does not infer a sum type; annotate the slot (`let v: i64 | str = if ...`)
  --> main.rok:2:9
   |
 2 | let v = if c { 1 } else { "one" };
   |         ^^^^^^^^^^^^^^^^^^^^^^^^^
```

Annotate the variable with the sum type:

```rok
let c = true;
let v: i64 | str = if c { 1 } else { "one" };
println(f"{v is i64}");
```

```output
true
```
