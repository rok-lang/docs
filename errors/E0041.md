# E0041: branches of different types

The branches of an `if`, `match` or the `break`s of a loop give values of different types. Rok does not invent a sum type for them: annotate the slot with the sum, `let v: i64 | str = if c { 1 } else { "a" };`, or make the branches agree.

```rok norun
let c = true;
let v = if c { 1 } else { "one" };
```

```text check=checks/E0041.rok
error[E0041]: `if` branches have different types `i64` and `str` - rok does not infer a sum type; annotate the slot (`let v: i64 | str = if ...`)
  --> main.rok:2:9
   |
 2 | let v = if c { 1 } else { "one" };
   |         ^^^^^^^^^^^^^^^^^^^^^^^^^
```

Annotate the variable with the sum type:

```rok
let c = true;
let v: i64 | str = if c { 1 } else { "one" };
println(f"{v is i64}");
```

```output
true
```
