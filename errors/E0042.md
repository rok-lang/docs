# E0042: type annotations needed

The compiler cannot work out a type from the code: an empty literal, a closure parameter nothing constrains, or a generic call whose type arguments nothing fixes. Write the type: `let v: List<i32> = [];`, `|x: i32| ..`, or `f::<i32>(..)`.

```rok norun
let xs = [];
```

```text check=checks/E0042.rok
error[E0042]: type annotations needed: cannot infer the type of `xs` (`List<_>`) from its initializer or later uses - add an annotation (`let xs: T = ..`)
  --> main.rok:1:1
   |
 1 | let xs = [];
   | ^^^
```

Write the type:

```rok
let xs: List<i32> = [];
println(f"{xs.len()}");
```

```output
0
```
