# E0043: no such field

The type has no field of this name (or a tuple has no element at this index). Check the spelling against the type's definition.

```rok norun
struct P { x: i32; y: i32; }

let p = P { x: 1, y: 2 };
println(f"{p.z}");
```

```text check=checks/E0043.rok
error[E0043]: struct `P` has no field `z`
  --> main.rok:4:12
   |
 4 | println(f"{p.z}");
   |            ^^^
   |
   = help: available fields: `x`, `y`
```

Use a field the type has; the help lists them:

```rok
struct P { x: i32; y: i32; }

let p = P { x: 1, y: 2 };
println(f"{p.y}");
```

```output
2
```
