# E0044: missing field in a literal

A struct or variant literal leaves out a field that has no default. Give every field a value, or declare a default in the struct (`n: i32 = 0`).

```rok norun
struct P { x: i32; y: i32; }

let p = P { x: 1 };
```

```text check=checks/E0044.rok
error[E0044]: struct `P` is missing field `y` and no default is declared
  --> main.rok:3:9
   |
 3 | let p = P { x: 1 };
   |         ^^^^^^^^^^
```

Give the field a value, or declare a default in the struct:

```rok
struct P { x: i32; y: i32 = 0; }

let p = P { x: 1 };
println(f"{p.y}");
```

```output
0
```
