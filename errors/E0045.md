# E0045: field given more than once

A struct literal names the same field twice. Remove one.

```rok norun
struct P { x: i32 }

let p = P { x: 1, x: 2 };
```

```text check=checks/E0045.rok
error[E0045]: field `x` specified more than once in `P` literal
  --> main.rok:3:9
   |
 3 | let p = P { x: 1, x: 2 };
   |         ^^^^^^^^^^^^^^^^
```

Give the field once:

```rok
struct P { x: i32 }

let p = P { x: 2 };
println(f"{p.x}");
```

```output
2
```
