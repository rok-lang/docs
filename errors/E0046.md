# E0046: no such method or associated item

The type has no method, associated function or associated constant of this name, or none that applies to these types. Check the spelling, the `use` of the trait that provides it, and its bounds.

```rok norun
let s = "rok";
println(s.size());
```

```text check=checks/E0046.rok
error[E0046]: no method `size` found for type `str`
  --> main.rok:2:9
   |
 2 | println(s.size());
   |         ^^^^^^^^
   |
   = help: did you mean `len`?
```

Use the method the help suggests:

```rok
let s = "rok";
println(f"{s.len()}");
```

```output
3
```

A method that exists only on another platform is also E0046, with a note that says where it exists ([chapter 17](../learn/17-conditional-compilation.html)). A method of a trait that is not imported is [E0136](E0136.html).
