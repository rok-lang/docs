# E0047: item used in the wrong form

An item is used in a form it does not have: an associated function called as a method (`v.new()` for `T::new()`), a method named without a call, a tuple struct built with `{..}` or a named one with `(..)`, or a type used as a value. Write the form the message gives.

```rok norun
struct P { a: i32; }
impl P { fn get(self) -> i32 { self.a } }

let p = P { a: 3 };
let f = p.get;
```

```text check=checks/E0047.rok
error[E0047]: `p.get` names a method without calling it; `.method` is not a function value
  --> main.rok:5:9
   |
 5 | let f = p.get;
   |         ^^^^^
   |
   = help: call it (`p.get(..)`), wrap it in a closure (`|..| p.get(..)`), or use the method path `P::get`
```

Call the method, or wrap the call in a closure:

```rok
struct P { a: i32; }
impl P { fn get(self) -> i32 { self.a } }

let p = P { a: 3 };
let f = || p.get();
println(f"{f()}");
```

```output
3
```
