# E0048: wrong number of arguments

A call passes more or fewer arguments than the function takes, or leaves out one without a default. Pass every parameter once; parameters with defaults may be left out.

```rok norun
fn add(a: i32, b: i32) -> i32 { a + b }
println(f"{add(1)}");
```

```text check=checks/E0048.rok
error[E0048]: missing argument `b` in call to `add`
  --> main.rok:2:12
   |
 2 | println(f"{add(1)}");
   |            ^^^^^^
   |
   = help: it is declared `add(a: i32, b: i32)`; pass `b` too
```

Pass every parameter, or give the last one a default:

```rok
fn add(a: i32, b: i32 = 0) -> i32 { a + b }
println(f"{add(1)} {add(1, 2)}");
```

```output
1 3
```
