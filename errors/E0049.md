# E0049: invalid named argument

A named argument (`f(x: 1)`) names no parameter of the function, or gives one parameter twice. Use the parameter names of the function's definition, each once.

```rok norun
fn area(w: i32, h: i32 = 1) -> i32 { w * h }
println(f"{area(w: 2, height: 3)}");
```

```text check=checks/E0049.rok
error[E0049]: `area` has no parameter named `height`
  --> main.rok:2:12
   |
 2 | println(f"{area(w: 2, height: 3)}");
   |            ^^^^^^^^^^^^^^^^^^^^^
```

Use the parameter names of the definition:

```rok
fn area(w: i32, h: i32 = 1) -> i32 { w * h }
println(f"{area(w: 2, h: 3)}");
```

```output
6
```
