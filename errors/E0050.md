# E0050: `ref` parameter and argument mismatch

A `ref` parameter takes an argument written `ref x`, which names a variable or a field of one; a plain parameter takes a plain argument. The same variable cannot go to two `ref` parameters of one call. Write `ref` exactly where the parameter has it.

```rok norun
fn inc(ref n: i32) { n += 1; }

let c = 0;
inc(c);
```

```text check=checks/E0050.rok
error[E0050]: parameter `n` of `inc` is `ref` - pass `ref c` at the call site
  --> main.rok:4:1
   |
 4 | inc(c);
   | ^^^^^^
```

Write `ref` at the call too:

```rok
fn inc(ref n: i32) { n += 1; }

let c = 0;
inc(ref c);
println(f"{c}");
```

```output
1
```
