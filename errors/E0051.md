# E0051: invalid spread argument

`f(..x)` spreads a tuple, `List`, `Slice`, array or `Dict<str, V>` into the arguments, and needs a callee known at compile time. Spread one of those, or pass the arguments one by one.

```rok norun
fn sum(xs: ...i32) -> i32 { 0 }

let n = 3;
println(f"{sum(..n)}");
```

```text check=checks/E0051.rok
error[E0051]: spread into a variadic `...T` needs a tuple, a `List`, a `Slice` or an array, found `i32`
  --> main.rok:4:12
   |
 4 | println(f"{sum(..n)}");
   |            ^^^^^^^^
```

Spread a collection:

```rok
fn sum(xs: ...i32) -> i32 {
    let t = 0;
    for x in xs { t += x; }
    t
}

let ns = [1, 2, 3];
println(f"{sum(..ns)}");
```

```output
6
```
