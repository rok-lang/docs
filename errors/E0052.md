# E0052: value is not callable

Only functions, closures and `fn` values can be called. Check that the name refers to a function, not a value of the same name.

```rok norun
let total = 3;
println(f"{total(1)}");
```

```text check=checks/E0052.rok
error[E0052]: a value of type `i32` is not callable
  --> main.rok:2:12
   |
 2 | println(f"{total(1)}");
   |            ^^^^^^^^
```

Call a function or closure:

```rok
let total = |x: i32| x + 3;
println(f"{total(1)}");
```

```output
4
```
