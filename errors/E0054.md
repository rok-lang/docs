# E0054: operator cannot be applied

An operator is used on types that do not support it. For your own types, implement the operator's trait (`impl Add for Point`); for a type parameter, add that trait as a bound.

```rok norun
let a: i32 = 1;
let b: i64 = 2;
println(f"{a + b}");
```

```text check=checks/E0054.rok
error[E0054]: operator `+` cannot be applied to `i32` and `i64`
  --> main.rok:3:12
   |
 3 | println(f"{a + b}");
   |            ^^^^^
   |
   = help: rok never converts numbers implicitly; convert one side: `(a as i64) + b`
```

Convert one side; Rok never converts numbers on its own:

```rok
let a: i32 = 1;
let b: i64 = 2;
println(f"{a as i64 + b}");
```

```output
3
```

On a type parameter the message says which bound is missing: ``operator `+` on `T` needs a `Add` bound on `T` `` ([chapter 7](../learn/07-generics.html)).

Related: [E0040](E0040.html) mismatched types, [E0069](E0069.html) trait bound not satisfied
