# E0055: literal fits several types

An unsuffixed literal could be any of several types the call or operator accepts, so its type is unclear. When one of them is `i64`, the default, the literal takes it; otherwise add a suffix (`1i32`) or an `as`.

```rok norun
struct X { v: i64; }
impl From<i32> for X { fn from(x: i32) -> X { X { v: x as i64 } } }
impl From<u8> for X { fn from(x: u8) -> X { X { v: x as i64 } } }

let x = X::from(5);
```

```text check=checks/E0055.rok
error[E0055]: `X::from`: the literal fits several `From` impls of `X` (`i32`, `u8`); add a suffix or `as`
  --> main.rok:5:9
   |
 5 | let x = X::from(5);
   |         ^^^^^^^^^^
```

Add a suffix:

```rok
struct X { v: i64; }
impl From<i32> for X { fn from(x: i32) -> X { X { v: x as i64 } } }
impl From<u8> for X { fn from(x: u8) -> X { X { v: x as i64 } } }

let x = X::from(5i32);
println(f"{x.v}");
```

```output
5
```
