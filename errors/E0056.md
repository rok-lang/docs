# E0056: invalid indexing

The value cannot be indexed, or the index is not an integer. Index arrays, lists and slices with integers, and types that implement `Index` with their key.

```rok norun
let total = 120;
println(f"{total[0]}");
```

```text check=checks/E0056.rok
error[E0056]: cannot index into a value of type `i64`
  --> main.rok:2:12
   |
 2 | println(f"{total[0]}");
   |            ^^^^^^^^
```

Index a collection:

```rok
let totals = [120, 80];
println(f"{totals[0]}");
```

```output
120
```
