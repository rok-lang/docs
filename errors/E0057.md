# E0057: invalid assignment

The left side of `=` cannot be assigned: a const, a static, a variable not declared with `let`, a value captured by a closure without `[ref name]`, or an expression that is not a place. Assign to a `let` variable, a field of one, or an element of one.

```rok norun
let count = 0;
coutn = count + 1;
```

```text check=checks/E0057.rok
error[E0057]: `coutn` is not declared; a variable is created only by `let`
  --> main.rok:2:1
   |
 2 | coutn = count + 1;
   | ^^^^^
   |
   = help: did you mean `count`? To declare a new variable, write `let coutn = count + 1;`
```

Assign to the variable you declared, or declare a new one with `let`:

```rok
let count = 0;
count = count + 1;
println(f"{count}");
```

```output
1
```

Rok has no declaration by assignment: a variable is created only by `let` ([5.1](../spec/refs-lang/005-modules/501-variable-declaration.html)).
