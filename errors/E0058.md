# E0058: invalid closure capture

A closure's capture list (`[ref x]`) names something it cannot capture: no variable of that name, or a `ref` capture in a closure that may run on another thread. Capture a `let` variable or parameter, and share across threads through a `Mutex` or an atomic.

```rok norun
let total = 0;
let add = [ref totl] |x: i32| { total += x; };
```

```text check=checks/E0058.rok
error[E0058]: `[ref totl]` names no variable in scope
  --> main.rok:2:11
   |
 2 | let add = [ref totl] |x: i32| { total += x; };
   |           ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
```

Capture the variable by its name:

```rok
let total = 0;
let add = [ref total] |x: i32| { total += x; };
add(2);
println(f"{total}");
```

```output
2
```
