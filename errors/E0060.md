# E0060: `let .. else` that does not diverge

The `else` block of `let .. else` runs when the pattern does not match, so it must leave the scope: end it with `return`, `break`, `continue` or `throw`.

```rok norun
fn first(xs: List<i32>) -> i32 {
    let n = xs.first() else {
        println("empty");
    };
    n
}
```

```text check=checks/E0060.rok
error[E0060]: the `else` block of `let ... else` must diverge (end in `return`, `break`, `continue` or `throw`)
  --> main.rok:2:13
   |
 2 |     let n = xs.first() else {
   |             ^^^^^^^^^^
```

Leave the function in the `else` block:

```rok
fn first(xs: List<i32>) -> i32 {
    let n = xs.first() else {
        return 0;
    };
    n
}
println(f"{first([])} {first([4])}");
```

```output
0 4
```
