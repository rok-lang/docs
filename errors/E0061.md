# E0061: operation needs `unsafe`

The operation can break memory safety: calling an `unsafe` or `extern` function, reading a union field, or indexing a `GcBuf` without a check. Wrap it in `unsafe { .. }`, inside an `unsafe fn` if it is a building block.

```rok norun
unsafe fn danger() -> i32 { 1 }
println(f"{danger()}");
```

```text check=checks/E0061.rok
error[E0061]: call to unsafe function `danger` outside an `unsafe` block or `unsafe fn`
  --> main.rok:2:12
   |
 2 | println(f"{danger()}");
   |            ^^^^^^^^
   |
   = help: wrap the call in `unsafe { .. }`; every `extern` function, `extern "rok"` included, is unsafe to call
```

Wrap the call in `unsafe { .. }`:

```rok
unsafe fn danger() -> i32 { 1 }
println(f"{unsafe { danger() }}");
```

```output
1
```
