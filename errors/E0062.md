# E0062: error not handled

A call can throw, and the error is neither caught nor declared. Mark the call with `try`, then either catch the error or add it to the enclosing function's `throws`.

```rok norun
let n = "42".parse::<i32>();
```

```text check=checks/E0062.rok
error[E0062]: this call can throw `ParseError` and must be marked with `try` (`try f()`; `try? f()` / `try! f()` to drop / panic on the error)
  --> main.rok:1:9
   |
 1 | let n = "42".parse::<i32>();
   |         ^^^^^^^^^^^^^^^^^^^
```

Mark the call with `try`, and declare `throws` where the error goes on:

```rok
fn main() throws {
    let n = try "42".parse::<i32>();
    println(f"{n}");
}
```

```output
42
```

`try? f()` turns the error into `none`, and `try! f()` panics on it ([chapter 10](../learn/10-errors.html)).
