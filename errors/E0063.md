# E0063: thrown value is not an `Error`

Only types that implement `Error` can be thrown. Implement `Error` for the type, or throw an error type that wraps the value.

```rok norun
struct Plain { msg: str; }

fn f() throws {
    throw Plain { msg: "bad" };
}
```

```text check=checks/E0063.rok
error[E0063]: `Plain` can't be thrown: it does not implement `Error`
  --> main.rok:4:5
   |
 4 |     throw Plain { msg: "bad" };
   |     ^^^^^
   |
   = help: add `impl Error for Plain {}` (it needs `Display` and `Debug`), or throw a `ValueError`: `throw ValueError::new(..);`
```

Give the type `Debug` and `Display`, and implement `Error`:

```rok
#[derive(Debug)]
struct Plain { msg: str; }
impl Display for Plain {
    fn fmt(self, ref f: Formatter) throws (FmtError) { try f.write_str(self.msg); }
}
impl Error for Plain {}

fn f() throws {
    throw Plain { msg: "bad" };
}
try f() catch e { println(f"{e}") };
```

```output
bad
```
