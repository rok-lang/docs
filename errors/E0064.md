# E0064: optional operator on a value that is not optional

`?`, `??` and `?.` work on optional values (`T | none`), and `try?` / `try!` on calls that throw. Use `.` on a plain value, and `throws` with `try` to pass errors on.

```rok norun
let xs = [1, 2, 3];
let n = xs.len()?;
```

```text check=checks/E0064.rok
error[E0064]: `?` only works on `T | none`, found `usize` - to propagate errors use `throws` and `try`
  --> main.rok:2:9
   |
 2 | let n = xs.len()?;
   |         ^^^^^^^^^
```

Use the value as it is:

```rok
let xs = [1, 2, 3];
let n = xs.len();
println(f"{n}");
```

```output
3
```
