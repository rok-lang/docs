# E0065: lock guard not released by `using`

A lock guard is released only when a `using` block ends. Bind the guard with `using g = m.lock() { .. }` instead of `let`, and do not discard it.

```rok norun
let m = Mutex::new(0);
let g = m.lock();
```

```text check=checks/E0065.rok
error[E0065]: `g` holds a `MutexGuard` that is never released: only `using` releases a lock guard, so bind it with `using g = .. { .. }`
  --> main.rok:2:1
   |
 2 | let g = m.lock();
   | ^^^
```

Bind the guard with `using`:

```rok
let m = Mutex::new(0);
using g = m.lock() { g.set(g.get() + 1) }
using g = m.lock() { println(f"{g.get()}") }
```

```output
1
```
