# E0066: `using` on a value without `Drop`

`using` releases its resource at the end of the block, so the resource's type must implement `Drop` or hold a `Drop` field. Use a plain `let` for other values.

```rok norun
using n = 3 {
    println(f"{n}");
}
```

```text check=checks/E0066.rok
error[E0066]: `using` needs a resource whose type implements `Drop`; `i64` does not implement `Drop` nor hold a `Drop` field
  --> main.rok:1:7
   |
 1 | using n = 3 {
   |       ^
```

Use a plain `let`:

```rok
let n = 3;
println(f"{n}");
```

```output
3
```
