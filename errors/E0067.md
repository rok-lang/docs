# E0067: block statement leaves a value

A block-like statement (`if`, `match`, a block) gives a value but is not the last expression and has no `;`. Add `;` to drop the value, or bind it with `let`.

```rok norun
fn pick(c: bool) -> i32 {
    if c { 1 } else { 2 }
    3
}
```

```text check=checks/E0067.rok
error[E0067]: this block-like statement leaves a value of type `i64` without `;`: a statement must be `()` (add `;` to discard it, or make it the block's last expression)
  --> main.rok:2:5
   |
 2 |     if c { 1 } else { 2 }
   |     ^^
```

Make the `if` the function's value, or end it with `;`:

```rok
fn pick(c: bool) -> i32 {
    if c { 1 } else { 2 }
}
println(f"{pick(true)}");
```

```output
1
```
