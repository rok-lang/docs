# E0068: value cannot be iterated

`for` iterates an integer range with a start (`0..n`, `0..`), an array, or a type that implements `IntoIterator` or `Iterator` (whose `next` returns `T | none`); `try for` iterates a `TryIterator`. Iterate one of those, or call the method that gives an iterator.

```rok norun
struct Bag { n: i32; }

let b = Bag { n: 3 };
for x in b {
    println(f"{x}");
}
```

```text check=checks/E0068.rok
error[E0068]: cannot iterate over a value of type `Bag` - `for` needs an integer range, an array, an `IntoIterator` / `Iterator` impl, or a `TryIterator` (`try for`)
  --> main.rok:4:1
   |
 4 | for x in b {
   | ^^^^^^^^^^^^
```

Iterate a range, a collection or an iterator:

```rok
struct Bag { n: i32; }

let b = Bag { n: 3 };
for x in 0..b.n {
    println(f"{x}");
}
```

```output
0
1
2
```
