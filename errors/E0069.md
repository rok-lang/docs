# E0069: trait bound not satisfied

A type does not implement a trait that a generic parameter, an associated type or a slot requires. Implement the trait for the type, or use a type that has it.

```rok norun
fn keep<T: Clone>(x: T) -> T { x }
struct P { x: i32; }

println(f"{keep(P { x: 1 }).x}");
```

```text check=checks/E0069.rok
error[E0069]: type `P` does not satisfy trait bound `Clone` required by `keep`
  --> main.rok:4:12
   |
 4 | println(f"{keep(P { x: 1 }).x}");
   |            ^^^^^^^^^^^^^^^^
```

Implement the trait for the type, here by deriving it:

```rok
fn keep<T: Clone>(x: T) -> T { x }
#[derive(Clone)]
struct P { x: i32; }

println(f"{keep(P { x: 1 }).x}");
```

```output
1
```
