# E0069: trait bound not satisfied

A type does not implement a trait that a generic parameter, an associated type or a slot requires. Implement the trait for the type, or use a type that has it.

```rok norun
fn keep<T: Clone>(x: T) -> T { x }
struct P { x: i32; }

println(f"{keep(P { x: 1 }).x}");
```

```text check=checks/E0069.rok
error[E0069]: type `P` does not satisfy trait bound `Clone` required by `keep`
  --> main.rok:4:12
   |
 4 | println(f"{keep(P { x: 1 }).x}");
   |            ^^^^^^^^^^^^^^^^
```

Implement the trait for the type, here by deriving it:

```rok
fn keep<T: Clone>(x: T) -> T { x }
#[derive(Clone)]
struct P { x: i32; }

println(f"{keep(P { x: 1 }).x}");
```

```output
1
```

A repeat literal `[v; N]` gives each element its own copy of `v` with `clone()`, so an element type that holds a collection must be `Clone` too:

```rok norun
struct Bag { xs: List<i32>; }

let bags = [Bag { xs: [] }; 3];
```

```text check=checks/E0069-repeat.rok
error[E0069]: `[v; N]` copies `v` into each element with `clone()`, but `Bag` is not `Clone`
  --> main.rok:3:12
   |
 3 | let bags = [Bag { xs: [] }; 3];
   |            ^^^^^^^^^^^^^^^^^^^
   |
   = help: build each element on its own: `List::from_fn(3, |_| ..)`
```

Derive `Clone` for the type, or build each element on its own:

```rok
struct Bag { xs: List<i32>; }

let bags = List::from_fn(3, |_| Bag { xs: [] });
bags[0].xs.push(1);
println(f"{bags.len()} {bags[0].xs:?} {bags[1].xs:?}");
```

```output
3 [1] []
```
