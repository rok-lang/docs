# E0071: trait used as a type

A trait is not a type. For a value of any type that implements it write `any Trait`, and for a generic parameter `T: Trait`.

```rok norun
trait Animal { fn name(self) -> str; }
fn f(a: Animal) {}
```

```text check=checks/E0071.rok
error[E0071]: trait `Animal` cannot be used as a type directly
  --> main.rok:2:1
   |
 2 | fn f(a: Animal) {}
   | ^^
   |
   = help: use `any Animal` for a value of any type implementing it, or a generic parameter `<T: Animal>`
```

Write `any Animal`:

```rok
trait Animal { fn name(self) -> str; }
struct Dog {}
impl Animal for Dog { fn name(self) -> str { "dog" } }

fn f(a: any Animal) { println(a.name()); }
f(Dog {});
```

```output
dog
```
