# E0072: impl is missing a trait item

A trait impl must define every method and associated constant the trait declares without a default. Add the missing items.

```rok norun
trait Shape {
    fn area(self) -> f64;
    fn name(self) -> str;
}
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
}
```

```text check=checks/E0072.rok
error[E0072]: impl of trait `Shape` for `Sq` is missing method `name`
  --> main.rok:6:1
   |
 6 | impl Shape for Sq {
   | ^^^^
```

Add the missing method:

```rok
trait Shape {
    fn area(self) -> f64;
    fn name(self) -> str;
}
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
    fn name(self) -> str { "square" }
}
println(Sq { s: 1.0 }.name());
```

```output
square
```
