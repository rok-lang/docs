# E0072: impl is missing a trait item

A trait impl must define every method, associated type and associated constant the trait declares without a default. Add the missing items.

```rok norun
trait Shape {
    fn area(self) -> f64;
    fn name(self) -> str;
}
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
}
```

```text check=checks/E0072.rok
error[E0072]: impl of trait `Shape` for `Sq` is missing method `name`
  --> main.rok:6:1
   |
 6 | impl Shape for Sq {
   | ^^^^
```

Add the missing method:

```rok
trait Shape {
    fn area(self) -> f64;
    fn name(self) -> str;
}
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
    fn name(self) -> str { "square" }
}
println(Sq { s: 1.0 }.name());
```

```output
square
```

An associated type the trait declares without a default must be given too; the help names the type the impl's methods use for it:

```rok norun
struct Count { n: i32; }
impl Iterator for Count {
    fn next(ref self) -> i32 | none {
        if self.n > 2 { return none; }
        self.n += 1;
        self.n
    }
}
```

```text check=checks/E0072-assoc.rok
error[E0072]: impl of `Iterator` for `Count` is missing associated type `Item`
  --> main.rok:2:1
   |
 2 | impl Iterator for Count {
   | ^^^^
   |
   = help: the trait declares `type Item` with no default: add `type Item = i32;` to the impl
```

Add the associated type:

```rok
struct Count { n: i32; }
impl Iterator for Count {
    type Item = i32;
    fn next(ref self) -> i32 | none {
        if self.n > 2 { return none; }
        self.n += 1;
        self.n
    }
}
for v in (Count { n: 0 }) { println(f"{v}"); }
```

```output
1
2
3
```
