# E0073: impl item is not in the trait

A trait impl defines a method the trait does not declare. Remove it, or move it to an inherent `impl` of the type.

```rok norun
trait Shape { fn area(self) -> f64; }
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
    fn side(self) -> f64 { self.s }
}
```

```text check=checks/E0073.rok
error[E0073]: method `side` is not a member of trait `Shape`
  --> main.rok:3:1
   |
 3 | impl Shape for Sq {
   | ^^^^
```

Move the method to an inherent `impl`:

```rok
trait Shape { fn area(self) -> f64; }
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
}
impl Sq {
    fn side(self) -> f64 { self.s }
}
println(f"{Sq { s: 3.0 }.side()}");
```

```output
3
```
