# E0074: impl item does not match the trait

A method in a trait impl differs from the trait's declaration in its parameters, return type or `throws`. Write it as the trait declares it.

```rok norun
trait Shape { fn area(self) -> f64; }
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self, scale: f64) -> f64 { self.s * scale }
}
```

```text check=checks/E0074.rok
error[E0074]: `area` does not match its declaration in trait `Shape`: it takes 2 parameters where the trait's takes 1
  --> main.rok:4:5
   |
 4 |     fn area(self, scale: f64) -> f64 { self.s * scale }
   |     ^^
   |
   = help: write `fn area(self) -> f64`
```

Write the method as the trait declares it:

```rok
trait Shape { fn area(self) -> f64; }
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
}
println(f"{Sq { s: 2.0 }.area()}");
```

```output
4
```
