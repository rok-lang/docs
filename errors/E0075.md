# E0075: conflicting implementations

Two impls give the same trait, or the same method, for one type. Remove one, or narrow a generic impl so they no longer overlap.

```rok norun
trait Show { fn show(self) -> str; }
impl<T> Show for T { fn show(self) -> str { "any" } }
impl Show for i32 { fn show(self) -> str { "i32" } }
```

```text check=checks/E0075.rok
error[E0075]: conflicting implementations of trait `Show` for `i32`: the concrete impl overlaps `impl<..> Show for T` (one impl per trait and type; no specialization)
  --> main.rok:2:18
   |
 2 | impl<T> Show for T { fn show(self) -> str { "any" } }
   |                  ^
```

Keep one impl for each trait and type:

```rok
trait Show { fn show(self) -> str; }
impl Show for i32 { fn show(self) -> str { "i32" } }
println(3.show());
```

```output
i32
```
