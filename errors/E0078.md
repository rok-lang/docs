# E0078: impl not allowed

This impl is not allowed: an inherent impl on a type parameter, a manual impl of `Reflect`, or an `unsafe impl` / `impl !Trait` of a trait that is not an auto trait (`Send`, `Sync`). Remove it, or write the form the message gives.

```rok norun
struct X { n: i32; }
impl Send for X {}
```

```text check=checks/E0078.rok
error[E0078]: `Send` is an auto trait the compiler derives from the fields; a manual impl for `X` must be `unsafe impl Send for X {}`
  --> main.rok:2:1
   |
 2 | impl Send for X {}
   | ^^^^
```

`Send` and `Sync` come from the fields, so a type of `Send` fields is `Send` without an impl:

```rok
struct X { n: i32; }
fn needs_send<T: Send>(x: T) -> T { x }
println(f"{needs_send(X { n: 1 }).n}");
```

```output
1
```
