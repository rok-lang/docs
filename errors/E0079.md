# E0079: cannot evaluate at compile time

A const, array length, const generic argument or `const fn` body uses something that has no value at compile time: a call of a plain `fn`, a heap allocation, or a runtime value. Use literals, other consts and `const fn` calls.

```rok norun
fn three() -> i32 { 3 }
const N: i32 = three();
```

```text check=checks/E0079.rok
error[E0079]: const `N` cannot be evaluated at compile time: calls `three`, which is not a `const fn`
  --> main.rok:2:16
   |
 2 | const N: i32 = three();
   |                ^^^^^^^
```

Make the function a `const fn`:

```rok
const fn three() -> i32 { 3 }
const N: i32 = three();
println(f"{N}");
```

```output
3
```
