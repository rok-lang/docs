# E0081: invalid const generic argument

A const generic argument has the wrong type or is out of range for its parameter. Pass a constant of the parameter's type.

```rok norun
struct Sep<const C: char> {}

let s = Sep::<97> {};
```

```text check=checks/E0081.rok
error[E0081]: const argument for `C: char` must be a `char`, found an integer
  --> main.rok:3:9
   |
 3 | let s = Sep::<97> {};
   |         ^^^^^^^^^^^^
```

Pass a constant of the parameter's type:

```rok
struct Sep<const C: char> {}

let s = Sep::<'a'> {};
println("ok");
```

```output
ok
```
