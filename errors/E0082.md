# E0082: wrong generic arguments

A generic item is given the wrong number of type arguments, or ones that do not fit its definition. Pass one argument per parameter (parameters with defaults may be left out).

```rok norun
let xs: List<i32, str> = [];
```

```text check=checks/E0082.rok
error[E0082]: `List` takes 1 generic argument but 2 were given
  --> main.rok:1:9
   |
 1 | let xs: List<i32, str> = [];
   |         ^^^^
   |
   = help: `List` is declared `List<T>`; remove the last argument
```

Pass one argument per parameter:

```rok
let xs: List<i32> = [];
println(f"{xs.len()}");
```

```output
0
```
