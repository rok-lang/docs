# E0083: invalid enum value

A value enum (`V = n`) has only value variants, each with a distinct constant that fits the tag type. Fix the variants the message names.

```rok norun
enum Code { Ok = 0, Bad = 0 }
```

```text check=checks/E0083.rok
error[E0083]: `Code::Bad` and `Code::Ok` have the same value 0
  --> main.rok:1:1
   |
 1 | enum Code { Ok = 0, Bad = 0 }
   | ^^^^
```

Give each variant its own value:

```rok
enum Code { Ok = 0, Bad = 1 }
println(f"{Code::Bad as i32}");
```

```output
1
```
