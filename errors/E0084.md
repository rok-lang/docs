# E0084: invalid foreign-function use

A C function, `extern` declaration or `extern "C" fn` breaks an FFI rule: a type C cannot hold (one the collector may move), a closure passed as a C callback, two declarations with different signatures, or a variadic argument C cannot take. Pass C-compatible types, and named functions as callbacks.

```rok norun
extern "C" {
    fn abs(x: i32) -> i32;
    fn abs(x: i64) -> i64;
}
```

```text check=checks/E0084.rok
error[E0084]: extern function `abs` is declared twice with different signatures: `fn(i64) -> i64` here, `fn(i32) -> i32` elsewhere
  --> main.rok:3:5
   |
 2 |     fn abs(x: i32) -> i32;
   |     -- declared as `fn(i32) -> i32` here
 3 |     fn abs(x: i64) -> i64;
   |     ^^
   |
   = help: a C symbol has one signature: declare `abs` as `fn(i32) -> i32` here too, or drop this declaration
```

Declare each C function once, with its C signature:

```rok
extern "C" {
    fn abs(x: i32) -> i32;
    fn labs(x: i64) -> i64;
}
println(f"{unsafe { labs(-5) }}");
```

```output
5
```
