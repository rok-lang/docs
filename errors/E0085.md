# E0085: value cannot cross threads

The value may be used by two threads at once: a `static` of a non-`Sync` type, a `[ref x]` capture in a spawned closure, or a non-`Send` value given to a task. Share it through a `Mutex`, an atomic or a channel.

```rok norun
use rok::std::thread;

let count = 0;
let t = thread::spawn([ref count] || { count += 1; });
try! t.join();
```

```text check=checks/E0085.rok
error[E0085]: `[ref count]` can't be used in a closure that may run on another thread: both threads could change `count` at once
  --> main.rok:4:9
   |
 4 | let t = thread::spawn([ref count] || { count += 1; });
   |         ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
   |
   = help: write `let count = Atomic::new(count);` before the closure, capture `count` without `ref`, and use `count.load()` / `count.store(..)`; or return the value from the closure instead
```

Share the counter through an atomic:

```rok
use rok::std::thread;

let count = Atomic::new(0);
let t = thread::spawn(|| { count.fetch_add(1); });
try! t.join();
println(f"{count.load()}");
```

```output
1
```
