# E0086: invalid union

A union declares at least one field, and its literal sets exactly one of them, with no `..base`. Unions take only `#[repr(C)]`.

```rok norun
#[repr(C)]
union Empty {}
```

```text check=checks/E0086.rok
error[E0086]: union `Empty` declares no fields
  --> main.rok:2:1
   |
 2 | union Empty {}
   | ^^^^^
```

Declare at least one field. A union exists to match a C union, so it is `#[repr(C)]` and is read in `unsafe` code ([chapter 14](../learn/14-ffi.html)).
