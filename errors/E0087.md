# E0087: ambiguous associated item

Several traits, impls or bounds give a method, associated type or constant of this name, so `T::name` is unclear. Name the trait: `<T as Trait>::name`, or call the method as `Trait::name(x)`.

```rok norun
trait A { const N: i32; }
trait B { const N: i32; }
struct S {}
impl A for S { const N: i32 = 1; }
impl B for S { const N: i32 = 2; }

println(f"{S::N}");
```

```text check=checks/E0087.rok
error[E0087]: associated const `N` of `S` is ambiguous: `A` and `B` define it - name the trait (`<T as Tr>::N`)
  --> main.rok:7:12
   |
 7 | println(f"{S::N}");
   |            ^^^^
```

Name the trait:

```rok
trait A { const N: i32; }
trait B { const N: i32; }
struct S {}
impl A for S { const N: i32 = 1; }
impl B for S { const N: i32 = 2; }

println(f"{<S as B>::N}");
```

```output
2
```
