# E0088: invalid format

An f-string hole formats a value that does not support the format (`{}` needs `Display`, `{:?}` needs `Debug`), or its format spec is not valid. Implement or derive the trait, or change the spec.

```rok norun
let name = "rok";
println(f"{name:x}");
```

```text check=checks/E0088.rok
error[E0088]: format type `x` needs an integer, found `str`
  --> main.rok:2:12
   |
 2 | println(f"{name:x}");
   |            ^^^^
```

Use a format that fits the value:

```rok
let n = 255;
println(f"{n:x}");
```

```output
ff
```
