# E0089: invalid compiler built-in call

A call of a compiler built-in (`size_of::<T>()`, the `atomic_*` and pointer operations, `addr_of`, `GcBuf` functions) has the wrong arguments: a value where a place is needed, an ordering that is not constant, or a missing type argument. Call it as the message shows.

```rok norun
use rok::bare::mem::size_of;

let n = size_of();
```

```text check=checks/E0089.rok
error[E0089]: `size_of` is called as `size_of::<T>()`
  --> main.rok:3:9
   |
 3 | let n = size_of();
   |         ^^^^^^^^^
```

Give the type argument:

```rok
use rok::bare::mem::size_of;

println(f"{size_of::<i64>()}");
```

```output
8
```
