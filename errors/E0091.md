# E0091: invalid broadcast

A broadcast call `f.(xs)` maps over a `List`, `Slice` or array, and arrays given together must have the same length. Pass collections of matching length.

```rok norun
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 4] = [10, 20, 30, 40];
println(f"{add.(xs, ys):?}");
```

```text check=checks/E0091.rok
error[E0091]: broadcast over arrays of lengths 3 and 4
  --> main.rok:5:12
   |
 5 | println(f"{add.(xs, ys):?}");
   |            ^^^^^^^^^^^^
```

Pass arrays of the same length:

```rok
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 3] = [10, 20, 30];
println(f"{add.(xs, ys):?}");
```

```output
[11, 22, 33]
```
