# E0092: `Drop::drop` called directly

`drop` runs on its own when a `using` block ends, and calling it again would release the resource twice. Expose a method such as `close()` for an early release.

```rok norun
struct Conn { id: i32; }
impl Drop for Conn { fn drop(ref self) {} }

let c = Conn { id: 1 };
c.drop();
```

```text check=checks/E0092.rok
error[E0092]: `Drop::drop` cannot be called directly; it runs when a `using` block exits - expose a method such as `close()` to release early
  --> main.rok:5:1
   |
 5 | c.drop();
   | ^^^^^^^^
```

Let `using` release the value:

```rok
struct Conn { id: i32; }
impl Drop for Conn { fn drop(ref self) { println(f"closed {self.id}"); } }

using c = (Conn { id: 1 }) {
    println(f"using {c.id}");
}
```

```output
using 1
closed 1
```
