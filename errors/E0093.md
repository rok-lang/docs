# E0093: generic instantiation too deep

Instantiating a generic function made it instantiate itself with ever larger types. Break the recursion, for example with an `any` parameter.

```rok norun
fn nest<T>(x: T, n: i32) -> i32 {
    if n == 0 { return 0; }
    nest((x, x), n - 1)
}
println(f"{nest(1, 3)}");
```

```text check=checks/E0093.rok
error[E0093]: instantiating generic function `nest` recursed past the limit (depth 64) - the instantiation never reaches a fixed point
  --> main.rok:3:5
   |
 3 |     nest((x, x), n - 1)
   |     ^^^^^^^^^^^^^^^^^^^
```

Take a value of any type with `any` instead of a type parameter:

```rok
fn nest(x: any Debug, n: i32) -> i32 {
    if n == 0 { return 0; }
    nest(x, n - 1)
}
println(f"{nest(1, 3)}");
```

```output
0
```
