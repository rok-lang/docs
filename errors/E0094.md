# E0094: invalid representation

A `#[repr(..)]` or `#[niche]` does not fit the type: a packed struct that holds a collected reference, a union with a repr other than `C`, or `#[niche]` on a type with more than one field. Change the attribute or the type.

```rok norun
#[niche]
struct Pair { a: i32; b: i32; }
```

```text check=checks/E0094.rok
error[E0094]: `#[niche]` goes on a single-field struct, not a struct with 2 fields
  --> main.rok:1:1
   |
 1 | #[niche]
   | ^^
```

Put `#[niche]` on a struct with exactly one field, or remove it. A `#[repr(packed)]` struct holds C data only, not `str`, collections or closures.

Related: [E0086](E0086.html) invalid union, [E0083](E0083.html) invalid enum value
