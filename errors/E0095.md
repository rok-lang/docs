# E0095: type too large

A value type is larger than the compiler handles. Hold the large part through a reference type such as `List`.

```rok norun
struct W<T> { a: T; b: T; }

let x: W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<i64>>>>>>>>>>>>>>>>>>>>>>>>>>> = panic("unreachable");
```

```text check=checks/E0095.rok
  --> main.rok:3:30
   |
 3 | let x: W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<i64>>>>>>>>>>>>>>>>>>>>>>>>>>> = panic("unreachable");
   |                              ^
```

Hold the large part through a reference type, such as a `List` of the inner values or a struct of your own that holds one.
