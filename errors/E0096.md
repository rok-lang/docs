# E0096: `try` or `catch` that does nothing

A `try` covers no call that throws, or no error reaches a `catch`. Remove it.

```rok norun
let n = try 1 + 2;
println(f"{n}");
```

```text check=checks/E0096.rok
warning[E0096]: this `try` covers no throwing call
  --> main.rok:1:9
   |
 1 | let n = try 1 + 2;
   |         ^^^^^^^^^
```

Remove the `try`:

```rok
let n = 1 + 2;
println(f"{n}");
```

```output
3
```

This is a warning: the program still builds.

Related: [E0062](E0062.html) error not handled, [E0064](E0064.html) optional operator on a value that is not optional
