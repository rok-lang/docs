# E0097: ROKON value of the wrong shape

A ROKON file (`rok.rokon`, a config) parses, but a value does not fit what the reader expects: a missing field, a value of the wrong type, or a number out of range. Write the value the message names.

This `rok.rokon` gives `version` as a number:

```rokon
Package {
    name: "pk",
    version: 1,
}
```

`rok check` prints:

```text
error[E0097]: `version` must be a string, found an integer
  --> rok.rokon:3:14
   |
 3 |     version: 1,
   |              ^
```

Give `version` as a string, `version: "0.1.0"`. The ROKON format is described in [chapter 11](../learn/11-modules-packages.html).
