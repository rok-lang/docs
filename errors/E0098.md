# E0098: non-exhaustive match

A `match` must cover every value. Add arms for the cases the message lists, or a `_` arm; an enum marked `#[non_exhaustive]` in another package always needs `_`.

```rok norun
enum Light { Red, Yellow, Green }

fn next(l: Light) -> Light {
    match l {
        Light::Red => Light::Green,
        Light::Green => Light::Yellow,
    }
}
```

```text check=checks/E0098.rok
error[E0098]: non-exhaustive match on `Light`: `Light::Yellow` not covered
  --> main.rok:4:5
   |
 4 |     match l {
   |     ^^^^^^^^^
   |
   = help: add `Light::Yellow => ..`
```

Add an arm for the missing case:

```rok
#[derive(PartialEq)]
enum Light { Red, Yellow, Green }

fn next(l: Light) -> Light {
    match l {
        Light::Red => Light::Green,
        Light::Green => Light::Yellow,
        Light::Yellow => Light::Red,
    }
}
println(f"{next(Light::Yellow) == Light::Red}");
```

```output
true
```

See [3.12.5 Exhaustiveness checking](../spec/refs-lang/003-expressions/312-match-expression.html#3125-exhaustiveness-checking).
