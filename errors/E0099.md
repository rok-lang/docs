# E0099: unreachable match arm

Earlier arms already match every value this arm matches, so it never runs. Remove it, or move it before the arm that covers it.

```rok norun
let n = 1;
let r = match n {
    _ => 0,
    1 => 1,
};
```

```text check=checks/E0099.rok
error[E0099]: unreachable match arm 2: earlier arms already match every value it matches
  --> main.rok:2:9
   |
 2 | let r = match n {
   |         ^^^^^^^^^
```

Move the catch-all arm last:

```rok
let n = 1;
let r = match n {
    1 => 1,
    _ => 0,
};
println(f"{r}");
```

```output
1
```
