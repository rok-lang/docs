# E0100: pattern does not fit the value's type

A pattern cannot match a value of this type: a struct pattern of another struct, a tuple pattern on a value that is not a tuple, or a refutable pattern where only an irrefutable one goes (`let`, parameters, `for`). Write a pattern of the value's type, and use `match` or `let .. else` for refutable ones.

```rok norun
let n = 5;
let (a, b) = n;
```

```text check=checks/E0100.rok
error[E0100]: tuple destructure of a non-tuple value of type `i32`
  --> main.rok:2:1
   |
 2 | let (a, b) = n;
   | ^^^
```

Destructure a value of the pattern's type:

```rok
let pair = (5, 6);
let (a, b) = pair;
println(f"{a} {b}");
```

```output
5 6
```
