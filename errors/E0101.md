# E0101: wrong number of fields in a pattern

A tuple or variant pattern has more or fewer parts than the value. Match each part, or use `..` for the rest.

```rok norun
let t = (1, 2, 3);
let (a, b) = t;
```

```text check=checks/E0101.rok
error[E0101]: tuple destructure length mismatch: pattern has 2 elements, value has 3
  --> main.rok:2:1
   |
 2 | let (a, b) = t;
   | ^^^
```

Match every part, or use `..` for the rest:

```rok
let t = (1, 2, 3);
let (a, ..) = t;
println(f"{a}");
```

```output
1
```
