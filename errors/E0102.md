# E0102: or-pattern alternatives bind differently

Every alternative of `a | b` binds the same names, with the same types. Bind the same names in each, or give the binding a sum type.

```rok norun
enum Shape { Circle(f64), Square(f64), Point }

fn size(s: Shape) -> f64 {
    match s {
        Shape::Circle(r) | Shape::Point => r,
        Shape::Square(w) => w,
    }
}
```

```text check=checks/E0102.rok
error[E0102]: or-pattern alternatives bind different name sets (alternative 1: missing `r`)
  --> main.rok:4:5
   |
 4 |     match s {
   |     ^^^^^^^^^
```

Bind the same names in every alternative:

```rok
enum Shape { Circle(f64), Square(f64), Point }

fn size(s: Shape) -> f64 {
    match s {
        Shape::Circle(v) | Shape::Square(v) => v,
        Shape::Point => 0.0,
    }
}
println(f"{size(Shape::Square(2.0))}");
```

```output
2
```
