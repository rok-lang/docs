# E0103: binding looks like a variant

A bare name in a pattern is a new variable that matches everything, not the variant of that name. Write the variant's path, `Color::Red`, to match it.

```rok norun
const LIMIT: i32 = 10;

let n = 3;
match n {
    LIMIT => println("at the limit"),
    _ => println("below"),
}
```

```text check=checks/E0103.rok
error[E0103]: `LIMIT` here would be a new variable that matches every value, not the const `LIMIT`
  --> main.rok:5:5
   |
 5 |     LIMIT => println("at the limit"),
   |     ^^^^^
   |
   = help: to compare with the const, write `x if x == LIMIT`
```

Compare with the const in a guard:

```rok
const LIMIT: i32 = 10;

let n = 3;
match n {
    m if m == LIMIT => println("at the limit"),
    _ => println("below"),
}
```

```output
below
```
