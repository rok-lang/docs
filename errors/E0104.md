# E0104: invalid rest pattern

A pattern has at most one `..`, and a rest pattern goes only where the message says. Remove the extra `..`.

```rok norun
enum E { A(i32, i32, i32) }

let v = E::A(1, 2, 3);
match v {
    E::A(x, .., y, ..) => println(f"{x}"),
}
```

```text check=checks/E0104.rok
error[E0104]: pattern `E::A` has more than one `..`
  --> main.rok:4:1
   |
 4 | match v {
   | ^^^^^^^^^
```

Keep one `..`:

```rok
enum E { A(i32, i32, i32) }

let v = E::A(1, 2, 3);
match v {
    E::A(x, .., y) => println(f"{x} {y}"),
}
```

```output
1 3
```
