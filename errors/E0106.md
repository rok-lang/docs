# E0106: value used after its lock was released

The value came out of a `Mutex` or `RwLock`, and the `using` block that held the lock has ended, so the lock no longer protects it. Use it inside the `using` block, or take a copy with `.clone()`.

```rok norun
let m = Mutex::new([1, 2, 3]);
let xs = using g = m.lock() { g.get() };
xs.push(4);
```

```text check=checks/E0106.rok
error[E0106]: the value of `g`'s `using` block is what the `Mutex` protects, and the block releases the lock before it is used
  --> main.rok:2:10
   |
 2 | let xs = using g = m.lock() { g.get() };
   |          ^^^^^
   |          ----- taken out of the lock here
   |
   = help: use it inside the `using` block, or make the block's value `using.clone()`
```

Take a deep copy out of the block with `get_clone()`:

```rok
let m = Mutex::new([1, 2, 3]);
let xs = using g = m.lock() { g.get_clone() };
xs.push(4);
println(f"{xs.len()}");
```

```output
4
```

What a lock guard's `get()` returns is a view of the protected value: passing it to a function that keeps it is E0106 too.
