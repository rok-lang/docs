# E0108: cannot derive

A `#[derive(..)]` cannot implement the trait for this type: a field does not implement it, it needs another derived trait too, or the type is of a kind the derive does not support. Implement the trait by hand, or fix the field the message names.

```rok norun
struct NoClone { n: i32; }
#[derive(Clone)]
struct Holder { n: NoClone; }
```

```text check=checks/E0108.rok
error[E0108]: cannot derive `Clone` for `Holder`: `n` has type `NoClone`, which does not implement `Clone`
  --> main.rok:2:1
   |
 2 | #[derive(Clone)]
   | ^^
```

Derive the trait for the field's type too, or implement it by hand:

```rok
#[derive(Clone)]
struct NoClone { n: i32; }
#[derive(Clone)]
struct Holder { n: NoClone; }
let h = Holder { n: NoClone { n: 1 } };
println(f"{h.clone().n.n}");
```

```output
1
```

A trait that cannot be derived at all, such as `Display`, is also E0108; the message says why.
