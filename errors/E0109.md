# E0109: malformed attribute

An attribute's arguments are not in the form it takes, or the attribute is not one Rok knows. The message gives the form, such as `#[path("file.rok")]`.

```rok norun
#[inlin]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```text check=checks/E0109.rok
error[E0109]: unknown attribute `#[inlin]`: not built in and no meta block defines it
  --> main.rok:1:1
   |
 1 | #[inlin]
   | ^^
```

Spell the attribute as listed in [6.2 Built-in attributes](../spec/refs-lang/006-meta-system/602-built-in-attributes.html):

```rok
#[inline]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```output
4
```

An attribute that is neither built in nor defined by a meta block in scope is unknown ([6.1.6](../spec/refs-lang/006-meta-system/601-attribute-syntax.html#616-unknown-attributes)).
