# E0111: invalid `#[lang]` item

`#[lang("slot")]` (standard library only) names a known slot, once, on an item of the slot's form.

```rok norun
#[lang("add_trait")]
trait BadAdd { fn plus(self, o: Self) -> Self; }
```

```text check=checks/E0111.rok
error[E0111]: `BadAdd` does not match the form of lang slot `add_trait`: it needs `fn add(self, _)`
  --> main.rok:1:1
   |
 1 | #[lang("add_trait")]
   | ^^
```

`#[lang]` is for the standard library. A program implements the standard trait instead: `impl Add for Point` gives `Point` the `+` operator.
