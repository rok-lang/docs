# E0112: invalid operator declaration

An operator attribute (`#[infix(..)]`, `#[prefix(..)]`, ..) on a trait method breaks a rule: a token that cannot be an operator, precedence on a built-in token, or aliases at different levels. A new token gives `like = "<existing token>"` for its precedence.

```rok norun
trait Before {
    #[infix(">>>", precedence = 3)]
    fn before(self, o: Self) -> bool;
}
```

```text check=checks/E0112.rok
error[E0112]: `#[infix]` takes only an operator token, `like = ".."` and `swap`: precedence and associativity are fixed by the language
  --> main.rok:2:5
   |
 2 |     #[infix(">>>", precedence = 3)]
   |     ^^
```

Remove the precedence. A new token borrows the precedence of a built-in one with `like`: `#[infix(">>>", like = ">>")]` ([6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)).
