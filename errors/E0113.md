# E0113: invalid `#[keyword]` declaration

`#[keyword("name")]` goes on a free function, its handler, and `name` is an identifier that is not already a keyword.

```rok norun
#[keyword("if")]
fn my_if(c: bool) -> bool { c }
```

```text check=checks/E0113.rok
error[E0113]: `#[keyword("if")]`: `if` is already a keyword
  --> main.rok:1:1
   |
 1 | #[keyword("if")]
   | ^^
```

Pick a name that is not a keyword yet, such as `#[keyword("unless")]`.

Related: [E0021](E0021.html) reserved word used as a name, [E0123](E0123.html) registered twice
