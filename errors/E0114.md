# E0114: invalid literal handler

A `#[literal(..)]` handler must be a function with the parameters its kind takes, registered once per suffix, priority and return type. A suffixed literal needs a handler for its suffix.

```rok norun
let d = 5q;
```

```text check=checks/E0114.rok
error[E0114]: unknown numeric literal suffix `q` - no `#[literal(number "q")]` handler is registered
  --> main.rok:1:9
   |
 1 | let d = 5q;
   |         ^^
```

Register a handler for the suffix; the literal becomes a call to it ([6.5](../spec/refs-lang/006-meta-system/605-literal-magic.html)):

```rok
#[literal(number "q")]
fn quarter(n: f64) -> f64 { n / 4.0 }

let d = 5q;
println(f"{d}");
```

```output
1.25
```
