# E0115: invalid `#[intrinsic]`

`#[intrinsic("rok.OP.TYPE")]` is for the standard library, on a function of the shape the operation takes.

```rok norun
#[intrinsic("rok.add.i32")]
fn add(a: i32, b: i32) -> i32 { a + b }
```

```text check=checks/E0115.rok
error[E0115]: `#[intrinsic]` on `add`: the intrinsic attribute is for the standard library only
  --> main.rok:2:1
   |
 2 | fn add(a: i32, b: i32) -> i32 { a + b }
   | ^^
```

Remove the attribute and write the body in Rok; the compiler optimizes plain arithmetic on its own.

Related: [E0111](E0111.html) invalid `#[lang]` item
