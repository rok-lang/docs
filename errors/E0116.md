# E0116: malformed macro definition

A macro's rules are not well formed. Each rule is `( matcher ) => { template }`, a metavariable is `@name: fragment`, and a repetition is `@rep[sep = ","] { .. }`.

```rok norun
#[impl_macro(twice)] @macro {
    @e: expr => { (@e, @e) }
}
let p = twice!(3);
```

```text check=checks/E0116.rok
error[E0116]: a macro rule starts with `( matcher )`
  --> main.rok:2:5
   |
 2 |     @e: expr => { (@e, @e) }
   |     ^
```

Wrap the matcher in parentheses:

```rok
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!(3);
println(f"{p.0 + p.1}");
```

```output
6
```

See [6.8.12 The macro form](../spec/refs-lang/006-meta-system/608-meta-blocks.html#6812-the-macro-form).
