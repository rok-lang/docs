# E0117: no macro rule matches

None of the macro's rules matches the arguments of this call. Check the call against the macro's matchers.

```rok norun
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!();
```

```text check=checks/E0117.rok
error[E0117]: no rule of macro `twice!` matches this call
  --> main.rok:4:9
   |
 4 | let p = twice!();
   |         ^^^^^
```

Call it with arguments a rule matches:

```rok
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!(3);
println(f"{p.0}");
```

```output
3
```
