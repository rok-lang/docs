# E0118: invalid meta template

A meta block's template uses a `@` token wrongly: an unknown token, one outside the `@for_fields` or `@for_variants` it needs, or one without its `(..)` or `{ .. }`. Write it as the message says.

```rok norun
#[impl_derive(Names)] @derive {
    impl @Self {
        fn names() -> str { @fild }
    }
}
#[derive(Names)]
struct P { x: i32; }
```

```text check=checks/E0118.rok
error[E0118]: unknown template token `@fild`
  --> main.rok:3:29
   |
 3 |         fn names() -> str { @fild }
   |                             ^
 ...
 6 | #[derive(Names)]
   | -- in this `#[derive(Names)]`
```

Spell the token as listed in [6.9 Template tokens](../spec/refs-lang/006-meta-system/609-template-tokens.html): here `@field`, inside a `@for_fields { .. }` block.
