# E0119: invalid meta block

A meta block's definition or use breaks a rule: it takes a built-in attribute's name, it is private to another file, its body does not start with the right `@` block, or it expands to something other than items. Fix the definition or the use as the message says.

```rok norun
#[impl_derive(Clone)] @derive {
    impl Clone for @Self {}
}
```

```text check=checks/E0119.rok
error[E0119]: `Clone` is a built-in derive; a meta block cannot redefine it
  --> main.rok:1:1
   |
 1 | #[impl_derive(Clone)] @derive {
   | ^^
```

Give the derive a name of its own, such as `#[impl_derive(MyClone)]`, or use the built-in `#[derive(Clone)]`.
