# E0120: recursive expansion

A macro or meta block expands into itself, directly or through others, without end. Break the cycle.

```rok norun
#[impl_macro(again)] @macro {
    ( @e: expr ) => { again!(@e) }
}
let x = again!(1);
```

```text check=checks/E0120.rok
error[E0120]: `again!` expands too deeply or cyclically
  --> main.rok:4:9
   |
 4 | let x = again!(1);
   |         ^^^^^
```

Make the template expand to code that does not call the macro again:

```rok
#[impl_macro(again)] @macro {
    ( @e: expr ) => { (@e, @e) }
}
let x = again!(1);
println(f"{x.0}");
```

```output
1
```
