# E0121: invalid `cfg` predicate

A `#[cfg(..)]` or `cfg!(..)` predicate is not well formed. It is a flag (`unix`), a `key = "value"` pair, or `all(..)`, `any(..)` and `not(..)` of those.

```rok norun
#[cfg(either(target_family = "unix", target_family = "windows"))]
println("desktop");
```

```text check=checks/E0121.rok
error[E0121]: unknown cfg combinator `either` (`all`, `any`, `not`)
  --> main.rok:1:1
   |
 1 | #[cfg(either(target_family = "unix", target_family = "windows"))]
   | ^^
```

Use `all`, `any` or `not`:

```rok
#[cfg(any(target_family = "unix", target_family = "windows"))]
println("desktop");
```

```output
desktop
```

[Chapter 17](../learn/17-conditional-compilation.html) lists the keys.
