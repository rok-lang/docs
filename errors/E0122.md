# E0122: file include failed

`include_str!` / `include_bytes!` take one string path, relative to the file, of a file that can be read.

```rok norun
let s = include_str!("missing.txt");
```

```text check=checks/E0122.rok
error[E0122]: `include_str!` cannot read "missing.txt": no such file
  --> main.rok:1:9
   |
 1 | let s = include_str!("missing.txt");
   |         ^^^^^^^^^^^
```

Create `missing.txt` next to `main.rok`, or fix the path. The path is relative to the file that has the `include_str!`.
