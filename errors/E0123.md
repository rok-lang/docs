# E0123: registered twice

A symbol, operator, lang slot, keyword or literal handler is registered by two items. Keep one.

```rok norun
#[keyword("twice")]
fn twice_a(x: i32) -> i32 { x * 2 }
#[keyword("twice")]
fn twice_b(x: i32) -> i32 { x + x }
```

```text check=checks/E0123.rok
error[E0123]: keyword `twice` is registered twice
  --> main.rok:3:1
   |
 1 | #[keyword("twice")]
   | -- first registered here
 ...
 3 | #[keyword("twice")]
   | ^^
```

Register the keyword once.

Related: [E0111](E0111.html) invalid `#[lang]` item, [E0112](E0112.html) invalid operator declaration, [E0113](E0113.html) invalid `#[keyword]` declaration
