# E0124: meta name cannot be resolved

A macro or meta block name is defined by several packages, or is reached only through a scope Rok no longer has. Import it from its package: `use dep::name!;`.

Import the macro or meta block from the package that defines it, `use dep::name!;`, or call it by its path, `dep::name!(..)`.

Related: [E0030](E0030.html) unresolved import, [E0119](E0119.html) invalid meta block
