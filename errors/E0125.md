# E0125: cannot read or write a file

The compiler could not read or write a file or directory. Check that the path exists and that you may read or write it.

The message names the path and the system's reason. A common case is an output directory that cannot be written: check `--target-dir`, the free space, and the permissions. A source file that does not exist is reported before compiling starts, as ``rokc: error: `x.rok` does not exist``.
