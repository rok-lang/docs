# E0127: code generation failed

The code generator (LLVM) failed. This is usually a compiler bug; please report it with the code that caused it.

No small program is known to trigger it. Building with the native backend (`-C backend=native`, the default at `-O0`) may get past it. Please report it at [github.com/rok-lang/rok/issues](https://github.com/rok-lang/rok/issues) with the program and the full output.
