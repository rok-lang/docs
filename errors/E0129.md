# E0129: invalid WIT

A `.wit` file named by `ffi::wit::import { .. }` or `ffi::wit::export { .. }` cannot be read, parsed or resolved. Fix the WIT file at the place the message names ([stdlib 1.8](../spec/refs-standard-libraries/100-bare/108-wit.html)).

```rok norun
ffi::wit::import { "calc.wit" }
```

```text check=checks/E0129.rok
error[E0129]: WIT: calc.wit:0:0: cannot read: No such file or directory (os error 2)
  --> main.rok:1:1
   |
 1 | ffi::wit::import { "calc.wit" }
   | ^^^
```

Create the WIT file, or fix the path; it is relative to the source file. When the file exists but does not parse, the message gives its line and column.

Related: [E0084](E0084.html) invalid foreign-function use, [E0125](E0125.html) cannot read or write a file
