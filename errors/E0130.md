# E0130: not supported by this backend

The code uses something the selected code generator does not support yet. Build with the LLVM backend (`-C backend=llvm`), or rewrite that part.

These are gaps in rokc, not mistakes in the program. Build with `-C backend=llvm` (the default above `-O0`), and please report the program at [github.com/rok-lang/rok/issues](https://github.com/rok-lang/rok/issues).
