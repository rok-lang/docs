# E0132: lint

A lint finding: code that compiles but is likely a mistake. Its note names the lint (`#[warn(name)]`, the JSON `lint` field). Fix the code, or allow the lint with `#[allow(name)]` or `-A name`; `rokc lint --list` describes every lint.

```rok norun
fn main() {
    let total = 10;
    let unused = 1;
    println(f"{total}");
}
```

```text check=checks/E0132.rok
warning[E0132]: unused variable `unused`
  --> main.rok:3:9
   |
 3 |     let unused = 1;
   |         ^^^^^^
   |
   = note: if this is intentional, prefix it with an underscore: `_unused`
   = note: `#[warn(unused_variables)]` on by default
```

Remove the variable, or prefix it with `_` if it is there on purpose:

```rok
fn main() {
    let total = 10;
    let _unused = 1;
    println(f"{total}");
}
```

```output
10
```

Every lint shares this code. Lints are warnings by default; they become errors with `deny` (in `rok.rokon`, with `-D` on the command line, or with `#[deny(..)]` in source). The last note names the lint and where its level was set ([6.2.9](../spec/refs-lang/006-meta-system/602-built-in-attributes.html#629-allow--deny--warn-lint-control)). See [chapter 16](../learn/16-tools.html) for setting levels.
