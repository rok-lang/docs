# E0133: invalid compiler option

A compiler option has a value it does not take. `rokc help` lists the options.

Most option mistakes are caught when the command line is read, with a message such as ``rokc: unknown option `--foo` `` and a pointer to `rokc help`. E0133 is for a value that passes that check but is rejected later, such as an optimization level the code generator does not know. Use a value from `rokc help build`.
