# E0134: resource used after it was moved or closed

A value whose type implements `Drop` (a `File`, a socket, a channel `Sender`) has one owner. It was moved to another owner or closed, and is used, moved or closed again here. Use the new owner, do the work before it is closed, or keep a copy with `.clone()` before it moves.

```rok norun
use rok::std::env;
use rok::std::fs::File;

fn main() throws {
    let f = try File::create(env::temp_dir() / "notes.txt");
    let g = f;
    try f.write_all("hi");
    try g.close();
}
```

```text check=checks/E0134.rok
error[E0134]: `f` was moved at line 6, and is used here
  --> main.rok:7:9
   |
 6 |     let g = f;
   |             - moved here
 7 |     try f.write_all("hi");
   |         ^
   |
   = help: a `File` has one owner, and `f` gave it away; use the new owner, or keep a copy with `.try_clone()` before it moves
```

Use the new owner:

```rok
use rok::std::env;
use rok::std::fs::File;

fn main() throws {
    let f = try File::create(env::temp_dir() / "notes.txt");
    let g = f;
    try g.write_all("hi");
    try g.close();
    println("written");
}
```

```output
written
```
