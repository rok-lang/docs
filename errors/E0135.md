# E0135: resource not closed

Closing this value can fail (its type implements `io::Close`), so it is not closed for you: on some path it leaves its scope, is replaced, or is dropped with an error that `try?` discards, while still open. Add `try x.close();` before it leaves, bind it with `using x = .. { .. }`, or catch the error and close what it holds.

```rok norun
use rok::std::env;
use rok::std::fs::File;

fn main() throws {
    let f = try File::create(env::temp_dir() / "notes.txt");
    try f.write_all("hi");
}
```

```text check=checks/E0135.rok
error[E0135]: `f` holds a `File` that is never closed
  --> main.rok:5:17
   |
 5 |     let f = try File::create(env::temp_dir() / "notes.txt");
   |                 ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
 6 |     try f.write_all("hi");
   |         ----------------- it is still open when it leaves here
   |
   = help: closing a `File` can fail, so it is not closed for you: add `try f.close();` before it leaves its scope, or bind it with `using f = .. { .. }`
```

Close it before it leaves its scope:

```rok
use rok::std::env;
use rok::std::fs::File;

fn main() throws {
    let f = try File::create(env::temp_dir() / "notes.txt");
    try f.write_all("hi");
    try f.close();
    println("written");
}
```

```output
written
```

A temporary that a call only borrows is the same: in `(try File::open(p)).read_to_str()` or `BufReader::new(try File::open(p)).lines()`, nothing owns the file after the call, so nothing closes it.

```rok norun
use rok::std::fs::File;
use rok::core::io::IoError;

fn whole(path: str) throws (IoError) -> str {
    try (try File::open(path)).read_to_str()
}
```

```text check=checks/E0135-temp.rok
error[E0135]: the `File` made here is never closed: this call only borrows it
  --> main.rok:5:14
   |
 5 |     try (try File::open(path)).read_to_str()
   |              ^^^^^^^^^^^^^^^^
   |
   = help: closing a `File` can fail, so it is not closed for you: bind it with `using` (`using x = .. { .. }`), or bind it and close it (`let x = ..; .. try x.close();`)
```

Bind it with `using`, which closes it when the block ends:

```rok
use rok::std::env;
use rok::std::fs;
use rok::std::fs::File;
use rok::std::process;
use rok::core::io::IoError;

fn whole(path: str) throws (IoError) -> str {
    using f = try File::open(path) { try f.read_to_str() }
}

fn main() throws (IoError) {
    let p = env::temp_dir() / f"rok_e0135_{process::id()}.txt";
    try fs::write(p, "hi");
    println(try whole(p.as_str()));
    try fs::remove_file(p);
}
```

```output
hi
```
