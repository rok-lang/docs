# E0137: thread-local value kept past `with`

A `ThreadLocal`'s `with` lends the value to its closure only for the call. The closure keeps it, returns it, hands it over or awaits with it, so it would outlive the call or move to another thread. Use it inside the closure, and take a `.clone()` or what you computed from it out instead.

```rok norun
use rok::std::thread;

static TL: thread::ThreadLocal<List<i32>> = thread::local(|| -> List<i32> { [1, 2, 3] });

let xs = TL.with(|l| l);
```

```text check=checks/E0137.rok
error[E0137]: this returns the value `with` lends out of its closure: the value is only lent to it
  --> main.rok:5:22
   |
 5 | let xs = TL.with(|l| l);
   |                      ^
   |
   = help: return a copy (`.clone()`) or what you computed from it, or take a `ThreadLocal`'s value out with `replace` / `take`
```

Return a copy:

```rok
use rok::std::thread;

static TL: thread::ThreadLocal<List<i32>> = thread::local(|| -> List<i32> { [1, 2, 3] });

let xs = TL.with(|l| l.clone());
xs.push(4);
println(f"{xs.len()}");
```

```output
4
```
