# E0139: `pub` function signature not written out

A `pub` or `pub(pkg)` function is called from other modules, so its signature is written out, not inferred from the body. Give every parameter a type, `x: i32` (or a type parameter, `fn f<T>(x: T)`, for any type). Without `->` it returns `()`; when the body gives a value, write its type, `-> i32`, as the fix-it shows. Trait impl methods take the trait's types and private functions keep inference.

```rok norun
pub fn double(x: i32) { x * 2 }

println(f"{double(4)}");
```

```text check=checks/E0139.rok
error[E0139]: `pub fn double` has no `->`, so it returns `()`, but its body gives `i32`
  --> main.rok:1:25
   |
 1 | pub fn double(x: i32) { x * 2 }
   |                         ^^^^^
   |
   = help: write `-> i32` before the body
```

Write the return type:

```rok
pub fn double(x: i32) -> i32 { x * 2 }

println(f"{double(4)}");
```

```output
8
```
