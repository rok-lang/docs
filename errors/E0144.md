# E0144: multi-axis index on a type indexed along one axis

An index with several parts and a slice among them (`m[1:, 0]`) gives one argument per axis. `List`, `Slice`, fixed arrays and `str` have one axis, so they take one part. Slice and index in separate brackets (`m[1:][0]`), or keep the data in an `Array<T, N>` (`rok::core::array::Array`), which takes axis arguments. A type of your own takes them by implementing `Index` over a tuple of `isize` and `rok::core::index::SliceArg`.

```rok norun
let xs = [10, 20, 30, 40];
let y = xs[1:, 0];
```

```text check=checks/E0144.rok
error[E0144]: `List<i64>` is indexed along one axis, but this index has 2 parts with a slice among them
  --> main.rok:2:9
   |
 2 | let y = xs[1:, 0];
   |         ^^^^^^^^^
   |
   = help: slice and index in separate brackets (`m[a:b][c]`), or keep the data in an `Array` (`rok::core::array::Array`), which takes `m[a:b, c]`
```

Slice first, then index the slice, or use an `Array`:

```rok
use rok::core::array::Array;

let xs = [10, 20, 30, 40];
let y = xs[1:][0];
let m: Array<i64, 2> = [[1, 2], [3, 4]];
println(f"{y} {m[1:, 0]:?}");
```

```output
20 [3]
```
