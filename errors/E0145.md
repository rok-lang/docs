# E0145: integer raised to a negative power

`b ** e` on an integer base gives an integer, so the exponent is a `u32`: `2 ** -1` would be `0.5`, which no integer holds. Raise a float (`2.0 ** -1.0`, or `(x as f64) ** -1.0`), or keep the exponent non-negative.

```rok norun
let half = 2 ** -1;
```

```text check=checks/E0145.rok
error[E0145]: `i64` to a negative power is a fraction, not an integer
  --> main.rok:1:17
   |
 1 | let half = 2 ** -1;
   |                 ^^
   |
   = help: raise a float instead: `2.0 ** -1.0`
```

Raise a float:

```rok
let half = 2.0 ** -1.0;
let n: i32 = 4;
println(f"{half} {(n as f64) ** -1.0}");
```

```output
0.5 0.25
```
