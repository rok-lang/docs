# E0146: named `some` type not defined by its module

`type X = some Tr;` is one concrete type, and the functions of X's module that return `X` (`fn make() -> X { .. }`) give it from their bodies. The module has none, they give different types, or one is generic. Add a function in that module that returns `X`, return the same type from every one (have the others call the first), or keep the type parameter out of it: a generic opaque result is written `fn f<T>(..) -> some Tr`.

```rok norun
type Evens = some Iterator<Item = i64>;

println("no evens yet");
```

```text check=checks/E0146.rok
error[E0146]: `Evens` has no defining function
  --> main.rok:1:1
   |
 1 | type Evens = some Iterator<Item = i64>;
   | ^^^^
   |
   = help: a function in this module that returns `Evens` gives its type: `fn make() -> Evens { .. }`
```

Add a function that returns it:

```rok
type Evens = some Iterator<Item = i64>;

fn evens(n: i64) -> Evens {
    (0..n).filter(|x| x % 2 == 0)
}

println(evens(7).count());
```

```output
4
```
