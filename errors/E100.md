# E100: cannot find a name

A value, type or trait is used, but no item or variable of that name is in scope. When a similar name exists, rokc suggests it; when an item of that name exists in another module, the help gives the `use` line that brings it in ([9.9.4](../spec/refs-lang/009-tools/909-debug-tools.html#994-diagnostics--error-messages)).

```rok norun
let count = 1;
println(f"{coun}");
```

```text check=checks/E100.rok
error[E100]: cannot find value `coun` in this scope
  --> main.rok:2:12
   |
 2 | println(f"{coun}");
   |            ^^^^
   |
   = help: did you mean `count`?
```

Fix the spelling, or import the item:

```rok
let count = 1;
println(f"{count}");
```

```output
1
```

The same code covers ``cannot find type `T` in this scope`` and ``cannot find trait `T` in this scope``. Assigning to a name that was never declared with `let` is [E200](E200.html), not E100.
