# E102: module, import or visibility error

Something about modules is wrong: an item is private to its module, a `use` names a path that does not exist, a named import collides with an item of the same name, or a `mod name;` has no file behind it.

Items are private to their module unless marked `pub` ([5.6 Visibility](../spec/refs-lang/005-modules/506-visibility.html)).

```rok norun
mod geo {
    fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```text check=checks/E102.rok
error[E102]: function `geo::area` is private to module `geo` and cannot be used from `<root>` (spec 5.6 - add `pub` to expose it)
  --> main.rok:4:12
   |
 4 | println(f"{geo::area(2, 3)}");
   |            ^^^^^^^^^^^^^^^
```

Add `pub`:

```rok
mod geo {
    pub fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```output
6
```

Other messages with this code: ``unresolved import: `a::b` does not exist`` ([5.5 use](../spec/refs-lang/005-modules/505-use.html)), an import that clashes with an item defined in the module (see [chapter 11](../learn/11-modules-packages.html)), and ``module `util` body not found at `util.rok` `` ([5.4 Modules](../spec/refs-lang/005-modules/504-modules.html)), whose help says to create the file or write `mod util { .. }`.
