# E200: type error

The program does not type-check. This is the most common code: a value of one type where another is expected, a call with the wrong arguments, a `match` that misses a case, an unsafe call outside `unsafe`, an assignment to a name never declared with `let`. Rok has no implicit numeric conversions, so `f64` is not accepted where `i32` is expected ([2.14 Casts and conversions](../spec/refs-lang/002-types/214-cast-and-conversion.html)).

```rok norun
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3.0)}");
```

```text check=checks/E200.rok
error[E200]: mismatched types: argument `x` of `half` expects `i32`, found `f64`
  --> main.rok:2:17
   |
 2 | println(f"{half(3.0)}");
   |                 ^^^
```

Pass an `i32`, or convert explicitly with `as`:

```rok
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3)}");
```

```output
1
```

Other messages with this code include ``non-exhaustive match on `Light`: `Light::Yellow` not covered`` ([3.12.5](../spec/refs-lang/003-expressions/312-match-expression.html#3125-exhaustiveness-checking)), ``mismatched types: `let n` expects `i32`, found `str` ``, `` `fn main`: must return `()` or `i32` `` ([4.16](../spec/refs-lang/004-functions/416-entry-point.html)) and `` `coutn` is not declared; a variable is created only by `let` `` ([5.1](../spec/refs-lang/005-modules/501-variable-declaration.html)). Most messages name the spec section of the rule they enforce.
