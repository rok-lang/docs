# E201: pattern

The spec reserves E201 for pattern and exhaustiveness errors ([9.9.4](../spec/refs-lang/009-tools/909-debug-tools.html#994-diagnostics--error-messages)), but rokc 0.1.6 does not emit it. A `match` that misses a case is reported as [E200](E200.html) (``non-exhaustive match on `T` ``).
