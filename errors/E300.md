# E300: attribute or meta error

An attribute, derive, meta block, `#[lang]`, `#[literal]`, `#[keyword]` or operator registration is used wrongly. A common case is an attribute name that is neither built in nor defined by a meta block in scope ([6.1.6 Unknown attributes](../spec/refs-lang/006-meta-system/601-attribute-syntax.html#616-unknown-attributes)).

```rok norun
#[inlin]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```text check=checks/E300.rok
error[E300]: unknown attribute `#[inlin]`: not built in and no meta block defines it (spec 6.1.6)
  --> main.rok:1:1
   |
 1 | #[inlin]
   | ^^
```

Spell the attribute as listed in [6.2 Built-in attributes](../spec/refs-lang/006-meta-system/602-built-in-attributes.html):

```rok
#[inline]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```output
4
```

Deriving a trait that cannot be derived is also E300: ``cannot derive `Frobnicate` for `P`: `Frobnicate` is not a derivable trait`` lists the derivable ones ([6.2.1](../spec/refs-lang/006-meta-system/602-built-in-attributes.html)).
