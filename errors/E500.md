# E500: unsupported in codegen

The program type-checked, but code generation met a construct it does not implement yet; the message starts with `unsupported in codegen:` and names it (a cast, an operator on some type, a `static` initializer). These are gaps in rokc, not mistakes in the program, and no small program is known to trigger one in rokc 0.1.5. If you hit it, please report it at [github.com/rok-lang/rok/issues](https://github.com/rok-lang/rok/issues) with the program.
