# E503: lint

A lint found something that compiles but is probably a mistake: an unused variable, dead code, a confusable identifier. Lints are warnings by default; they become errors with `deny` (in `rok.rokon`, with `-D` on the command line, or with `#[deny(..)]` in source). The last note names the lint and where its level was set ([6.2.9](../spec/refs-lang/006-meta-system/602-built-in-attributes.html#629-allow--deny--warn-lint-control)).

```rok norun
fn main() {
    let total = 10;
    let unused = 1;
    println(f"{total}");
}
```

```text check=checks/E503.rok
warning[E503]: unused variable `unused`
  --> main.rok:3:9
   |
 3 |     let unused = 1;
   |         ^^^^^^
   |
   = note: if this is intentional, prefix it with an underscore: `_unused`
   = note: `#[warn(unused_variables)]` on by default
```

Remove the variable, or prefix it with `_` if it is there on purpose:

```rok
fn main() {
    let total = 10;
    let _unused = 1;
    println(f"{total}");
}
```

```output
10
```

`rokc lint --list` prints every lint, its group and its default level. See [chapter 16](../learn/16-tools.html#rok-lint-and-rok-check) for setting levels.
