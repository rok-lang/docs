# E0001: 소스에 예상치 못한 문자

어떤 토큰도 시작하지 않는 문자가 소스에 있습니다. 떨어져 있는 `#`나 `$`, 첫 줄이 아닌 곳의 `#!` 줄 같은 것입니다. 지우거나 문자열이나 주석 안에 쓰세요.

```rok norun
let price = 5$;
```

```text check=checks/E0001.rok
error[E0001]: unexpected character(s) `$`
  --> main.rok:1:14
   |
 1 | let price = 5$;
   |              ^
```

문자를 지우거나 문자열 안에 넣으세요.

```rok
let price = 5;
println(f"${price}");
```

```output
$5
```
