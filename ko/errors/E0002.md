# E0002: 소스에 양방향 제어 문자

소스에 유니코드 양방향 제어 문자(U+202A~U+202E, U+2066~U+2069)가 있습니다. 이 문자들은 글자가 보이는 순서를 바꾸므로, 코드가 컴파일러가 보는 것과 다르게 읽힐 수 있습니다. 아래 예의 문자열 `"abcdef"`에는 `abc`와 `def` 사이에 이 문자가 숨어 있습니다. 문자열 안에서 이스케이프 `"\u{202E}"`로 쓰세요.

```text check=checks/E0002.rok
error[E0002]: bidirectional control character U+202E in source; write it as an escape (`\u{202E}`) instead
  --> main.rok:1:17
```

문자를 이스케이프로 쓰세요.

```rok
let label = "abc\u{202E}def";
println(f"{label.len()}");
```

```output
9
```
