# E0003: 잘못된 숫자 리터럴

숫자 리터럴의 형식이 잘못되었습니다. 진법에 없는 숫자(`0b2`), 두 숫자 사이가 아닌 곳의 `_`, 숫자 없는 지수, 십진수 앞의 `0`(`012`), 앞자리 숫자 없는 실수(`.5`), 종류가 맞지 않는 접미사(`1.5i32`)가 여기에 속합니다. 메시지가 제안하는 대로, 예를 들어 `0.5`, `1_000`, `0o12`처럼 쓰세요.

```rok norun
let mode = 0755;
```

```text check=checks/E0003.rok
error[E0003]: `0755`: a decimal literal can't start with `0`
  --> main.rok:1:12
   |
 1 | let mode = 0755;
   |            ^^^^
   |
   = help: write `0o755` for an octal number, or `755` for decimal
```

help가 말하는 대로, 여기서는 8진수로 쓰세요.

```rok
let mode = 0o755;
println(f"{mode}");
```

```output
493
```
