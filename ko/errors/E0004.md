# E0004: 타입의 범위를 벗어난 리터럴

리터럴이 타입에 맞지 않습니다. `300u8`, 부호 없는 타입이 와야 할 곳의 `-1`, `f32`에 너무 큰 실수가 그 예입니다. 더 넓은 타입(`300u16`)이나 들어맞는 값을 쓰거나, 크기 제한 없는 수에는 `int`를 쓰세요.

```rok norun
let b: u8 = 300;
```

```text check=checks/E0004.rok
error[E0004]: integer literal `300` out of range for `u8`
  --> main.rok:1:13
   |
 1 | let b: u8 = 300;
   |             ^^^
```

값이 들어가는 넓은 타입을 쓰세요.

```rok
let b: u16 = 300;
println(f"{b}");
```

```output
300
```
