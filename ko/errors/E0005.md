# E0005: 끝나지 않은 리터럴이나 주석

문자열, 문자, 바이트 문자열, f-string, raw 문자열, 블록 주석이 시작했지만 끝나지 않습니다. 닫는 따옴표나 `*/`를 붙이세요. raw 문자열은 연 만큼의 `#`로 닫습니다.

```rok norun
/* the greeting
println("hi");
```

```text check=checks/E0005.rok
error[E0005]: unterminated block comment
  --> main.rok:1:1
   |
 1 | /* the greeting
   | ^^^^^^^^^^^^^^^
```

주석을 닫으세요.

```rok
/* the greeting */
println("hi");
```

```output
hi
```
