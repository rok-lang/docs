# E0006: 리터럴 안의 잘못된 이스케이프

문자열이나 문자 리터럴의 `\` 이스케이프가 Rok이 모르는 것이거나, 바이트 문자열에 담을 수 없는 문자가 있습니다. 아는 이스케이프는 `\n`, `\r`, `\t`, `\0`, `\\`, `\'`, `\"`, `\xHH`, `\u{..}`입니다. 바이트 문자열은 ASCII만 담으므로 다른 바이트는 `\xHH`(최대 `\xFF`)로 쓰세요.

```rok norun
println("100\% done");
```

```text check=checks/E0006.rok
error[E0006]: unknown escape sequence `\%`
  --> main.rok:1:9
   |
 1 | println("100\% done");
   |         ^^^^^^^^^^^^
```

`%`는 이스케이프할 필요가 없습니다. 백슬래시 자체는 `\\`로 씁니다.

```rok
println("100% done");
```

```output
100% done
```
