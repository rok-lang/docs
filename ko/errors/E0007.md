# E0007: 문자 리터럴에는 문자 하나

`'..'` 리터럴은 유니코드 코드 포인트 정확히 하나를, `c'..'` 리터럴은 바이트 정확히 하나를 담습니다. 길이가 정해지지 않은 텍스트에는 문자열 `"ab"`를, ASCII가 아닌 바이트에는 `\xHH`를 쓰세요.

```rok norun
let c = 'ab';
```

```text check=checks/E0007.rok
error[E0007]: char literal must contain exactly one code point
  --> main.rok:1:9
   |
 1 | let c = 'ab';
   |         ^^^^
```

문자가 둘 이상이면 문자열을 쓰세요.

```rok
let s = "ab";
println(s);
```

```output
ab
```
