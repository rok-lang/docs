# E0008: 잘못된 f-string

f-string의 `{..}` 구멍 형식이 잘못되었습니다. `}` 없는 `{`, 짝 없는 `}`, 빈 `{}`, 형식 지정 안의 또 다른 형식 지정, `f""".."""` 밖에서 여러 줄에 걸친 구멍이 여기에 속합니다. 중괄호 자체는 `{{`나 `}}`로 쓰고, 구멍마다 값을 넣으세요: `f"{x}"`.

```rok norun
let n = 3;
println(f"n = {}");
```

```text check=checks/E0008.rok
error[E0008]: empty `{}` in f-string
  --> main.rok:2:15
   |
 2 | println(f"n = {}");
   |               ^
```

구멍에 값을 넣으세요.

```rok
let n = 3;
println(f"{n}");
```

```output
3
```
