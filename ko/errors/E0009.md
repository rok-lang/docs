# E0009: raw 식별자로 쓸 수 없는 이름

`r#name`은 키워드를 이름으로 쓸 수 있게 하지만, 몇몇 이름(`self`, `Self`, `crate`, `super`, `_`)은 이렇게 쓸 수 없습니다. 다른 이름을 고르세요.

```rok norun
let r#self = 1;
```

```text check=checks/E0009.rok
error[E0009]: `r#self` is not allowed: `self` can't be a raw identifier; write `self` or pick another name
  --> main.rok:1:5
   |
 1 | let r#self = 1;
   |     ^^^^^^
```

다른 이름을 고르세요.

```rok
let me = 1;
println(f"{me}");
```

```output
1
```
