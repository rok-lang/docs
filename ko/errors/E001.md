# E001: 어휘 에러

소스 텍스트를 토큰으로 나눌 수 없습니다. 끝나지 않는 문자열이나 주석, Rok이 정의하지 않은 이스케이프 시퀀스, 코드 포인트가 둘 이상인 문자 리터럴, 숫자가 없는 숫자 리터럴이 그런 경우입니다. 렉서는 다른 어떤 단계보다 먼저 돌므로 이 에러를 고치기 전에는 파일의 나머지를 검사하지 않습니다.

```rok norun
println("100\% done");
```

```text check=checks/E001.rok
error[E001]: unknown escape sequence `\%`
  --> main.rok:1:9
   |
 1 | println("100\% done");
   |         ^^^^^^^^^^^^
```

`%`는 이스케이프할 필요가 없습니다. Rok이 아는 이스케이프는 [1.7.1 이스케이프 시퀀스](../spec/refs-lang/001-lexical/107-string-literals.html#이스케이프-시퀀스)에 있습니다. 백슬래시 자체는 `\\`로 씁니다.

```rok
println("100% done");
```

```output
100% done
```

이 코드를 쓰는 다른 메시지로 `unterminated string literal`, `unterminated block comment`, `char literal must contain exactly one code point`, `missing digits in numeric literal`이 있습니다. [1. 어휘 구조](../spec/refs-lang/001-lexical/index.html)를 참고하세요.
