# E0010: 예상치 못한 토큰

파서가 기대한 것과 다른 것을 만났습니다. 빠진 `;`, `,`, `)`, `}`, 이름 자리의 키워드, 항목 자리의 식이 그 예입니다. 메시지가 무엇을 기대했는지 알려 주므로 그것을 쓰거나, 앞줄에 열어 두고 닫지 않은 것이 없는지 보세요.

```rok norun
let x = (1 + 2;
println(f"{x}");
```

```text check=checks/E0010.rok
error[E0010]: expected `)`, found `;`
  --> main.rok:1:15
   |
 1 | let x = (1 + 2;
   |         - unclosed delimiter
   |               ^ expected `)`
```

괄호를 닫으세요.

```rok
let x = (1 + 2);
println(f"{x}");
```

```output
3
```

`;`가 빠지면 ``expected `;` ``와 함께 ``help: add `;` at the end of the statement``가 나옵니다. 구분자를 열어 두고 닫지 않았으면 두 번째 표시가 그 위치를 가리킵니다.
