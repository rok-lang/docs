# E0012: 다른 언어의 구문

Rok에 없는 형태를 썼습니다. `c ? a : b` 연산자, `++` / `--`, `let mut`이 그렇습니다. 메시지가 Rok의 형태를 알려 줍니다: `if c { a } else { b }`, `x += 1`, 그리고 그냥 `let`(변수는 원래 바꿀 수 있습니다).

```rok norun
let mut n = 0;
```

```text check=checks/E0012.rok
error[E0012]: rok has no `let mut`: variables are mutable by default
  --> main.rok:1:5
   |
 1 | let mut n = 0;
   |     ^^^
   |
   = help: drop `mut`: `let n = ..;`
```

`mut`를 지우세요. 모든 변수에 대입할 수 있습니다.

```rok
let n = 0;
n += 1;
println(f"{n}");
```

```output
1
```
