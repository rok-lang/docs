# E0013: 블록 머리의 구조체 리터럴

`if`, `while`, `match`, `for`의 머리에서는 `{`가 본문을 열기 때문에, 그 자리의 구조체 리터럴은 잘못 읽힙니다. 리터럴을 괄호로 감싸세요: `if p == (Point { x: 0, y: 0 }) { .. }`.

```rok norun
struct P { x: i32; }

match P { x: 2 } {
    P { x } => println(f"{x}"),
}
```

```text check=checks/E0013.rok
error[E0013]: a struct literal can't start a block's head: its `{` would open the body
  --> main.rok:3:7
   |
 3 | match P { x: 2 } {
   |       ^^^^^^^^^^
   |
   = help: wrap the struct literal in parentheses: `(P { x: 2 })`
```

리터럴을 괄호로 감싸세요.

```rok
struct P { x: i32; }

match (P { x: 2 }) {
    P { x } => println(f"{x}"),
}
```

```output
2
```
