# E0014: 순서가 틀린 수식어

함수 수식어는 `unsafe async yield fn` 한 가지 순서로, 각각 한 번씩만 씁니다. `throws`는 반환 타입 앞에 옵니다: `fn f() throws -> T`. help가 보여 주는 대로 순서를 바꾸세요.

```rok norun
fn parse(s: str) -> i32 throws {
    0
}
```

```text check=checks/E0014.rok
error[E0014]: `throws` goes before the return type
  --> main.rok:1:25
   |
 1 | fn parse(s: str) -> i32 throws {
   |                         ^^^^^^
   |
   = help: write `fn parse(s: str) throws -> i32`
```

`throws`를 반환 타입 앞에 두세요.

```rok
fn parse(s: str) throws -> i32 {
    try s.parse::<i32>()
}
println(f"{try! parse("7")}");
```

```output
7
```
