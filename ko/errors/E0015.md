# E0015: 아무것도 설명하지 않는 문서 주석

문서 주석(`///`나 `/** */`)은 설명할 항목 바로 앞에 옵니다. 그 자리로 옮기거나 일반 주석(`//`)으로 바꾸세요.

```rok norun
fn f() {}
/// The answer.
```

```text check=checks/E0015.rok
error[E0015]: doc comment documents nothing: it must come before an item; use `//` for a plain comment
  --> main.rok:2:1
   |
 2 | /// The answer.
   | ^^^^^^^^^^^^^^^
```

문서 주석을 설명할 항목 위로 옮기세요.

```rok
/// The answer.
fn answer() -> i32 { 42 }
println(f"{answer()}");
```

```output
42
```
