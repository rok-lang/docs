# E0016: 의미 없는 자리의 가시성

아무것도 바꾸지 않는 곳에 `pub`을 썼습니다. 블록 안의 함수나 항목(그 블록 안에서만 보입니다), 그리고 열거형 variant(열거형의 가시성을 따릅니다)가 그렇습니다. 지우세요.

```rok norun
enum Color { pub Red, Blue }
```

```text check=checks/E0016.rok
error[E0016]: enum variants take the enum's visibility; remove the visibility keyword
  --> main.rok:1:14
   |
 1 | enum Color { pub Red, Blue }
   |              ^^^
```

variant에서 `pub`을 지우세요. variant를 보이게 하려면 열거형에 `pub`을 붙입니다.

```rok
#[derive(Debug)]
pub enum Color { Red, Blue }
println(f"{Color::Red:?}");
```

```output
Red
```
