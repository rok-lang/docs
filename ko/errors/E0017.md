# E0017: 잘못된 자리의 항목

항목이나 문장이 허용되지 않는 곳에 있습니다. `impl` 안의 `static`, `extern` 블록 밖의 `static mut`, 모듈 본문의 문장, 함수 안의 매크로 import가 그 예입니다. 메시지가 말하는 곳, 대개 모듈 최상위로 옮기세요.

```rok norun
mod inner {
    println("hi");
}
```

```text check=checks/E0017.rok
error[E0017]: expected an item in `mod inner`: module bodies are definitions-only; statements belong in `main.rok`
  --> main.rok:2:5
   |
 2 |     println("hi");
   |     ^^^^^^^
```

모듈 본문에는 정의만 둡니다. 문장은 함수 안에 넣으세요.

```rok
mod inner {
    pub fn hi() { println("hi"); }
}
inner::hi();
```

```output
hi
```
