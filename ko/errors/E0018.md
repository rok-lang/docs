# E0018: 최상위 문장의 `return`

프로그램의 최상위 문장은 함수가 아니므로 `return`이 돌아갈 곳이 없습니다. `process::exit(code)`로 프로그램을 끝내거나, `fn main() -> i32`을 쓰고 거기서 return하세요.

```rok norun
let args = 1;
if args > 0 { return; }
```

```text check=checks/E0018.rok
error[E0018]: `return` is not allowed in top-level statements; use `process::exit(code)` or an explicit `fn main() -> i32`
  --> main.rok:2:15
   |
 2 | if args > 0 { return; }
   |               ^^^^^^
```

`process::exit`로 프로그램을 끝내세요.

```rok
use rok::std::process;

let args = 1;
if args > 0 { process::exit(0); }
println("unreached");
```
