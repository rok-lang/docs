# E0019: 괄호가 필요한 연산자

어떤 연산자는 이어 쓸 수 없습니다: 방향이 섞인 비교(`a < b > c`), `a != b != c`, `x ∈ s == y`, `a..b..c`. 같은 방향의 비교는 이어 쓸 수 있습니다(`0 <= i < n`). 부분을 `&&`로 잇거나 괄호를 넣어 뜻을 밝히세요. (축이 하나인 타입에 여러 부분으로 된 인덱스 `xs[1:, 0]`을 쓰면 [E0144](E0144.html)입니다.)

```rok norun
let a = 1;
let b = 2;
println(f"{a < b > 0}");
```

```text check=checks/E0019.rok
error[E0019]: `<` and `>` cannot be chained
  --> main.rok:3:18
   |
 3 | println(f"{a < b > 0}");
   |                  ^
   |
   = help: a chain compares in one direction (`a < b <= c`, `a > b >= c`, `a == b == c`); write `a < b && b > c`
```

두 비교를 `&&`로 이으세요. 한 방향의 비교 사슬은 괜찮습니다.

```rok
let a = 1;
let b = 2;
println(f"{a < b && b > 0} {0 <= a < b}");
```

```output
true true
```

관련 코드: [E0010](E0010.html) 예상치 못한 토큰
