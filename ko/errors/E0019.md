# E0019: 괄호가 필요한 연산자

어떤 연산자는 이어 쓸 수 없습니다: `a == b == c`, `a..b..c`, `try? x ?? y`, 그리고 `,`로 인덱싱하면서 `:`로 슬라이스하는 `[..]` 하나. 괄호를 넣거나 대괄호를 나눠 뜻을 밝히세요.

```rok norun
let a = 1;
let b = 2;
println(f"{a < b < 3}");
```

```text check=checks/E0019.rok
error[E0019]: non-associative operator `<` cannot be chained (parenthesise to disambiguate)
  --> main.rok:3:18
   |
 3 | println(f"{a < b < 3}");
   |                  ^
```

비교를 둘로 나눠 쓰세요.

```rok
let a = 1;
let b = 2;
println(f"{a < b && b < 3}");
```

```output
true
```
