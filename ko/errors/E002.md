# E002: 구문 에러

토큰이 올바른 Rok 구문을 이루지 않습니다. 메시지는 파서가 무엇을 기대했고 대신 무엇을 만났는지 알려 줍니다. 닫히지 않은 구분자가 있으면 보조 표시가 그곳을 가리킵니다.

```rok norun
let x = (1 + 2;
println(f"{x}");
```

```text check=checks/E002.rok
error[E002]: expected `)`, found `;`
  --> main.rok:1:15
   |
 1 | let x = (1 + 2;
   |         - unclosed delimiter
   |               ^ expected `)`
```

괄호를 닫습니다.

```rok
let x = (1 + 2);
println(f"{x}");
```

```output
3
```

`;`가 빠지면 ``expected `;` ``와 `help: add `;` at the end of the statement`를 보고합니다. 한 블록에서 같은 이름을 두 번 정의하는 것 (`` `x` is defined twice in this block ``) 과 `#[keyword]`로 등록한 키워드를 이름으로 쓰는 것도 E002입니다.
