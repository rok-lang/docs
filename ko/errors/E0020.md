# E0020: 후행 클로저 안의 `return`

문장의 후행 클로저 안에서 그냥 `return`을 쓰면 둘러싼 함수가 아니라 클로저만 빠져나옵니다. 클로저는 `return@name`(`name`은 클로저를 받는 함수)으로 빠져나오고, 함수는 호출 뒤의 코드로 빠져나오세요.

```rok norun
fn each(xs: List<i32>, f: fn(i32) -> ()) { for x in xs { f(x); } }

fn main() {
    each([1, 2, 3]) |x| {
        if x == 2 { return; }
        println(f"{x}");
    }
}
```

```text check=checks/E0020.rok
error[E0020]: a bare `return` in a statement's trailing closure: it would leave only the closure, not the function
  --> main.rok:5:21
   |
 5 |         if x == 2 { return; }
   |                     ^^^^^^
   |
   = help: write `return@each` to end this call of the closure; to leave the function, write a `for` loop instead of the call
```

클로저를 받는 함수 이름을 붙인 `return@each`로 클로저를 빠져나오세요.

```rok
fn each(xs: List<i32>, f: fn(i32) -> ()) { for x in xs { f(x); } }

fn main() {
    each([1, 2, 3]) |x| {
        if x == 2 { return@each; }
        println(f"{x}");
    }
}
```

```output
1
3
```
