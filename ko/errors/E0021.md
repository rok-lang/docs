# E0021: 이름으로 쓴 예약어

키워드나 예약된 이름(`rok` 같은 경로 루트, `#[keyword]`로 등록한 키워드)을 이름으로 썼습니다. 다른 이름을 고르거나, 키워드를 이름으로 쓰려면 `r#name`으로 쓰세요.

```rok norun
let gen = 1;
```

```text check=checks/E0021.rok
error[E0021]: `gen` is a reserved keyword, not a name
  --> main.rok:1:5
   |
 1 | let gen = 1;
   |     ^^^
   |
   = help: write `r#gen` to keep this name, or rename it
```

이름을 유지하려면 `r#gen`으로 쓰고, 아니면 다른 이름을 고르세요.

```rok
let r#gen = 1;
println(f"{r#gen}");
```

```output
1
```
