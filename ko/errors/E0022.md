# E0022: 값 없는 `let`

모든 `let`은 변수에 값을 줍니다. 값을 쓰거나(`let n: i32 = 0;`), 옵셔널 타입으로 비워 두고 시작하세요: `let n: i32 | none = none;`.

```rok norun
let n: i32;
```

```text check=checks/E0022.rok
error[E0022]: `let n` needs a value
  --> main.rok:1:11
   |
 1 | let n: i32;
   |           ^
   |
   = help: give it one, `let n: i32 = ..;`, or start it empty: `let n: i32 | none = none;`
```

값으로 시작하거나, 옵셔널 타입과 `none`으로 시작하세요.

```rok
let n: i32 | none = none;
println(f"{n ?? 0}");
```

```output
0
```
