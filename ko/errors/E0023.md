# E0023: 잘못된 함수 시그니처

함수의 매개변수나 반환 타입이 규칙을 어깁니다. 마지막이 아닌 가변 인자 `...`, 코루틴이나 `fn` 값의 `ref` 매개변수, 던지는 매개변수가 없는 `rethrows`, 테스트 속성이 허용하지 않는 시그니처가 그 예입니다. 메시지가 규칙을 알려 주므로 그에 맞게 시그니처를 고치세요.

```rok norun
fn f(a: i32, ...) -> i32 { a }
```

```text check=checks/E0023.rok
error[E0023]: `f`: a C variadic `...` parameter is only allowed on a declaration in an `extern "C" { .. }` block
  --> main.rok:1:1
   |
 1 | fn f(a: i32, ...) -> i32 { a }
   | ^^
```

C 가변 인자는 `extern` 선언에만 씁니다. Rok 함수는 `...T`로 인자를 몇 개든 받습니다.

```rok
fn sum(xs: ...i32) -> i32 {
    let t = 0;
    for x in xs { t += x; }
    t
}
println(f"{sum(1, 2, 3)}");
```

```output
6
```
