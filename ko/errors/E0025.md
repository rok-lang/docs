# E0025: 지원하지 않는 ABI

`extern`이 Rok이 지원하지 않는 ABI를 쓰거나 ABI를 빠뜨렸습니다. `extern "C"`(플랫폼 시스템 호출에는 `"system"`)로 쓰세요.

```rok norun
extern "fastcall" {
    fn abs(x: i32) -> i32;
}
```

```text check=checks/E0025.rok
error[E0025]: unsupported ABI `"fastcall"` (`"C"`, `"system"`, or `"rok"` for the runtime)
  --> main.rok:1:1
   |
 1 | extern "fastcall" {
   | ^^^^^^
```

`"C"`로 쓰세요.

```rok
extern "C" {
    fn abs(x: i32) -> i32;
}
println(f"{unsafe { abs(-3) }}");
```

```output
3
```
