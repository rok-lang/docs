# E0026: 두 번 이상 정의한 이름

한 스코프의 두 항목이 같은 이름입니다. Rok에는 오버로딩이 없습니다. 하나의 이름을 바꾸거나, 인자 개수만 다른 함수라면 하나만 두고 뒤쪽 매개변수에 기본값을 주세요(`b: i32 = 0`).

```rok norun
fn area(w: i32) -> i32 { w * w }
fn area(w: i32, h: i32) -> i32 { w * h }
```

```text check=checks/E0026.rok
error[E0026]: function `area` is defined more than once
  --> main.rok:2:1
   |
 1 | fn area(w: i32) -> i32 { w * w }
   | -- first defined here
 2 | fn area(w: i32, h: i32) -> i32 { w * h }
   | ^^ defined again here
   |
   = help: rename one of them, e.g. `area2`; there is no overloading, so to take fewer arguments keep one and give its last parameters defaults, as in `b: i32 = 0`
```

함수를 하나만 두고 마지막 매개변수에 기본값을 주세요.

```rok
fn area(w: i32, h: i32 = 0) -> i32 { if h == 0 { w * w } else { w * h } }
println(f"{area(3)} {area(2, 5)}");
```

```output
9 10
```
