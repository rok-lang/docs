# E0027: 값이나 함수를 찾을 수 없음

이 이름의 값이나 함수가 스코프에 없습니다. 철자를 확인하고, `use`로 가져오거나(help가 그 이름의 항목을 보여 줍니다) 먼저 `let`으로 선언하세요.

```rok norun
let count = 1;
println(f"{coun}");
```

```text check=checks/E0027.rok
error[E0027]: cannot find value `coun` in this scope
  --> main.rok:2:12
   |
 2 | println(f"{coun}");
   |            ^^^^
   |
   = help: did you mean `count`?
```

철자를 고치거나 항목을 가져오세요.

```rok
let count = 1;
println(f"{count}");
```

```output
1
```

다른 모듈에 그 이름의 항목이 있으면 help가 그것을 가져오는 `use` 줄을 알려 줍니다. `let`으로 선언한 적 없는 이름에 대입하는 것은 [E0057](E0057.html)입니다.

관련 코드: [E0028](E0028.html) 타입이나 트레이트를 찾을 수 없음, [E0057](E0057.html) 잘못된 대입, [E0136](E0136.html) 메서드의 트레이트가 스코프에 없음
