# E0029: 열거형 variant를 찾을 수 없음

열거형에 이 이름의 variant가 없습니다. 열거형의 정의와 철자를 대조하세요.

```rok norun
enum Light { Red, Green }

let l = Light::Yellow;
```

```text check=checks/E0029.rok
error[E0029]: enum `Light` has no variant `Yellow`
  --> main.rok:3:9
   |
 3 | let l = Light::Yellow;
   |         ^^^^^^^^^^^^^
```

열거형에 있는 variant를 쓰거나, 열거형에 variant를 추가하세요.

```rok
#[derive(PartialEq)]
enum Light { Red, Green, Yellow }

let l = Light::Yellow;
println(f"{l == Light::Yellow}");
```

```output
true
```

관련 코드: [E0027](E0027.html) 값이나 함수를 찾을 수 없음, [E0103](E0103.html) variant처럼 보이는 바인딩
