# E0030: 풀리지 않는 import

`use`가 존재하지 않는 것을 가리킵니다. 경로를 확인하세요. 경로는 패키지(`crate::`), 의존성, `rok::` 중 하나에서 시작합니다.

```rok norun
use rok::std::fss;
```

```text check=checks/E0030.rok
error[E0030]: unresolved import: `rok::std::fss` does not exist
  --> main.rok:1:5
   |
 1 | use rok::std::fss;
   |     ^^^
```

경로를 고치세요.

```rok
use rok::std::fs;

println(f"{fs::exists("no-such-file")}");
```

```output
false
```

관련 코드: [E0027](E0027.html) 값이나 함수를 찾을 수 없음, [E0035](E0035.html) 모듈 파일 문제
