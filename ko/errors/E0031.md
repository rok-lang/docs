# E0031: 모호한 이름

여러 glob import(`use a::*;`)나 패키지가 이 이름을 제공하므로 어느 것인지 분명하지 않습니다. 원하는 것을 이름으로 가져오거나 경로를 쓰세요.

```rok norun
mod a { pub fn item() -> i32 { 1 } }
mod b { pub fn item() -> i32 { 2 } }
use a::*;
use b::*;
println(f"{item()}");
```

```text check=checks/E0031.rok
error[E0031]: name `item` is ambiguous in module `<root>` - multiple glob imports resolve it: a::item, b::item
  --> main.rok:5:12
   |
 5 | println(f"{item()}");
   |            ^^^^^^
```

원하는 것을 이름으로 가져오세요.

```rok
mod a { pub fn item() -> i32 { 1 } }
mod b { pub fn item() -> i32 { 2 } }
use a::item;
println(f"{item()}");
```

```output
1
```
