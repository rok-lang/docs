# E0033: 잘못된 재내보내기

`pub use`가 규칙을 어깁니다. 다시 내보내는 항목보다 넓거나, 매크로를 다시 내보내거나, 재내보내기가 순환합니다. 항목을 재내보내기만큼 보이게 하거나 재내보내기를 고치세요.

```rok norun
mod inner {
    fn helper() -> i32 { 1 }
}
pub use inner::helper;
```

```text check=checks/E0033.rok
error[E0033]: `inner::helper` is private but re-exported as `pub` - a re-export can't be wider than its item
  --> main.rok:4:9
   |
 4 | pub use inner::helper;
   |         ^^^^^
```

항목을 재내보내기만큼 보이게 하세요.

```rok
mod inner {
    pub fn helper() -> i32 { 1 }
}
pub use inner::helper;
println(f"{helper()}");
```

```output
1
```
