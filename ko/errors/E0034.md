# E0034: 비공개 항목

항목, 필드, 메서드가 다른 모듈에 비공개(또는 다른 패키지에서 `pub(pkg)`)라서 여기서 쓸 수 없습니다. 정의한 곳에서 `pub`을 붙이거나 공개 항목을 쓰세요.

```rok norun
mod geo {
    fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```text check=checks/E0034.rok
error[E0034]: function `geo::area` is private to module `geo` and cannot be used from `<root>` (add `pub` to expose it)
  --> main.rok:4:12
   |
 4 | println(f"{geo::area(2, 3)}");
   |            ^^^^^^^^^^^^^^^
```

`pub`을 붙이세요.

```rok
mod geo {
    pub fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```output
6
```

`pub`을 붙이지 않은 항목은 자기 모듈에 비공개입니다([5.6 가시성](../spec/refs-lang/005-modules/506-visibility.html)).
