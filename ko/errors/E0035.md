# E0035: 모듈 파일 문제

`mod name;`을 불러올 수 없습니다. 파일 `name.rok`이 없거나 읽을 수 없거나, 모듈을 두 번 선언했거나, 인라인 모듈이면서 파일이기도 합니다. 모듈 파일은 모듈 이름을 따르고(Rok에는 `mod.rok`이 없습니다) 선언하는 파일 옆에 둡니다.

```rok norun
mod geo;
```

```text check=checks/E0035.rok
error[E0035]: module `geo` body not found at `geo.rok`
   = help: create `geo.rok`, or write `mod geo { .. }` in place of `mod geo;`
```

`main.rok` 옆에 `geo.rok`을 만들거나, 모듈을 그 자리에 `mod geo { .. }`로 쓰세요([5.4 모듈](../spec/refs-lang/005-modules/504-modules.html)).

관련 코드: [E0030](E0030.html) 풀리지 않는 import, [E0036](E0036.html) 잘못된 프로그램 진입점
