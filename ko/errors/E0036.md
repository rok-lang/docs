# E0036: 잘못된 프로그램 진입점

프로그램은 `main.rok`의 최상위 문장이나 `fn main` 중 하나에서 시작하며, 둘 다일 수는 없습니다. 다른 파일에는 정의만 둡니다. `fn main`은 매개변수를 받지 않고, 제네릭이나 `unsafe`가 아니며, `()`나 `i32`를 반환합니다. `async`일 수 있고, `throws` `main`은 `()`를 반환합니다.

```rok norun
fn main(args: List<str>) {}
```

```text check=checks/E0036.rok
error[E0036]: `fn main`: takes no parameters; read arguments through `rok::std::env`
  --> main.rok:1:1
   |
 1 | fn main(args: List<str>) {}
   | ^^
```

인자는 `rok::std::env`로 읽으세요.

```rok
use rok::std::env;

fn main() {
    println(f"{env::args().len() > 0}");
}
```

```output
true
```

`fn main`이 다른 타입을 반환하는 경우(`` `fn main`: must return `()` or `i32` ``)도 E0036입니다([4.16](../spec/refs-lang/004-functions/416-entry-point.html)).

관련 코드: [E0018](E0018.html) 최상위 문장의 `return`, [E0023](E0023.html) 잘못된 함수 시그니처
