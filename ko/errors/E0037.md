# E0037: 잘못된 의존성

컴파일러에 준 의존성(`--extern`이나 표준 라이브러리 계층)이 이 빌드에 맞지 않습니다. 다른 이름이나 다른 툴체인으로 빌드되었거나, 여기서 쓸 수 없는 것입니다. 다시 빌드하거나 의존성 목록을 고치세요.

`rok`은 의존성을 같은 툴체인으로 빌드해 넘겨 주므로, 이 에러는 `rokc`를 직접 부르거나 툴체인을 바꾼 뒤 오래된 빌드 결과가 남았을 때 나옵니다. `rok clean` 뒤에 다시 빌드하거나, 의존성을 지금의 `rokc`로 다시 빌드하세요.

관련 코드: [E0030](E0030.html) 풀리지 않는 import, [E0125](E0125.html) 파일을 읽거나 쓸 수 없음
