# E0038: 중첩 함수와 이름이 같은 변수

같은 블록의 변수와 중첩 함수가 이름을 같이 씁니다. 중첩 함수는 블록 전체에서 보이므로 그 이름이 둘 다를 뜻하게 됩니다. 둘 중 하나의 이름을 바꾸세요.

```rok norun
fn main() {
    fn step(x: i32) -> i32 { x + 1 }
    let step = 2;
    println(f"{step}");
}
```

```text check=checks/E0038.rok
error[E0038]: `step` names both a variable and a nested function in this block
  --> main.rok:3:5
   |
 3 |     let step = 2;
   |     ^^^
   |
   = help: a nested function is seen in its whole block, so rename one of them: `let step2 = ..` or `fn step2(..)`
```

변수나 함수에 따로 이름을 주세요.

```rok
fn main() {
    fn step(x: i32) -> i32 { x + 1 }
    let steps = 2;
    println(f"{step(steps)}");
}
```

```output
3
```

변수 이름에 `let`을 한 번 더 쓰는 것은 괜찮습니다. 새 변수를 만듭니다([5.1.4](../spec/refs-lang/005-modules/501-variable-declaration.html#514-같은-스코프-안의-재선언)).
