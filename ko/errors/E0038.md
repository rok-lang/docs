# E0038: 두 번 선언한 지역 변수

`let`이 같은 스코프에 이미 선언된 이름을 다시 선언하거나, 변수와 중첩 함수가 이름을 같이 씁니다. Rok에서는 두 번째 `let`이 첫 번째를 가리지 않습니다. 대입(`x = ..`)하거나 새 이름을 고르세요.

```rok norun
let x = 1;
let x = 2;
```

```text check=checks/E0038.rok
error[E0038]: `x` is already declared in this scope, and rok does not let a second `let` hide it
  --> main.rok:2:1
   |
 2 | let x = 2;
   | ^^^
   |
   = help: to change its value write `x = 2;`, or give the new value its own name: `let x2 = 2;`
```

새 값을 대입하거나 새 이름을 주세요.

```rok
let x = 1;
x = 2;
println(f"{x}");
```

```output
2
```
