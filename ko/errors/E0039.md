# E0039: 바깥 지역 변수를 쓰는 중첩 항목

중첩된 `fn`, `struct`, `impl`은 둘러싼 함수의 지역 변수나 제네릭 매개변수를 쓸 수 없습니다. 값을 매개변수로 넘기거나, 캡처할 수 있는 클로저를 쓰세요.

```rok norun
fn wrap<T>(t: T) -> i32 {
    struct Holder { v: T; }
    0
}
```

```text check=checks/E0039.rok
error[E0039]: `Holder` is declared inside `wrap` and can't use `T`, a generic parameter of `wrap`; declare its own instead: `struct Holder<T>`
  --> main.rok:2:24
   |
 2 |     struct Holder { v: T; }
   |                        ^
```

중첩 항목에 자기 매개변수를 주거나, 함수 밖에 선언하세요.

```rok
struct Holder<T> { v: T; }

fn wrap<T>(t: T) -> Holder<T> {
    Holder { v: t }
}
println(f"{wrap(5).v}");
```

```output
5
```

중첩 `fn`이 둘러싼 함수의 지역 변수를 써도 같은 코드가 나옵니다. 클로저(`let add = |x: i32| x + base;`)는 지역 변수를 캡처할 수 있습니다.
