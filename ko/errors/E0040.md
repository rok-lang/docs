# E0040: 타입 불일치

어떤 타입의 값이 다른 타입을 기대하는 곳에 쓰였습니다. 인자, 타입을 적은 `let`, 반환값, 본문을 `;`로 끝내 값을 버린 함수의 값이 그 예입니다. 값을 변환하거나(`as i32`, `.to_str()`), 기대하는 타입을 바꾸거나, `;`를 지우세요.

```rok norun
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3.0)}");
```

```text check=checks/E0040.rok
error[E0040]: mismatched types: argument `x` of `half` expects `i32`, found `f64`
  --> main.rok:2:17
   |
 2 | println(f"{half(3.0)}");
   |                 ^^^
   |
   = help: convert it with `as`: `3.0 as i32`
```

`i32`를 넘기거나 `as`로 명시적으로 변환하세요.

```rok
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3)}");
```

```output
1
```

Rok에는 암묵적인 숫자 변환이 없으므로 `i32`를 기대하는 곳에 `f64`를 받지 않습니다([2.14 캐스트와 변환](../spec/refs-lang/002-types/214-cast-and-conversion.html)). 대부분의 메시지에는 대신 쓸 코드를 알려 주는 `help:` 줄이 붙습니다.
