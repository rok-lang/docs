# E0041: 타입이 다른 분기

`if`나 `match`의 분기, 또는 루프의 `break`들이 서로 다른 타입의 값을 냅니다. Rok은 이들을 위한 합 타입을 지어내지 않습니다. 자리에 합 타입을 적거나(`let v: i64 | str = if c { 1 } else { "a" };`) 분기의 타입을 맞추세요.

```rok norun
let c = true;
let v = if c { 1 } else { "one" };
```

```text check=checks/E0041.rok
error[E0041]: `if` branches have different types `i64` and `str` - rok does not infer a sum type; annotate the slot (`let v: i64 | str = if ...`)
  --> main.rok:2:9
   |
 2 | let v = if c { 1 } else { "one" };
   |         ^^^^^^^^^^^^^^^^^^^^^^^^^
```

변수에 합 타입을 적으세요.

```rok
let c = true;
let v: i64 | str = if c { 1 } else { "one" };
println(f"{v is i64}");
```

```output
true
```
