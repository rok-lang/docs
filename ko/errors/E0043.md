# E0043: 없는 필드

타입에 이 이름의 필드가 없습니다(또는 튜플에 이 인덱스의 원소가 없습니다). 타입의 정의와 철자를 대조하세요.

```rok norun
struct P { x: i32; y: i32; }

let p = P { x: 1, y: 2 };
println(f"{p.z}");
```

```text check=checks/E0043.rok
error[E0043]: struct `P` has no field `z`
  --> main.rok:4:12
   |
 4 | println(f"{p.z}");
   |            ^^^
   |
   = help: available fields: `x`, `y`
```

타입에 있는 필드를 쓰세요. help가 필드 목록을 보여 줍니다.

```rok
struct P { x: i32; y: i32; }

let p = P { x: 1, y: 2 };
println(f"{p.y}");
```

```output
2
```
