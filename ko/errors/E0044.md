# E0044: 리터럴에 빠진 필드

구조체나 variant 리터럴이 기본값 없는 필드를 빠뜨렸습니다. 모든 필드에 값을 주거나, 구조체에 기본값을 선언하세요(`n: i32 = 0`).

```rok norun
struct P { x: i32; y: i32; }

let p = P { x: 1 };
```

```text check=checks/E0044.rok
error[E0044]: struct `P` is missing field `y` and no default is declared
  --> main.rok:3:9
   |
 3 | let p = P { x: 1 };
   |         ^^^^^^^^^^
```

필드에 값을 주거나 구조체에 기본값을 선언하세요.

```rok
struct P { x: i32; y: i32 = 0; }

let p = P { x: 1 };
println(f"{p.y}");
```

```output
0
```
