# E0045: 두 번 준 필드

구조체 리터럴이 같은 필드를 두 번 씁니다. 하나를 지우세요.

```rok norun
struct P { x: i32 }

let p = P { x: 1, x: 2 };
```

```text check=checks/E0045.rok
error[E0045]: field `x` specified more than once in `P` literal
  --> main.rok:3:9
   |
 3 | let p = P { x: 1, x: 2 };
   |         ^^^^^^^^^^^^^^^^
```

필드는 한 번만 주세요.

```rok
struct P { x: i32 }

let p = P { x: 2 };
println(f"{p.x}");
```

```output
2
```
