# E0046: 없는 메서드나 연관 항목

타입에 이 이름의 메서드, 연관 함수, 연관 상수가 없거나, 이 타입들에 맞는 것이 없습니다. 철자, 그것을 제공하는 트레이트의 `use`, 그리고 바운드를 확인하세요.

```rok norun
let s = "rok";
println(s.size());
```

```text check=checks/E0046.rok
error[E0046]: no method `size` found for type `str`
  --> main.rok:2:9
   |
 2 | println(s.size());
   |         ^^^^^^^^
   |
   = help: did you mean `len`?
```

help가 제안하는 메서드를 쓰세요.

```rok
let s = "rok";
println(f"{s.len()}");
```

```output
3
```

다른 플랫폼에만 있는 메서드도 E0046이며, 어디에 있는지 알려 주는 note가 붙습니다([17장](../learn/17-conditional-compilation.html)). 가져오지 않은 트레이트의 메서드는 [E0136](E0136.html)입니다.
