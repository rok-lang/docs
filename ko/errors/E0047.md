# E0047: 잘못된 형태로 쓴 항목

항목을 그것에 없는 형태로 썼습니다. 연관 함수를 메서드처럼 부르기(`T::new()` 대신 `v.new()`), 호출 없이 메서드 이름만 쓰기, 튜플 구조체를 `{..}`로 또는 이름 있는 구조체를 `(..)`로 만들기, 타입을 값으로 쓰기가 그 예입니다. 메시지가 알려 주는 형태로 쓰세요.

```rok norun
struct P { a: i32; }
impl P { fn get(self) -> i32 { self.a } }

let p = P { a: 3 };
let f = p.get;
```

```text check=checks/E0047.rok
error[E0047]: `p.get` names a method without calling it; `.method` is not a function value
  --> main.rok:5:9
   |
 5 | let f = p.get;
   |         ^^^^^
   |
   = help: call it (`p.get(..)`), wrap it in a closure (`|..| p.get(..)`), or use the method path `P::get`
```

메서드를 호출하거나, 호출을 클로저로 감싸세요.

```rok
struct P { a: i32; }
impl P { fn get(self) -> i32 { self.a } }

let p = P { a: 3 };
let f = || p.get();
println(f"{f()}");
```

```output
3
```
