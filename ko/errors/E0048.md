# E0048: 인자 개수가 틀림

호출이 함수가 받는 것보다 많거나 적은 인자를 넘기거나, 기본값 없는 인자를 빠뜨렸습니다. 매개변수마다 한 번씩 넘기세요. 기본값 있는 매개변수는 빼도 됩니다.

```rok norun
fn add(a: i32, b: i32) -> i32 { a + b }
println(f"{add(1)}");
```

```text check=checks/E0048.rok
error[E0048]: missing argument `b` in call to `add`
  --> main.rok:2:12
   |
 2 | println(f"{add(1)}");
   |            ^^^^^^
   |
   = help: it is declared `add(a: i32, b: i32)`; pass `b` too
```

모든 매개변수를 넘기거나, 마지막 매개변수에 기본값을 주세요.

```rok
fn add(a: i32, b: i32 = 0) -> i32 { a + b }
println(f"{add(1)} {add(1, 2)}");
```

```output
1 3
```
