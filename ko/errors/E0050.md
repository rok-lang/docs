# E0050: `ref` 매개변수와 인자의 불일치

`ref` 매개변수는 `ref x`로 쓴 인자를 받으며, 그 인자는 변수나 변수의 필드를 가리킵니다. 일반 매개변수는 일반 인자를 받습니다. 한 호출에서 같은 변수를 두 `ref` 매개변수에 넘길 수 없습니다. 매개변수에 `ref`가 있는 곳에만 정확히 `ref`를 쓰세요.

```rok norun
fn inc(ref n: i32) { n += 1; }

let c = 0;
inc(c);
```

```text check=checks/E0050.rok
error[E0050]: parameter `n` of `inc` is `ref` - pass `ref c` at the call site
  --> main.rok:4:1
   |
 4 | inc(c);
   | ^^^^^^
```

호출에도 `ref`를 쓰세요.

```rok
fn inc(ref n: i32) { n += 1; }

let c = 0;
inc(ref c);
println(f"{c}");
```

```output
1
```
