# E0051: 잘못된 펼침 인자

`f(..x)`는 튜플, `List`, `Slice`, 배열, `Dict<str, V>`를 인자로 펼치며, 컴파일 시간에 알려진 피호출자가 필요합니다. 이 중 하나를 펼치거나 인자를 하나씩 넘기세요.

```rok norun
fn sum(xs: ...i32) -> i32 { 0 }

let n = 3;
println(f"{sum(..n)}");
```

```text check=checks/E0051.rok
error[E0051]: spread into a variadic `...T` needs a tuple, a `List`, a `Slice` or an array, found `i64`
  --> main.rok:4:12
   |
 4 | println(f"{sum(..n)}");
   |            ^^^^^^^^
```

컬렉션을 펼치세요.

```rok
fn sum(xs: ...i32) -> i32 {
    let t = 0;
    for x in xs { t += x; }
    t
}

let ns = [1, 2, 3];
println(f"{sum(..ns)}");
```

```output
6
```
