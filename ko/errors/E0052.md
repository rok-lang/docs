# E0052: 호출할 수 없는 값

함수, 클로저, `fn` 값만 호출할 수 있습니다. 이름이 같은 이름의 값이 아니라 함수를 가리키는지 확인하세요.

```rok norun
let total = 3;
println(f"{total(1)}");
```

```text check=checks/E0052.rok
error[E0052]: a value of type `i32` is not callable
  --> main.rok:2:12
   |
 2 | println(f"{total(1)}");
   |            ^^^^^^^^
```

함수나 클로저를 호출하세요.

```rok
let total = |x: i32| x + 3;
println(f"{total(1)}");
```

```output
4
```
