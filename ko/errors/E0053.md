# E0053: 잘못된 캐스트

`as`는 숫자, `bool`, `char` 사이를 변환하고, 페이로드 없는 열거형을 정수로 변환합니다. 다른 변환은 메서드입니다. `char`로는 `u8`만 캐스트할 수 있고(더 넓은 값에는 `char::from_u32(n)`), `bool`로는 아무것도 캐스트할 수 없습니다(비교하세요: `n != 0`). 메시지가 제안하는 변환 메서드를 쓰세요.

```rok norun
let n = 98u32;
let c = n as char;
```

```text check=checks/E0053.rok
error[E0053]: only `u8` can be cast as `char`, not `u32`; use `char::from_u32(n)` (`char | none`) for a wider value
  --> main.rok:2:9
   |
 2 | let c = n as char;
   |         ^^^^^^^^^
```

문자가 아닌 값에는 `none`을 주는 `char::from_u32`로 변환하세요.

```rok
let n = 98u32;
let c = char::from_u32(n) ?? '?';
println(f"{c}");
```

```output
b
```
