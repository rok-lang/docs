# E0054: 적용할 수 없는 연산자

연산자를 지원하지 않는 타입에 썼습니다. 직접 만든 타입에는 연산자의 트레이트를 구현하고(`impl ops::Add for Point`), 타입 매개변수에는 그 트레이트를 바운드로 추가하세요.

```rok norun
let a: i32 = 1;
let b: i64 = 2;
println(f"{a + b}");
```

```text check=checks/E0054.rok
error[E0054]: operator `+` cannot be applied to `i32` and `i64`
  --> main.rok:3:12
   |
 3 | println(f"{a + b}");
   |            ^^^^^
   |
   = help: rok never converts numbers implicitly; convert one side: `(a as i64) + b`
```

한쪽을 변환하세요. Rok은 숫자를 저절로 변환하지 않습니다.

```rok
let a: i32 = 1;
let b: i64 = 2;
println(f"{a as i64 + b}");
```

```output
3
```

타입 매개변수에서는 어떤 바운드가 빠졌는지 메시지가 알려 줍니다: ``operator `+` on `T` needs the bound `T: Add` ``([7장](../learn/07-generics.html)).

관련 코드: [E0040](E0040.html) 타입 불일치, [E0069](E0069.html) 트레이트 바운드를 만족하지 않음
