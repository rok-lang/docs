# E0055: 여러 타입에 맞는 리터럴

접미사 없는 리터럴이 호출이나 연산자가 받는 여러 타입 중 어느 것이든 될 수 있어서 타입이 분명하지 않습니다. 접미사(`1i64`)나 `as`를 붙이세요.

```rok norun
struct X { v: i64; }
impl From<i64> for X { fn from(x: i64) -> X { X { v: x } } }
impl From<u8> for X { fn from(x: u8) -> X { X { v: x as i64 } } }

let x = X::from(5);
```

```text check=checks/E0055.rok
error[E0055]: `X::from`: the literal fits several `From` impls of `X` (`i64`, `u8`); add a suffix or `as`
  --> main.rok:5:9
   |
 5 | let x = X::from(5);
   |         ^^^^^^^^^^
```

접미사를 붙이세요.

```rok
struct X { v: i64; }
impl From<i64> for X { fn from(x: i64) -> X { X { v: x } } }
impl From<u8> for X { fn from(x: u8) -> X { X { v: x as i64 } } }

let x = X::from(5i64);
println(f"{x.v}");
```

```output
5
```
