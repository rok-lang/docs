# E0056: 잘못된 인덱싱

값을 인덱싱할 수 없거나 인덱스가 정수가 아닙니다. 배열, 리스트, 슬라이스는 정수로, `Index`를 구현한 타입은 그 키로 인덱싱하세요.

```rok norun
let total = 120;
println(f"{total[0]}");
```

```text check=checks/E0056.rok
error[E0056]: cannot index into a value of type `i64`
  --> main.rok:2:12
   |
 2 | println(f"{total[0]}");
   |            ^^^^^^^^
```

컬렉션을 인덱싱하세요.

```rok
let totals = [120, 80];
println(f"{totals[0]}");
```

```output
120
```
