# E0057: 잘못된 대입

`=`의 왼쪽에 대입할 수 없습니다. 상수, static, `let`으로 선언하지 않은 변수, `[ref name]` 없이 클로저가 캡처한 값이 그 예입니다. `let` 변수나 그 필드, 원소에 대입하세요. 호출 결과처럼 왼쪽이 값이면 E0141입니다. 사본(값으로 받은 `self`나 매개변수, 클로저의 인자, `for` 바인딩, `xs[i]`를 받은 `let`)에 쓴 뒤 아무도 읽지 않는 필드는 바꾼 내용이 사라지므로 이것도 에러입니다. `ref self`나 `ref` 매개변수를 받거나, 클로저에서 인자를 돌려주고 그 결과를 쓰거나, `for ref x in xs`로 쓰거나, 원소를 다시 써 넣으세요.

```rok norun
let count = 0;
coutn = count + 1;
```

```text check=checks/E0057.rok
error[E0057]: `coutn` is not declared; a variable is created only by `let`
  --> main.rok:2:1
   |
 2 | coutn = count + 1;
   | ^^^^^
   |
   = help: did you mean `count`? To declare a new variable, write `let coutn = count + 1;`
```

선언한 변수에 대입하거나, `let`으로 새로 선언하세요.

```rok
let count = 0;
count = count + 1;
println(f"{count}");
```

```output
1
```

Rok에는 대입으로 하는 선언이 없습니다. 변수는 `let`으로만 만듭니다([5.1](../spec/refs-lang/005-modules/501-variable-declaration.html)). `(a, b) = (b, a);` 같은 분해 대입의 각 이름도 마찬가지입니다. 먼저 `let`으로 선언하거나 `let (a, b) = ..;`로 한꺼번에 선언하세요.

사본에 필드를 쓴 뒤 아무도 읽지 않는 것도 이 에러입니다. 바꾼 내용이 사라지기 때문입니다. struct는 값이므로 값으로 받은 `self`나 매개변수, 클로저의 인자(`m.with(|a| { a.n += 1; })`), `for` 바인딩, 원소의 `let`(`let q = xs[i];`)은 사본을 가집니다([2.3.8](../spec/refs-lang/002-types/203-struct.html#238-값-의미)).

```rok norun
struct Point { x: i32; y: i32; }

let ps = [Point { x: 1, y: 0 }, Point { x: 2, y: 0 }];
for p in ps { p.x = 7; }
```

```text check=checks/E0057-copy.rok
error[E0057]: `p.x` is set on a copy of the element, so `ps` does not change
  --> main.rok:4:15
   |
 4 | for p in ps { p.x = 7; }
   |               ^^^
   |
   = help: bind each element as a place with `for ref`: `for ref p in ps { p.x = 7; }`
```

`for ref`는 각 원소를 자리로 묶으므로 쓴 내용이 리스트에 닿습니다([3.13.3](../spec/refs-lang/003-expressions/313-loop-expressions.html#for-ref-원소를-자리로)). 메서드라면 `ref self`를, 매개변수라면 `ref p`를 받고, 클로저라면 인자를 돌려주고 그 결과를 쓰며, 원소의 `let`이라면 되씁니다(`xs[i] = q;`).

```rok
struct Point { x: i32; y: i32; }

let ps = [Point { x: 1, y: 0 }, Point { x: 2, y: 0 }];
for ref p in ps { p.x = 7; }
println(f"{ps[0].x} {ps[1].x}");
```

```output
7 7
```
