# E0057: 잘못된 대입

`=`의 왼쪽에 대입할 수 없습니다. 상수, static, `let`으로 선언하지 않은 변수, `[ref name]` 없이 클로저가 캡처한 값, 자리(place)가 아닌 식이 그 예입니다. `let` 변수나 그 필드, 원소에 대입하세요.

```rok norun
let count = 0;
coutn = count + 1;
```

```text check=checks/E0057.rok
error[E0057]: `coutn` is not declared; a variable is created only by `let`
  --> main.rok:2:1
   |
 2 | coutn = count + 1;
   | ^^^^^
   |
   = help: did you mean `count`? To declare a new variable, write `let coutn = count + 1;`
```

선언한 변수에 대입하거나, `let`으로 새로 선언하세요.

```rok
let count = 0;
count = count + 1;
println(f"{count}");
```

```output
1
```

Rok에는 대입으로 하는 선언이 없습니다. 변수는 `let`으로만 만듭니다([5.1](../spec/refs-lang/005-modules/501-variable-declaration.html)).

관련 코드: [E0027](E0027.html) 값이나 함수를 찾을 수 없음, [E0038](E0038.html) 두 번 선언한 지역 변수
