# E0058: 잘못된 클로저 캡처

클로저의 캡처 목록(`[ref x]`)이 캡처할 수 없는 것을 가리킵니다. 그 이름의 변수가 없거나, 다른 스레드에서 돌 수 있는 클로저의 `ref` 캡처입니다. `let` 변수나 매개변수를 캡처하고, 스레드 사이에서는 `Mutex`나 원자 타입으로 공유하세요.

```rok norun
let total = 0;
let add = [ref totl] |x: i32| { total += x; };
```

```text check=checks/E0058.rok
error[E0058]: `[ref totl]` names no variable in scope
  --> main.rok:2:11
   |
 2 | let add = [ref totl] |x: i32| { total += x; };
   |           ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
```

변수를 그 이름으로 캡처하세요.

```rok
let total = 0;
let add = [ref total] |x: i32| { total += x; };
add(2);
println(f"{total}");
```

```output
2
```
