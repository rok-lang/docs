# E0059: 맥락 밖의 키워드

`break`와 `continue`는 루프 안에서만, `yield`는 제너레이터 안에서만, `await`는 async 본문 안에서만, `self`는 메서드 안에서만 씁니다. `return`, `break`, `continue`로 `finally` 블록을 빠져나올 수 없습니다. `break value`는 `loop`나 레이블 붙은 블록에서만 빠져나오며, `while` / `for`에서는 쓸 수 없습니다. 코드를 그런 본문 안으로 옮기거나 `finally` 밖으로 빼세요.

```rok norun
let n = 3;
if n > 2 { break; }
```

```text check=checks/E0059.rok
error[E0059]: `break` outside of a loop
  --> main.rok:2:12
   |
 2 | if n > 2 { break; }
   |            ^^^^^
```

`break`는 루프 안에서 쓰세요.

```rok
for n in 0..5 {
    if n > 2 { break; }
    println(f"{n}");
}
```

```output
0
1
2
```

관련 코드: [E0018](E0018.html) 최상위 문장의 `return`, [E0060](E0060.html) 발산하지 않는 `let .. else`
