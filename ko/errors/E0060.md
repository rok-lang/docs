# E0060: 발산하지 않는 `let .. else`

`let .. else`의 `else` 블록은 패턴이 맞지 않을 때 돌므로 스코프를 떠나야 합니다. `return`, `break`, `continue`, `throw`로 끝내세요.

```rok norun
fn first(xs: List<i32>) -> i32 {
    let n: i32 = xs.first() else {
        println("empty");
    };
    n
}
```

```text check=checks/E0060.rok
error[E0060]: the `else` block of `let ... else` must diverge (end in `return`, `break`, `continue` or `throw`)
  --> main.rok:2:18
   |
 2 |     let n: i32 = xs.first() else {
   |                  ^^^^^^^^^^
```

`else` 블록에서 함수를 빠져나가세요.

```rok
fn first(xs: List<i32>) -> i32 {
    let n: i32 = xs.first() else {
        return 0;
    };
    n
}
println(f"{first([])} {first([4])}");
```

```output
0 4
```
