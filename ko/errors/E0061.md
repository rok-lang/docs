# E0061: `unsafe`가 필요한 연산

메모리 안전을 깰 수 있는 연산입니다. `unsafe` 함수나 C 함수 호출, union 필드 읽기, 검사 없는 `GcBuf` 인덱싱이 그렇습니다. `unsafe { .. }`로 감싸고, 그것이 다른 코드의 재료라면 `unsafe fn` 안에 두세요.

```rok norun
unsafe fn danger() -> i32 { 1 }
println(f"{danger()}");
```

```text check=checks/E0061.rok
error[E0061]: call to unsafe function `danger` outside an `unsafe` block or `unsafe fn` (C functions are implicitly unsafe)
  --> main.rok:2:12
   |
 2 | println(f"{danger()}");
   |            ^^^^^^^^
```

호출을 `unsafe { .. }`로 감싸세요.

```rok
unsafe fn danger() -> i32 { 1 }
println(f"{unsafe { danger() }}");
```

```output
1
```
