# E0062: 처리하지 않은 에러

호출이 에러를 던질 수 있는데, 그 에러를 잡지도 선언하지도 않았습니다. 호출에 `try`를 붙이고, 에러를 잡거나 둘러싼 함수의 `throws`에 추가하세요.

```rok norun
let n = "42".parse::<i32>();
```

```text check=checks/E0062.rok
error[E0062]: this call can throw `ParseError` and must be marked with `try` (`try f()`; `try? f()` / `try! f()` to drop / panic on the error)
  --> main.rok:1:9
   |
 1 | let n = "42".parse::<i32>();
   |         ^^^^^^^^^^^^^^^^^^^
```

호출에 `try`를 붙이고, 에러가 넘어가는 곳에 `throws`를 선언하세요.

```rok
fn main() throws {
    let n = try "42".parse::<i32>();
    println(f"{n}");
}
```

```output
42
```

`try? f()`는 에러를 `none`으로 바꾸고, `try! f()`는 에러에서 패닉합니다([10장](../learn/10-errors.html)).

관련 코드: [E0063](E0063.html) `Error`가 아닌 값을 던짐, [E0064](E0064.html) 옵셔널이 아닌 값의 옵셔널 연산자, [E0096](E0096.html) 아무것도 하지 않는 `try`나 `catch`
