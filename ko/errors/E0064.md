# E0064: 옵셔널이 아닌 값의 옵셔널 연산자

`?`, `??`, `?.`는 옵셔널 값(`T | none`)에, `try?` / `try!`는 던지는 호출에 씁니다. 일반 값에는 `.`를 쓰고, 에러를 넘기려면 `throws`와 `try`를 쓰세요.

```rok norun
let xs = [1, 2, 3];
let n = xs.len()?;
```

```text check=checks/E0064.rok
error[E0064]: `?` only works on `T | none`, found `usize` - to propagate errors use `throws` and `try`
  --> main.rok:2:9
   |
 2 | let n = xs.len()?;
   |         ^^^^^^^^^
```

값을 그대로 쓰세요.

```rok
let xs = [1, 2, 3];
let n = xs.len();
println(f"{n}");
```

```output
3
```
