# E0065: `using`으로 풀지 않은 잠금 가드

잠금 가드는 `using` 블록이 끝날 때에만 풀립니다. 가드를 `let` 대신 `using g = m.lock() { .. }`로 묶고, 버리지 마세요.

```rok norun
let m = Mutex::new(0);
let g = m.lock();
```

```text check=checks/E0065.rok
error[E0065]: `g` holds a `MutexGuard` that is never released: only `using` releases a lock guard, so bind it with `using g = .. { .. }`
  --> main.rok:2:1
   |
 2 | let g = m.lock();
   | ^^^
```

가드를 `using`으로 묶으세요.

```rok
let m = Mutex::new(0);
using g = m.lock() { g.set(g.get() + 1) }
using g = m.lock() { println(f"{g.get()}") }
```

```output
1
```
