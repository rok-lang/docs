# E0066: `Drop` 없는 값의 `using`

`using`은 블록 끝에서 자원을 해제하므로 자원의 타입이 `Drop`을 구현하거나 `Drop` 필드를 가져야 합니다. 다른 값에는 그냥 `let`을 쓰세요.

```rok norun
using n = 3 {
    println(f"{n}");
}
```

```text check=checks/E0066.rok
error[E0066]: `using` needs a resource whose type implements `Drop`; `i32` does not implement `Drop` nor hold a `Drop` field
  --> main.rok:1:7
   |
 1 | using n = 3 {
   |       ^
```

그냥 `let`을 쓰세요.

```rok
let n = 3;
println(f"{n}");
```

```output
3
```

관련 코드: [E0065](E0065.html) `using`으로 풀지 않은 잠금 가드, [E0092](E0092.html) 직접 부른 `Drop::drop`
