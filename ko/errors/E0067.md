# E0067: 값을 남기는 블록 문장

블록 같은 문장(`if`, `match`, 블록)이 값을 내지만 마지막 식이 아니고 `;`도 없습니다. `;`를 붙여 값을 버리거나 `let`으로 묶으세요.

```rok norun
fn pick(c: bool) -> i32 {
    if c { 1 } else { 2 }
    3
}
```

```text check=checks/E0067.rok
error[E0067]: this block-like statement leaves a value of type `i32` without `;`: a statement must be `()` (add `;` to discard it, or make it the block's last expression)
  --> main.rok:2:5
   |
 2 |     if c { 1 } else { 2 }
   |     ^^
```

`if`를 함수의 값으로 만들거나 `;`로 끝내세요.

```rok
fn pick(c: bool) -> i32 {
    if c { 1 } else { 2 }
}
println(f"{pick(true)}");
```

```output
1
```
