# E0068: 반복할 수 없는 값

`for`는 양쪽 끝이 있는 정수 범위, 배열, `IntoIterator`나 `Iterator`(`next`가 `T | none`을 반환)를 구현한 타입을 반복합니다. 이 중 하나를 반복하거나, 반복자를 주는 메서드를 부르세요.

```rok norun
struct Bag { n: i32; }

let b = Bag { n: 3 };
for x in b {
    println(f"{x}");
}
```

```text check=checks/E0068.rok
error[E0068]: cannot iterate over a value of type `Bag` - `for` needs an integer range, an array, an `IntoIterator` / `Iterator` impl, or a `TryIterator` (`try for`)
  --> main.rok:4:1
   |
 4 | for x in b {
   | ^^^^^^^^^^^^
```

범위, 컬렉션, 반복자를 반복하세요.

```rok
struct Bag { n: i32; }

let b = Bag { n: 3 };
for x in 0..b.n {
    println(f"{x}");
}
```

```output
0
1
2
```

관련 코드: [E0069](E0069.html) 트레이트 바운드를 만족하지 않음
