# E0069: 트레이트 바운드를 만족하지 않음

제네릭 매개변수, 연관 타입, 자리가 요구하는 트레이트를 타입이 구현하지 않습니다. 타입에 트레이트를 구현하거나, 그 트레이트가 있는 타입을 쓰세요.

```rok norun
fn keep<T: Clone>(x: T) -> T { x }
struct P { x: i32; }

println(f"{keep(P { x: 1 }).x}");
```

```text check=checks/E0069.rok
error[E0069]: type `P` does not satisfy trait bound `Clone` required by `keep`
  --> main.rok:4:12
   |
 4 | println(f"{keep(P { x: 1 }).x}");
   |            ^^^^^^^^^^^^^^^^
```

타입에 트레이트를 구현하세요. 여기서는 derive로 구현합니다.

```rok
fn keep<T: Clone>(x: T) -> T { x }
#[derive(Clone)]
struct P { x: i32; }

println(f"{keep(P { x: 1 }).x}");
```

```output
1
```

반복 리터럴 `[v; N]`은 `clone()`으로 원소마다 `v`의 복사본을 주므로, 컬렉션을 가진 원소 타입도 `Clone`이어야 합니다.

```rok norun
struct Bag { xs: List<i32>; }

let bags = [Bag { xs: [] }; 3];
```

```text check=checks/E0069-repeat.rok
error[E0069]: `[v; N]` copies `v` into each element with `clone()`, but `Bag` is not `Clone`
  --> main.rok:3:12
   |
 3 | let bags = [Bag { xs: [] }; 3];
   |            ^^^^^^^^^^^^^^^^^^^
   |
   = help: build each element on its own: `array::from_fn::<Bag, 3>(|_| ..)`
```

타입에 `Clone`을 derive하거나, 원소를 하나씩 따로 만드세요.

```rok
struct Bag { xs: List<i32>; }

let bags = array::from_fn::<Bag, 3>(|_| Bag { xs: [] });
bags[0].xs.push(1);
println(f"{bags.len()} {bags[0].xs:?} {bags[1].xs:?}");
```

```output
3 [1] []
```
