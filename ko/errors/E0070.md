# E0070: 트레이트가 아님

이 자리(`as` 뒤, `any` 바운드, `fn` 타입 바운드)에는 트레이트가 와야 하는데, 이름이 타입이거나 다른 것입니다. 트레이트 이름을 쓰세요.

```rok norun
struct Sq { side: f64; }
fn area(s: any Sq) -> f64 { 0.0 }
```

```text check=checks/E0070.rok
error[E0070]: `Sq` in `any Sq` is not a trait - `any` bounds must name traits
  --> main.rok:2:1
   |
 2 | fn area(s: any Sq) -> f64 { 0.0 }
   | ^^
```

트레이트 이름을 쓰세요.

```rok
trait Shape { fn area(self) -> f64; }
struct Sq { side: f64; }
impl Shape for Sq { fn area(self) -> f64 { self.side * self.side } }

fn area(s: any Shape) -> f64 { s.area() }
println(f"{area(Sq { side: 2.0 })}");
```

```output
4
```
