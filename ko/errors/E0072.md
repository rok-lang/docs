# E0072: impl에 빠진 트레이트 항목

트레이트 impl은 트레이트가 기본 구현 없이 선언한 메서드, 연관 타입, 연관 상수를 모두 정의해야 합니다. 빠진 항목을 추가하세요(`type Item = i32;`).

```rok norun
trait Shape {
    fn area(self) -> f64;
    fn name(self) -> str;
}
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
}
```

```text check=checks/E0072.rok
error[E0072]: impl of trait `Shape` for `Sq` is missing method `name`
  --> main.rok:6:1
   |
 6 | impl Shape for Sq {
   | ^^^^
```

빠진 메서드를 추가하세요.

```rok
trait Shape {
    fn area(self) -> f64;
    fn name(self) -> str;
}
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
    fn name(self) -> str { "square" }
}
println(Sq { s: 1.0 }.name());
```

```output
square
```

트레이트가 기본값 없이 선언한 연관 타입도 정해야 합니다. 도움말은 impl의 메서드가 그 자리에 쓴 타입을 알려 줍니다.

```rok norun
struct Count { n: i32; }
impl Iterator for Count {
    fn next(ref self) -> i32 | none {
        if self.n > 2 { return none; }
        self.n += 1;
        self.n
    }
}
```

```text check=checks/E0072-assoc.rok
error[E0072]: impl of `Iterator` for `Count` is missing associated type `Item`
  --> main.rok:2:1
   |
 2 | impl Iterator for Count {
   | ^^^^
   |
   = help: the trait declares `type Item` with no default: add `type Item = i32;` to the impl
```

연관 타입을 추가하세요.

```rok
struct Count { n: i32; }
impl Iterator for Count {
    type Item = i32;
    fn next(ref self) -> i32 | none {
        if self.n > 2 { return none; }
        self.n += 1;
        self.n
    }
}
for v in (Count { n: 0 }) { println(f"{v}"); }
```

```output
1
2
3
```
