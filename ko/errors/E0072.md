# E0072: impl에 빠진 트레이트 항목

트레이트 impl은 트레이트가 기본 구현 없이 선언한 메서드와 연관 상수를 모두 정의해야 합니다. 빠진 항목을 추가하세요.

```rok norun
trait Shape {
    fn area(self) -> f64;
    fn name(self) -> str;
}
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
}
```

```text check=checks/E0072.rok
error[E0072]: impl of trait `Shape` for `Sq` is missing method `name`
  --> main.rok:6:1
   |
 6 | impl Shape for Sq {
   | ^^^^
```

빠진 메서드를 추가하세요.

```rok
trait Shape {
    fn area(self) -> f64;
    fn name(self) -> str;
}
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
    fn name(self) -> str { "square" }
}
println(Sq { s: 1.0 }.name());
```

```output
square
```
