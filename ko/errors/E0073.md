# E0073: 트레이트에 없는 impl 항목

트레이트 impl이 트레이트가 선언하지 않은 메서드나 연관 타입을 정의합니다. 지우거나, 메서드라면 타입의 고유 `impl`로 옮기세요. 트레이트의 제네릭 매개변수는 연관 타입이 아닙니다. `type V = ..`가 아니라 헤더에 `impl IndexSet<usize, V> for T`처럼 쓰세요.

```rok norun
trait Shape { fn area(self) -> f64; }
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
    fn side(self) -> f64 { self.s }
}
```

```text check=checks/E0073.rok
error[E0073]: method `side` is not a member of trait `Shape`
  --> main.rok:3:1
   |
 3 | impl Shape for Sq {
   | ^^^^
```

메서드를 고유 `impl`로 옮기세요.

```rok
trait Shape { fn area(self) -> f64; }
struct Sq { s: f64; }
impl Shape for Sq {
    fn area(self) -> f64 { self.s * self.s }
}
impl Sq {
    fn side(self) -> f64 { self.s }
}
println(f"{Sq { s: 3.0 }.side()}");
```

```output
3
```
