# E0077: 구현하지 않은 상위 트레이트

트레이트가 다른 트레이트(상위 트레이트)를 요구하는데 타입이 그것을 구현하지 않습니다. 타입에 상위 트레이트도 구현하세요.

```rok norun
trait Base { fn id(self) -> i32; }
trait Named: Base { fn name(self) -> str; }
struct X {}
impl Named for X { fn name(self) -> str { "x" } }
```

```text check=checks/E0077.rok
error[E0077]: `X` implements `Named` but not its supertrait `Base`
  --> main.rok:4:1
   |
 4 | impl Named for X { fn name(self) -> str { "x" } }
   | ^^^^
```

상위 트레이트도 구현하세요.

```rok
trait Base { fn id(self) -> i32; }
trait Named: Base { fn name(self) -> str; }
struct X {}
impl Base for X { fn id(self) -> i32 { 1 } }
impl Named for X { fn name(self) -> str { "x" } }
println(f"{X {}.name()} {X {}.id()}");
```

```output
x 1
```
