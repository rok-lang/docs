# E0078: 허용되지 않는 impl

이 impl은 허용되지 않습니다. 타입 매개변수에 대한 고유 impl, `Reflect`의 수동 impl, 자동 트레이트(`Send`, `Sync`)도 `unsafe trait`도 아닌 트레이트의 `unsafe impl`, 자동 트레이트가 아닌 트레이트의 `impl !Trait`, `unsafe trait`의 평범한 `impl`이 그렇습니다. 지우거나 메시지가 알려 주는 형태로 쓰세요.

```rok norun
struct X { n: i32; }
impl Send for X {}
```

```text check=checks/E0078.rok
error[E0078]: `Send` is an auto trait the compiler derives from the fields; a manual impl for `X` must be `unsafe impl Send for X {}`
  --> main.rok:2:1
   |
 2 | impl Send for X {}
   | ^^^^
```

`Send`와 `Sync`는 필드에서 오므로, 필드가 모두 `Send`인 타입은 impl 없이도 `Send`입니다.

```rok
struct X { n: i32; }
fn needs_send<T: Send>(x: T) -> T { x }
println(f"{needs_send(X { n: 1 }).n}");
```

```output
1
```
