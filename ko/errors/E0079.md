# E0079: 컴파일 시간에 계산할 수 없음

상수, 배열 길이, const 제네릭 인자, `const fn` 본문이 컴파일 시간에 값이 없는 것을 씁니다. 일반 `fn` 호출, 힙 할당, 런타임 값이 그렇습니다. 리터럴, 다른 상수, `const fn` 호출을 쓰세요.

```rok norun
fn three() -> i32 { 3 }
const N: i32 = three();
```

```text check=checks/E0079.rok
error[E0079]: const `N` cannot be evaluated at compile time: calls `three`, which is not a `const fn`
  --> main.rok:2:16
   |
 2 | const N: i32 = three();
   |                ^^^^^^^
```

함수를 `const fn`으로 만드세요.

```rok
const fn three() -> i32 { 3 }
const N: i32 = three();
println(f"{N}");
```

```output
3
```
