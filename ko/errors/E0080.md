# E0080: 자기 자신에 의존하는 정의

상수, static, 타입 별칭이 직접 또는 다른 것을 거쳐 자기 자신으로 정의되었거나, 타입이 자기 자신을 값으로 담습니다. 순환을 끊으세요. 자기 자신을 담는 타입은 `List` 같은 참조 타입을 거쳐 담습니다.

```rok norun
struct Node { value: i32; next: Node; }
```

```text check=checks/E0080.rok
error[E0080]: recursive type `Node` has infinite size (a struct can't contain itself by value; hold it through a reference type such as `List`)
  --> main.rok:1:1
   |
 1 | struct Node { value: i32; next: Node; }
   | ^^^^^^
```

안쪽 값을 `List` 같은 참조 타입을 거쳐 담으세요.

```rok
struct Node { value: i32; next: List<Node>; }
let n = Node { value: 1, next: [] };
println(f"{n.value}");
```

```output
1
```
