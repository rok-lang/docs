# E0081: 잘못된 const 제네릭 인자

const 제네릭 인자의 타입이 틀렸거나 매개변수의 범위를 벗어났습니다. 매개변수 타입의 상수를 넘기세요.

```rok norun
struct Sep<const C: char> {}

let s = Sep::<97> {};
```

```text check=checks/E0081.rok
error[E0081]: const argument for `C: char` must be a `char`, found an integer
  --> main.rok:3:9
   |
 3 | let s = Sep::<97> {};
   |         ^^^^^^^^^^^^
```

매개변수 타입의 상수를 넘기세요.

```rok
struct Sep<const C: char> {}

let s = Sep::<'a'> {};
println("ok");
```

```output
ok
```
