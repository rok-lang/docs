# E0082: 잘못된 제네릭 인자

제네릭 항목에 타입 인자를 잘못된 개수로, 또는 정의에 맞지 않게 주었습니다. 매개변수마다 인자를 하나씩 넘기세요(기본값 있는 매개변수는 빼도 됩니다).

```rok norun
let xs: List<i32, str> = [];
```

```text check=checks/E0082.rok
error[E0082]: `List` takes 1 generic argument but 2 were given
  --> main.rok:1:9
   |
 1 | let xs: List<i32, str> = [];
   |         ^^^^
   |
   = help: `List` is declared `List<T>`; remove the last argument
```

매개변수마다 인자를 하나씩 넘기세요.

```rok
let xs: List<i32> = [];
println(f"{xs.len()}");
```

```output
0
```
