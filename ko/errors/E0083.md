# E0083: 잘못된 열거형 값

값 열거형(`V = n`)은 값 variant만 가지며, 각각 태그 타입에 맞는 서로 다른 상수를 가집니다. 메시지가 말하는 variant를 고치세요.

```rok norun
enum Code { Ok = 0, Bad = 0 }
```

```text check=checks/E0083.rok
error[E0083]: `Code::Bad` and `Code::Ok` have the same value 0
  --> main.rok:1:1
   |
 1 | enum Code { Ok = 0, Bad = 0 }
   | ^^^^
```

variant마다 다른 값을 주세요.

```rok
enum Code { Ok = 0, Bad = 1 }
println(f"{Code::Bad as i32}");
```

```output
1
```
