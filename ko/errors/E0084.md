# E0084: 잘못된 외부 함수 사용

C 함수, `extern` 선언, `extern "C" fn`이 FFI 규칙을 어깁니다. C가 담을 수 없는 타입(수집기가 옮길 수 있는 것), C 콜백으로 넘긴 클로저, 시그니처가 다른 두 선언, C가 받을 수 없는 가변 인자가 그 예입니다. C와 호환되는 타입을 넘기고, 콜백에는 이름 있는 함수를 넘기세요.

```rok norun
extern "C" {
    fn abs(x: i32) -> i32;
    fn abs(x: i64) -> i64;
}
```

```text check=checks/E0084.rok
error[E0084]: extern function `abs` is declared twice with different signatures: `fn(i64) -> i64` here, `fn(i32) -> i32` elsewhere
  --> main.rok:3:5
   |
 2 |     fn abs(x: i32) -> i32;
   |     -- declared as `fn(i32) -> i32` here
 3 |     fn abs(x: i64) -> i64;
   |     ^^
   |
   = help: a C symbol has one signature: declare `abs` as `fn(i32) -> i32` here too, or drop this declaration
```

C 함수는 C 시그니처로 한 번만 선언하세요.

```rok
extern "C" {
    fn abs(x: i32) -> i32;
    fn labs(x: i64) -> i64;
}
println(f"{unsafe { labs(-5) }}");
```

```output
5
```
