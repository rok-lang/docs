# E0087: 모호한 연관 항목

여러 트레이트, impl, 바운드가 이 이름의 메서드, 연관 타입, 상수를 주므로 `T::name`이 분명하지 않습니다. 트레이트를 밝히세요: `<T as Trait>::name`, 또는 메서드를 `Trait::name(x)`로 부르세요.

```rok norun
trait A { const N: i32; }
trait B { const N: i32; }
struct S {}
impl A for S { const N: i32 = 1; }
impl B for S { const N: i32 = 2; }

println(f"{S::N}");
```

```text check=checks/E0087.rok
error[E0087]: associated const `N` of `S` is ambiguous: `A` and `B` define it - name the trait (`<T as Tr>::N`)
  --> main.rok:7:12
   |
 7 | println(f"{S::N}");
   |            ^^^^
```

트레이트를 밝히세요.

```rok
trait A { const N: i32; }
trait B { const N: i32; }
struct S {}
impl A for S { const N: i32 = 1; }
impl B for S { const N: i32 = 2; }

println(f"{<S as B>::N}");
```

```output
2
```
