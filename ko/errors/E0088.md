# E0088: 잘못된 서식

f-string 구멍이 그 서식을 지원하지 않는 값을 서식화하거나(`{}`에는 `Display`, `{:?}`에는 `Debug`가 필요합니다), 서식 지정이 올바르지 않습니다. 트레이트를 구현하거나 derive하고, 아니면 서식 지정을 바꾸세요.

```rok norun
let name = "rok";
println(f"{name:x}");
```

```text check=checks/E0088.rok
error[E0088]: format type `x` needs an integer, found `str`
  --> main.rok:2:12
   |
 2 | println(f"{name:x}");
   |            ^^^^
```

값에 맞는 서식을 쓰세요.

```rok
let n = 255;
println(f"{n:x}");
```

```output
ff
```
