# E0089: 잘못된 컴파일러 내장 함수 호출

컴파일러 내장 함수(`size_of::<T>()`, `atomic_*`와 포인터 연산, `addr_of`, `GcBuf` 함수) 호출의 인자가 틀렸습니다. 자리가 필요한 곳의 값, 상수가 아닌 메모리 순서, 빠진 타입 인자가 그 예입니다. 메시지가 보여 주는 대로 부르세요.

```rok norun
use rok::bare::mem::size_of;

let n = size_of();
```

```text check=checks/E0089.rok
error[E0089]: `size_of` is called as `size_of::<T>()`
  --> main.rok:3:9
   |
 3 | let n = size_of();
   |         ^^^^^^^^^
```

타입 인자를 주세요.

```rok
use rok::bare::mem::size_of;

println(f"{size_of::<i64>()}");
```

```output
8
```
