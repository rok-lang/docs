# E0090: 잘못된 코루틴 사용

코루틴(`async`나 `yield`)이 규칙을 어깁니다. future가 아닌 것을 `await`하거나, 코루틴 프레임 안을 가리키는 포인터를 중단 지점 뒤에 썼습니다. future를 await하고, 포인터는 `await`나 `yield` 뒤에 다시 얻으세요.

흔한 원인은 `async`나 `yield` 본문 안에서 `addr_of`로 얻은 포인터를 `await`나 `yield` 뒤에 쓰는 것입니다. 프레임이 옮겨졌을 수 있으므로 중단 지점 뒤에 포인터를 다시 얻으세요. future가 아닌 값을 await하면 `await`에 `IntoFuture`가 필요하므로 대개 [E0069](E0069.html)가 나옵니다.
