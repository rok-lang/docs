# E0091: 잘못된 브로드캐스트

브로드캐스트 호출 `f.(xs)`는 `List`, `Slice`, 배열 위로 매핑하며, 함께 넘긴 배열들은 길이가 같아야 합니다. 길이가 맞는 컬렉션을 넘기세요. 점 식 하나는 core 컬렉션이나 `Broadcastable` 타입(`Array`) 중 한쪽만 받습니다. 리스트는 `Array::from_list(xs, [xs.len()])`로 배열로 바꿉니다. `.=` / `.+=` 등은 `List`, 고정 배열, `Array`(그 뷰 포함)에 쓰며 피연산자는 대상의 모양에 맞아야 합니다. `.??`에는 컨테이너 피연산자가 필요합니다.

```rok norun
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 4] = [10, 20, 30, 40];
println(f"{add.(xs, ys):?}");
```

```text check=checks/E0091.rok
error[E0091]: broadcast over arrays of lengths 3 and 4
  --> main.rok:5:12
   |
 5 | println(f"{add.(xs, ys):?}");
   |            ^^^^^^^^^^^^
```

길이가 같은 배열을 넘기세요.

```rok
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 3] = [10, 20, 30];
println(f"{add.(xs, ys):?}");
```

```output
[11, 22, 33]
```

같은 코드가 점 문법의 다른 잘못된 사용도 다루며, 각각 고치는 방법을 도움말로 적어 줍니다. 점 식 하나는 core 컬렉션(`List`, `Slice`, 고정 배열)이나 `Array` 같은 `Broadcastable` 타입 중 한쪽만 받습니다.

```rok
use rok::core::array::Array;

let xs = [1.0, 2.0];
let a = Array::from_list(xs, [xs.len()]);
let b: Array<f64, 1> = [10.0, 20.0];
println(f"{a .+ b:?}");
```

```output
[11.0, 22.0]
```

`.=`와 `.+=` 등은 `List`, 고정 배열, `Array`(그 뷰 포함)에 쓰며, 피연산자는 대상의 모양에 맞아야 합니다. `Slice`는 읽기 전용이고, 그 밖의 대상은 연산을 풀어 씁니다(`x = x .+ ..;`). `.??`에는 컨테이너 피연산자가 필요합니다. 값 하나라면 `x ?? y`를 씁니다.
