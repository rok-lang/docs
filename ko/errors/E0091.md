# E0091: 잘못된 브로드캐스트

브로드캐스트 호출 `f.(xs)`는 `List`, `Slice`, 배열 위로 매핑하며, 함께 넘긴 배열들은 길이가 같아야 합니다. 길이가 맞는 컬렉션을 넘기세요.

```rok norun
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 4] = [10, 20, 30, 40];
println(f"{add.(xs, ys):?}");
```

```text check=checks/E0091.rok
error[E0091]: broadcast over arrays of lengths 3 and 4
  --> main.rok:5:12
   |
 5 | println(f"{add.(xs, ys):?}");
   |            ^^^^^^^^^^^^
```

길이가 같은 배열을 넘기세요.

```rok
fn add(a: i32, b: i32) -> i32 { a + b }

let xs: [i32; 3] = [1, 2, 3];
let ys: [i32; 3] = [10, 20, 30];
println(f"{add.(xs, ys):?}");
```

```output
[11, 22, 33]
```
