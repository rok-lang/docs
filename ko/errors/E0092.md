# E0092: 직접 부른 `Drop::drop`

`drop`은 `using` 블록이 끝날 때 저절로 돌며, 다시 부르면 자원을 두 번 해제합니다. 일찍 해제하려면 `close()` 같은 메서드를 따로 두세요.

```rok norun
struct Conn { id: i32; }
impl Drop for Conn { fn drop(ref self) {} }

let c = Conn { id: 1 };
c.drop();
```

```text check=checks/E0092.rok
error[E0092]: `Drop::drop` cannot be called directly; it runs when a `using` block exits - expose a method such as `close()` to release early
  --> main.rok:5:1
   |
 5 | c.drop();
   | ^^^^^^^^
```

값의 해제는 `using`에 맡기세요.

```rok
struct Conn { id: i32; }
impl Drop for Conn { fn drop(ref self) { println(f"closed {self.id}"); } }

using c = (Conn { id: 1 }) {
    println(f"using {c.id}");
}
```

```output
using 1
closed 1
```

관련 코드: [E0066](E0066.html) `Drop` 없는 값의 `using`, [E0134](E0134.html) 옮기거나 닫은 뒤에 쓴 자원
