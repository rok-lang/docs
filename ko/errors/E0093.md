# E0093: 너무 깊은 제네릭 인스턴스화

제네릭 함수를 인스턴스화하자 점점 더 큰 타입으로 자기 자신을 인스턴스화하게 되었습니다. 예를 들어 `any` 매개변수로 재귀를 끊으세요.

```rok norun
fn nest<T>(x: T, n: i32) -> i32 {
    if n == 0 { return 0; }
    nest((x, x), n - 1)
}
println(f"{nest(1, 3)}");
```

```text check=checks/E0093.rok
error[E0093]: instantiating generic function `nest` recursed past the limit (depth 64) - the instantiation never reaches a fixed point
  --> main.rok:3:5
   |
 3 |     nest((x, x), n - 1)
   |     ^^^^^^^^^^^^^^^^^^^
```

타입 매개변수 대신 `any`로 아무 타입의 값을 받으세요.

```rok
fn nest(x: any Debug, n: i32) -> i32 {
    if n == 0 { return 0; }
    nest(x, n - 1)
}
println(f"{nest(1, 3)}");
```

```output
0
```
