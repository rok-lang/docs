# E0094: 잘못된 표현

`#[repr(..)]`나 `#[niche]`가 타입에 맞지 않습니다. 수집되는 참조를 담은 packed 구조체, `C`가 아닌 repr의 union, 필드가 둘 이상인 타입의 `#[niche]`가 그 예입니다. 속성이나 타입을 바꾸세요.

```rok norun
#[niche]
struct Pair { a: i32; b: i32; }
```

```text check=checks/E0094.rok
error[E0094]: `#[niche]` goes on a single-field struct, not a struct with 2 fields
  --> main.rok:1:1
   |
 1 | #[niche]
   | ^^
```

`#[niche]`는 필드가 정확히 하나인 구조체에 붙이거나 지우세요. `#[repr(packed)]` 구조체는 C 데이터만 담으며, `str`, 컬렉션, 클로저는 담지 않습니다.
