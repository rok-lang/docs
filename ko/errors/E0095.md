# E0095: 너무 큰 타입

값 타입이 컴파일러가 다룰 수 있는 것보다 큽니다. 큰 부분을 `List` 같은 참조 타입을 거쳐 담으세요.

```rok norun
struct W<T> { a: T; b: T; }

let x: W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<W<i64>>>>>>>>>>>>>>>>>>>>>>>>>>> = panic("unreachable");
```

   |                              ^

큰 부분을 참조 타입을 거쳐 담으세요. 안쪽 값들의 `List`나, 그것을 담는 직접 만든 구조체가 그렇습니다.
