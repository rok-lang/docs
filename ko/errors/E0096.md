# E0096: 아무것도 하지 않는 `try`나 `catch`

`try`가 던지는 호출을 하나도 덮지 않거나, `catch`에 닿는 에러가 없습니다. 지우세요.

```rok norun
let n = try 1 + 2;
println(f"{n}");
```

```text check=checks/E0096.rok
warning[E0096]: this `try` covers no throwing call
  --> main.rok:1:9
   |
 1 | let n = try 1 + 2;
   |         ^^^^^^^^^
```

`try`를 지우세요.

```rok
let n = 1 + 2;
println(f"{n}");
```

```output
3
```

이것은 경고이므로 프로그램은 그래도 빌드됩니다.
