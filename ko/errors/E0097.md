# E0097: 형태가 틀린 ROKON 값

ROKON 파일(`rok.rokon`, 설정 파일)이 파싱은 되지만, 값이 읽는 쪽이 기대하는 것과 맞지 않습니다. 빠진 필드, 타입이 틀린 값, 범위를 벗어난 수가 그 예입니다. 메시지가 말하는 값을 쓰세요.

이 `rok.rokon`은 `version`을 숫자로 줍니다.

```rokon
Package {
    name: "pk",
    version: 1,
}
```

`rok check`는 다음을 출력합니다.

```text
error[E0097]: `version` must be a string, found an integer
  --> rok.rokon:3:14
   |
 3 |     version: 1,
   |              ^
```

`version`을 문자열 `version: "0.1.0"`로 쓰세요. ROKON 형식은 [11장](../learn/11-modules-packages.html)에 있습니다.
