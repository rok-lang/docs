# E0098: 빠진 경우가 있는 match

`match`는 모든 값을 덮어야 합니다. 메시지가 나열하는 경우에 대한 arm이나 `_` arm을 추가하세요. 다른 패키지에서 `#[non_exhaustive]`로 표시한 열거형에는 언제나 `_`가 필요합니다.

```rok norun
enum Light { Red, Yellow, Green }

fn next(l: Light) -> Light {
    match l {
        Light::Red => Light::Green,
        Light::Green => Light::Yellow,
    }
}
```

```text check=checks/E0098.rok
error[E0098]: non-exhaustive match on `Light`: `Light::Yellow` not covered
  --> main.rok:4:5
   |
 4 |     match l {
   |     ^^^^^^^^^
   |
   = help: add `Light::Yellow => ..`
```

빠진 경우의 arm을 추가하세요.

```rok
#[derive(PartialEq)]
enum Light { Red, Yellow, Green }

fn next(l: Light) -> Light {
    match l {
        Light::Red => Light::Green,
        Light::Green => Light::Yellow,
        Light::Yellow => Light::Red,
    }
}
println(f"{next(Light::Yellow) == Light::Red}");
```

```output
true
```

[3.12.5](../spec/refs-lang/003-expressions/312-match-expression.html#3125-완전성-검사exhaustiveness)를 보세요.
