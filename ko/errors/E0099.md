# E0099: 닿지 않는 match arm

앞선 arm들이 이 arm이 맞추는 모든 값을 이미 맞추므로 이 arm은 돌지 않습니다. 지우거나, 그것을 덮는 arm 앞으로 옮기세요.

```rok norun
let n = 1;
let r = match n {
    _ => 0,
    1 => 1,
};
```

```text check=checks/E0099.rok
error[E0099]: unreachable match arm 2: earlier arms already match every value it matches
  --> main.rok:4:10
   |
 4 |     1 => 1,
   |          ^
```

모두 받는 arm을 마지막으로 옮기세요.

```rok
let n = 1;
let r = match n {
    1 => 1,
    _ => 0,
};
println(f"{r}");
```

```output
1
```
