# E0100: 값의 타입에 맞지 않는 패턴

패턴이 이 타입의 값에 맞을 수 없습니다. 다른 구조체의 구조체 패턴, 튜플이 아닌 값의 튜플 패턴, 반박 불가능한 패턴만 오는 곳(`let`, 매개변수, `for`)의 반박 가능한 패턴이 그 예입니다. 값의 타입에 맞는 패턴을 쓰고, 반박 가능한 패턴에는 `match`나 `let .. else`를 쓰세요.

```rok norun
let n = 5;
let (a, b) = n;
```

```text check=checks/E0100.rok
error[E0100]: tuple destructure of a non-tuple value of type `i64`
  --> main.rok:2:1
   |
 2 | let (a, b) = n;
   | ^^^
```

패턴 타입의 값을 분해하세요.

```rok
let pair = (5, 6);
let (a, b) = pair;
println(f"{a} {b}");
```

```output
5 6
```
