# E0101: 패턴의 필드 개수가 틀림

튜플이나 variant 패턴의 부분 개수가 값보다 많거나 적습니다. 부분마다 맞추거나, 나머지는 `..`로 쓰세요.

```rok norun
let t = (1, 2, 3);
let (a, b) = t;
```

```text check=checks/E0101.rok
error[E0101]: tuple destructure length mismatch: pattern has 2 elements, value has 3
  --> main.rok:2:1
   |
 2 | let (a, b) = t;
   | ^^^
```

부분마다 맞추거나 나머지를 `..`로 쓰세요.

```rok
let t = (1, 2, 3);
let (a, ..) = t;
println(f"{a}");
```

```output
1
```
