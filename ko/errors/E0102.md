# E0102: 다르게 묶는 or 패턴

`a | b`의 모든 대안은 같은 이름을 같은 타입으로 묶어야 합니다. 대안마다 같은 이름을 묶거나, 묶는 이름에 합 타입을 주세요.

```rok norun
enum Shape { Circle(f64), Square(f64), Point }

fn size(s: Shape) -> f64 {
    match s {
        Shape::Circle(r) | Shape::Point => r,
        Shape::Square(w) => w,
    }
}
```

```text check=checks/E0102.rok
error[E0102]: or-pattern alternatives bind different name sets (alternative 1: missing `r`)
  --> main.rok:4:5
   |
 4 |     match s {
   |     ^^^^^^^^^
```

대안마다 같은 이름을 묶으세요.

```rok
enum Shape { Circle(f64), Square(f64), Point }

fn size(s: Shape) -> f64 {
    match s {
        Shape::Circle(v) | Shape::Square(v) => v,
        Shape::Point => 0.0,
    }
}
println(f"{size(Shape::Square(2.0))}");
```

```output
2
```
