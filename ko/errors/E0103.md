# E0103: variant처럼 보이는 바인딩

패턴 안의 맨 이름은 모든 값에 맞는 새 변수입니다. 맞춰지는 열거형의 variant 이름과 정확히 같을 때만 예외입니다. 이 이름은 const나 static이거나 variant 이름과 비슷해서, 모든 것을 바인딩하게 됩니다. variant의 경로 `Color::Red`로 쓰거나, 가드에서 비교하세요: `x if x == LIMIT`.

```rok norun
const LIMIT: i32 = 10;

let n = 3;
match n {
    LIMIT => println("at the limit"),
    _ => println("below"),
}
```

```text check=checks/E0103.rok
error[E0103]: `LIMIT` here would be a new variable that matches every value, not the const `LIMIT`
  --> main.rok:5:5
   |
 5 |     LIMIT => println("at the limit"),
   |     ^^^^^
   |
   = help: to compare with the const, write `x if x == LIMIT`
```

가드에서 상수와 비교하세요.

```rok
const LIMIT: i32 = 10;

let n = 3;
match n {
    m if m == LIMIT => println("at the limit"),
    _ => println("below"),
}
```

```output
below
```
