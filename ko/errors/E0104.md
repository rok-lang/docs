# E0104: 잘못된 나머지 패턴

패턴에는 `..`가 많아야 하나이고, 나머지 패턴은 메시지가 말하는 자리에만 옵니다. 남는 `..`를 지우세요.

```rok norun
enum E { A(i32, i32, i32) }

let v = E::A(1, 2, 3);
match v {
    E::A(x, .., y, ..) => println(f"{x}"),
}
```

```text check=checks/E0104.rok
error[E0104]: pattern `E::A` has more than one `..`
  --> main.rok:4:1
   |
 4 | match v {
   | ^^^^^^^^^
```

`..`는 하나만 두세요.

```rok
enum E { A(i32, i32, i32) }

let v = E::A(1, 2, 3);
match v {
    E::A(x, .., y) => println(f"{x} {y}"),
}
```

```output
1 3
```
