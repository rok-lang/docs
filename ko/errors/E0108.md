# E0108: derive할 수 없음

`#[derive(..)]`가 이 타입에 트레이트를 구현할 수 없습니다. 필드가 그 트레이트를 구현하지 않거나, 다른 derive 트레이트도 필요하거나, derive가 지원하지 않는 종류의 타입입니다. 트레이트를 직접 구현하거나 메시지가 말하는 필드를 고치세요.

```rok norun
struct NoClone { n: i32; }
#[derive(Clone)]
struct Holder { n: NoClone; }
```

```text check=checks/E0108.rok
error[E0108]: cannot derive `Clone` for `Holder`: `n` has type `NoClone`, which does not implement `Clone`
  --> main.rok:2:1
   |
 2 | #[derive(Clone)]
   | ^^
```

필드 타입에도 트레이트를 derive하거나 직접 구현하세요.

```rok
#[derive(Clone)]
struct NoClone { n: i32; }
#[derive(Clone)]
struct Holder { n: NoClone; }
let h = Holder { n: NoClone { n: 1 } };
println(f"{h.clone().n.n}");
```

```output
1
```

`Display`처럼 아예 derive할 수 없는 트레이트도 E0108이며, 메시지가 이유를 알려 줍니다.
