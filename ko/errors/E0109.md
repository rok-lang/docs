# E0109: 잘못된 속성

속성의 인자가 그 속성이 받는 형태가 아니거나, Rok이 모르는 속성입니다. 메시지가 `#[path("file.rok")]` 같은 형태를 알려 줍니다.

```rok norun
#[inlin]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```text check=checks/E0109.rok
error[E0109]: unknown attribute `#[inlin]`: not built in and no meta block defines it
  --> main.rok:1:1
   |
 1 | #[inlin]
   | ^^
```

[6.2 내장 속성](../spec/refs-lang/006-meta-system/602-built-in-attributes.html)에 있는 대로 속성 이름을 쓰세요.

```rok
#[inline]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```output
4
```

내장도 아니고 스코프의 메타 블록이 정의하지도 않은 속성은 알 수 없는 속성입니다([6.1.6](../spec/refs-lang/006-meta-system/601-attribute-syntax.html)).
