# E0110: 잘못된 항목의 속성

속성이 이 종류의 항목에 적용되지 않습니다. 제네릭이거나 본문 없는 함수의 `#[export_name]`, `main`의 `#[track_caller]`, `#[cfg]`만 붙을 수 있는 문장에 붙인 속성이 그 예입니다. 적용되는 항목으로 옮기거나 지우세요.

```rok norun
#[link_name("abs")]
fn my_abs(x: i32) -> i32 { x }
```

```text check=checks/E0110.rok
error[E0110]: `#[link_name]` cannot be attached to a function; it goes on an extern function
  --> main.rok:1:1
   |
 1 | #[link_name("abs")]
   | ^^
```

속성을 `extern` 블록의 함수에 붙이세요.

```rok
extern "C" {
    #[link_name = "abs"]
    fn my_abs(x: i32) -> i32;
}
println(f"{unsafe { my_abs(-2) }}");
```

```output
2
```
