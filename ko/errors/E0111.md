# E0111: 잘못된 `#[lang]` 항목

`#[lang("slot")]`(표준 라이브러리 전용)은 알려진 슬롯을 한 번만, 그 슬롯의 형태를 가진 항목에 붙여 가리킵니다.

```rok norun
#[lang("add_trait")]
trait BadAdd { fn plus(self, o: Self) -> Self; }
```

```text check=checks/E0111.rok
error[E0111]: `BadAdd` does not match the form of lang slot `add_trait`: it needs `fn add(self, _)`
  --> main.rok:1:1
   |
 1 | #[lang("add_trait")]
   | ^^
```

`#[lang]`은 표준 라이브러리용입니다. 프로그램은 대신 표준 트레이트를 구현합니다. `impl ops::Add for Point`이면 `Point`에 `+` 연산자가 생깁니다.

관련 코드: [E0115](E0115.html) 잘못된 `#[intrinsic]`, [E0123](E0123.html) 두 번 등록함
