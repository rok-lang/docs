# E0112: 잘못된 연산자 선언

트레이트 메서드의 연산자 속성(`#[infix(..)]`, `#[prefix(..)]`, ..)이 규칙을 어깁니다. 연산자가 될 수 없는 토큰, 내장 토큰의 우선순위 지정, 서로 다른 수준의 별칭이 그 예입니다. 새 토큰은 `like = "<기존 토큰>"`으로 우선순위를 정합니다.

```rok norun
trait Before {
    #[infix(">>>", precedence = 3)]
    fn before(self, o: Self) -> bool;
}
```

```text check=checks/E0112.rok
error[E0112]: `#[infix]` takes only an operator token, `like = ".."` and `swap`: precedence and associativity are fixed by the language
  --> main.rok:2:5
   |
 2 |     #[infix(">>>", precedence = 3)]
   |     ^^
```

우선순위를 지우세요. 새 토큰은 `like`로 내장 토큰의 우선순위를 빌려 옵니다: `#[infix(">>>", like = ">>")]`([6.7](../spec/refs-lang/006-meta-system/607-operator-magic.html)).

관련 코드: [E0113](E0113.html) 잘못된 `#[keyword]` 선언, [E0123](E0123.html) 두 번 등록함
