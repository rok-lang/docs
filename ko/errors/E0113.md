# E0113: 잘못된 `#[keyword]` 선언

`#[keyword("name")]`은 처리기가 되는 자유 함수에 붙이며, `name`은 아직 키워드가 아닌 식별자입니다.

```rok norun
#[keyword("if")]
fn my_if(c: bool) -> bool { c }
```

```text check=checks/E0113.rok
error[E0113]: `#[keyword("if")]`: `if` is already a keyword
  --> main.rok:1:1
   |
 1 | #[keyword("if")]
   | ^^
```

`#[keyword("unless")]`처럼 아직 키워드가 아닌 이름을 고르세요.
