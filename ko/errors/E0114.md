# E0114: 잘못된 리터럴 처리기

`#[literal(..)]` 처리기는 그 종류가 받는 매개변수를 가진 함수여야 하며, 접미사, 우선순위, 반환 타입마다 한 번만 등록합니다. 접미사 붙은 리터럴에는 그 접미사의 처리기가 필요합니다.

```rok norun
let d = 5q;
```

```text check=checks/E0114.rok
error[E0114]: unknown numeric literal suffix `q` - no `#[literal(number "q")]` handler is registered
  --> main.rok:1:9
   |
 1 | let d = 5q;
   |         ^^
```

접미사의 처리기를 등록하세요. 리터럴은 그 처리기 호출이 됩니다([6.5](../spec/refs-lang/006-meta-system/605-literal-magic.html)).

```rok
#[literal(number "q")]
fn quarter(n: f64) -> f64 { n / 4.0 }

let d = 5q;
println(f"{d}");
```

```output
1.25
```

관련 코드: [E0003](E0003.html) 잘못된 숫자 리터럴, [E0123](E0123.html) 두 번 등록함
