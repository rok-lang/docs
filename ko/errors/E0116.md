# E0116: 잘못된 매크로 정의

매크로의 규칙 형식이 잘못되었습니다. 규칙은 `( matcher ) => { template }`이고, 메타변수는 `@name: fragment`, 반복은 `@rep[sep = ","] { .. }`입니다.

```rok norun
#[impl_macro(twice)] @macro {
    @e: expr => { (@e, @e) }
}
let p = twice!(3);
```

```text check=checks/E0116.rok
error[E0116]: a macro rule starts with `( matcher )`
  --> main.rok:2:5
   |
 2 |     @e: expr => { (@e, @e) }
   |     ^
```

matcher를 괄호로 감싸세요.

```rok
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!(3);
println(f"{p.0 + p.1}");
```

```output
6
```

[6.8.12 매크로 형식](../spec/refs-lang/006-meta-system/608-meta-blocks.html#6812-macro-형태)을 보세요.
