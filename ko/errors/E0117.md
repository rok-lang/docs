# E0117: 맞는 매크로 규칙이 없음

매크로의 어떤 규칙도 이 호출의 인자에 맞지 않습니다. 호출을 매크로의 matcher와 대조하세요.

```rok norun
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!();
```

```text check=checks/E0117.rok
error[E0117]: no rule of macro `twice!` matches this call
  --> main.rok:4:9
   |
 4 | let p = twice!();
   |         ^^^^^
```

규칙에 맞는 인자로 부르세요.

```rok
#[impl_macro(twice)] @macro {
    ( @e: expr ) => { { let v = @e; (v, v) } }
}
let p = twice!(3);
println(f"{p.0}");
```

```output
3
```
