# E0118: 잘못된 메타 템플릿

메타 블록의 템플릿이 `@` 토큰을 잘못 씁니다. 모르는 토큰, 필요한 `@for_fields`나 `@for_variants` 밖의 토큰, `(..)`나 `{ .. }`가 빠진 토큰이 그 예입니다. 메시지대로 쓰세요.

```rok norun
#[impl_derive(Names)] @derive {
    impl @Self {
        fn names() -> str { @fild }
    }
}
#[derive(Names)]
struct P { x: i32; }
```

```text check=checks/E0118.rok
error[E0118]: unknown template token `@fild`
  --> main.rok:3:29
   |
 3 |         fn names() -> str { @fild }
   |                             ^
 ...
 6 | #[derive(Names)]
   | -- in this `#[derive(Names)]`
```

[6.9 템플릿 토큰](../spec/refs-lang/006-meta-system/609-template-tokens.html)에 있는 대로 토큰을 쓰세요. 여기서는 `@for_fields { .. }` 블록 안의 `@field`입니다.
