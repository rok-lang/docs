# E0119: 잘못된 메타 블록

메타 블록의 정의나 사용이 규칙을 어깁니다. 내장 속성의 이름을 가져가거나, 다른 파일에 비공개이거나, 본문이 맞는 `@` 블록으로 시작하지 않거나, 항목이 아닌 것으로 펼쳐집니다. 메시지대로 정의나 사용을 고치세요.

```rok norun
#[impl_derive(Clone)] @derive {
    impl Clone for @Self {}
}
```

```text check=checks/E0119.rok
error[E0119]: `Clone` is a built-in derive; a meta block cannot redefine it
  --> main.rok:1:1
   |
 1 | #[impl_derive(Clone)] @derive {
   | ^^
```

`#[impl_derive(MyClone)]`처럼 derive에 고유한 이름을 주거나, 내장 `#[derive(Clone)]`을 쓰세요.
