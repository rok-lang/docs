# E0120: 재귀적인 펼침

매크로나 메타 블록이 직접 또는 다른 것을 거쳐 끝없이 자기 자신으로 펼쳐집니다. 순환을 끊으세요.

```rok norun
#[impl_macro(again)] @macro {
    ( @e: expr ) => { again!(@e) }
}
let x = again!(1);
```

```text check=checks/E0120.rok
error[E0120]: `again!` expands too deeply or cyclically
  --> main.rok:4:9
   |
 4 | let x = again!(1);
   |         ^^^^^
```

템플릿이 매크로를 다시 부르지 않는 코드로 펼쳐지게 하세요.

```rok
#[impl_macro(again)] @macro {
    ( @e: expr ) => { (@e, @e) }
}
let x = again!(1);
println(f"{x.0}");
```

```output
1
```
