# E0121: 잘못된 `cfg` 조건

`#[cfg(..)]`나 `cfg!(..)`의 조건 형식이 잘못되었습니다. 조건은 플래그(`unix`), `key = "value"` 쌍, 그리고 이것들의 `all(..)`, `any(..)`, `not(..)`입니다.

```rok norun
#[cfg(either(target_family = "unix", target_family = "windows"))]
println("desktop");
```

```text check=checks/E0121.rok
error[E0121]: unknown cfg combinator `either` (`all`, `any`, `not`)
  --> main.rok:1:1
   |
 1 | #[cfg(either(target_family = "unix", target_family = "windows"))]
   | ^^
```

`all`, `any`, `not`을 쓰세요.

```rok
#[cfg(any(target_family = "unix", target_family = "windows"))]
println("desktop");
```

```output
desktop
```

키 목록은 [17장](../learn/17-conditional-compilation.html)에 있습니다.
