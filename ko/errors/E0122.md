# E0122: 파일 포함 실패

`include_str!` / `include_bytes!`는 문자열 경로 하나를 받으며, 그 경로는 파일 기준의 상대 경로이고 읽을 수 있는 파일이어야 합니다.

```rok norun
let s = include_str!("missing.txt");
```

```text check=checks/E0122.rok
error[E0122]: `include_str!` cannot read "missing.txt": no such file
  --> main.rok:1:9
   |
 1 | let s = include_str!("missing.txt");
   |         ^^^^^^^^^^^
```

`main.rok` 옆에 `missing.txt`를 만들거나 경로를 고치세요. 경로는 `include_str!`이 있는 파일을 기준으로 합니다.
