# E0123: 두 번 등록함

심볼, 연산자, lang 슬롯, 키워드, 리터럴 처리기를 두 항목이 등록합니다. 하나만 두세요.

```rok norun
#[keyword("twice")]
fn twice_a(x: i32) -> i32 { x * 2 }
#[keyword("twice")]
fn twice_b(x: i32) -> i32 { x + x }
```

```text check=checks/E0123.rok
error[E0123]: keyword `twice` is registered twice
  --> main.rok:3:1
   |
 1 | #[keyword("twice")]
   | -- first registered here
 ...
 3 | #[keyword("twice")]
   | ^^
```

키워드는 한 번만 등록하세요.
