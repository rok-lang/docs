# E0127: 코드 생성 실패

코드 생성기(LLVM)가 실패했습니다. 대개 컴파일러 버그입니다. 원인이 된 코드와 함께 알려 주세요.

이 에러를 내는 작은 프로그램은 알려져 있지 않습니다. 네이티브 백엔드(`-C backend=native`, `-O0`의 기본값)로 빌드하면 넘어갈 수도 있습니다. 프로그램과 전체 출력을 [github.com/rok-lang/rok/issues](https://github.com/rok-lang/rok/issues)에 알려 주세요.

관련 코드: [E0131](E0131.html) 내부 컴파일러 에러, [E0130](E0130.html) 이 백엔드가 지원하지 않음
