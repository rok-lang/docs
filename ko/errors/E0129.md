# E0129: 잘못된 WIT

`ffi::wit::import { .. }`나 `ffi::wit::export { .. }`가 가리키는 `.wit` 파일을 읽거나, 파싱하거나, 해석할 수 없습니다. 메시지가 가리키는 곳에서 WIT 파일을 고치세요([stdlib 1.8](../spec/refs-standard-libraries/100-bare/108-wit.html)).

```rok norun
ffi::wit::import { "calc.wit" }
```

```text check=checks/E0129.rok
error[E0129]: WIT: calc.wit:0:0: cannot read: No such file or directory (os error 2)
  --> main.rok:1:1
   |
 1 | ffi::wit::import { "calc.wit" }
   | ^^^
```

WIT 파일을 만들거나 경로를 고치세요. 경로는 소스 파일 기준입니다. 파일이 있지만 파싱되지 않으면 메시지가 줄과 열을 알려 줍니다.

관련 코드: [E0084](E0084.html) 잘못된 외부 함수 사용, [E0125](E0125.html) 파일을 읽거나 쓸 수 없음
