# E0132: 린트

린트가 찾은 것입니다. 컴파일은 되지만 실수일 가능성이 큰 코드입니다. note가 린트 이름(`#[warn(name)]`, JSON의 `lint` 필드)을 알려 줍니다. 코드를 고치거나, `#[allow(name)]`이나 `-A name`으로 린트를 허용하세요. `rokc lint --list`가 모든 린트를 설명합니다.

```rok norun
fn main() {
    let total = 10;
    let unused = 1;
    println(f"{total}");
}
```

```text check=checks/E0132.rok
warning[E0132]: unused variable `unused`
  --> main.rok:3:9
   |
 3 |     let unused = 1;
   |         ^^^^^^
   |
   = note: if this is intentional, prefix it with an underscore: `_unused`
   = note: `#[warn(unused_variables)]` on by default
```

변수를 지우거나, 일부러 둔 것이면 이름 앞에 `_`를 붙이세요.

```rok
fn main() {
    let total = 10;
    let _unused = 1;
    println(f"{total}");
}
```

```output
10
```

모든 린트가 이 코드를 같이 씁니다. 린트는 기본으로 경고입니다. `rok.rokon`이나 명령줄의 `-D`, 소스의 `#[deny(..)]`에서 `deny`로 정하면 에러가 됩니다. 마지막 note는 린트 이름과 그 수준을 정한 곳을 알려 줍니다([6.2.9](../spec/refs-lang/006-meta-system/602-built-in-attributes.html#629-allow--deny--warn-린트-제어)). 수준을 정하는 방법은 [16장](../learn/16-tools.html)에 있습니다.
