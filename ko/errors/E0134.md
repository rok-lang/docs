# E0134: 옮기거나 닫은 뒤에 쓴 자원

타입이 `Drop`을 구현하는 값(`File`, 소켓, 채널의 `Sender`)은 소유자가 하나입니다. 다른 소유자에게 옮겨졌거나 닫혔는데, 여기서 다시 쓰거나, 옮기거나, 닫습니다. 새 소유자를 쓰거나, 닫기 전에 일을 마치거나, 옮기기 전에 `.clone()`으로 복사본을 두세요.

```rok norun
use rok::std::env;
use rok::std::fs::File;

fn main() throws {
    let f = try File::create(env::temp_dir() / "notes.txt");
    let g = f;
    try f.write_all("hi");
    try g.close();
}
```

```text check=checks/E0134.rok
error[E0134]: `f` was moved at line 6, and is used here
  --> main.rok:7:9
   |
 6 |     let g = f;
   |             - moved here
 7 |     try f.write_all("hi");
   |         ^
   |
   = help: a `File` has one owner, and `f` gave it away; use the new owner, or keep a copy with `.try_clone()` before it moves
```

새 소유자를 쓰세요.

```rok
use rok::std::env;
use rok::std::fs::File;

fn main() throws {
    let f = try File::create(env::temp_dir() / "notes.txt");
    let g = f;
    try g.write_all("hi");
    try g.close();
    println("written");
}
```

```output
written
```

옮겨 넣은 값(`[move x]`)을 가진 클로저도 같습니다. `thread::spawn`이나 `task::spawn_blocking`에 한 번 넘긴 뒤 다시 쓰면 이 에러입니다. `.clone()`을 옮겨 넣은 클로저를 하나 더 만들거나, 아무것도 옮겨 넣지 않는 `fn` 값이면 타입에 `+ Send + Sync`를 적어 다시 spawn할 수 있게 하세요.
