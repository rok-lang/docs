# E0136: 메서드의 트레이트가 스코프에 없음

메서드는 있지만 여기서 가져오지 않은 트레이트의 것이며, 트레이트의 메서드는 그 트레이트가 스코프에 있을 때에만 닿습니다. help가 보여 주는 대로 `use path::Trait;`을 추가하거나, `Trait::method(x, ..)`로 부르세요.

```rok norun
mod zoo {
    pub trait Wave { fn wave(self) -> str; }
    impl Wave for i32 { fn wave(self) -> str { "hi" } }
}

println(3.wave());
```

```text check=checks/E0136.rok
error[E0136]: method `wave` comes from trait `zoo::Wave`, which is not in scope
  --> main.rok:6:9
   |
 6 | println(3.wave());
   |         ^^^^^^^^
   |
   = help: add `use zoo::Wave;`
```

트레이트를 가져오세요.

```rok
mod zoo {
    pub trait Wave { fn wave(self) -> str; }
    impl Wave for i32 { fn wave(self) -> str { "hi" } }
}
use zoo::Wave;

println(3.wave());
```

```output
hi
```
