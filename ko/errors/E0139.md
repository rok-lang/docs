# E0139: 적어 두지 않은 `pub` 함수 시그니처

`pub`나 `pub(pkg)` 함수는 다른 모듈이 호출하므로, 시그니처를 본체에서 추론하지 않고 적어 둡니다. 매개변수마다 타입을 쓰세요. `x: i32`처럼 쓰거나, 어떤 타입이든 받으려면 타입 매개변수를 둡니다(`fn f<T>(x: T)`). `->`가 없으면 `()`를 반환합니다. 본체가 값을 내면 fix-it이 보여 주는 대로 그 타입을 `-> i32`처럼 쓰세요. 트레이트 impl 메서드는 트레이트의 타입을 따르고, 비공개 함수는 그대로 추론합니다.

```rok norun
pub fn double(x: i32) { x * 2 }

println(f"{double(4)}");
```

```text check=checks/E0139.rok
error[E0139]: `pub fn double` has no `->`, so it returns `()`, but its body gives `i32`
  --> main.rok:1:25
   |
 1 | pub fn double(x: i32) { x * 2 }
   |                         ^^^^^
   |
   = help: write `-> i32` before the body
```

반환 타입을 쓰세요.

```rok
pub fn double(x: i32) -> i32 { x * 2 }

println(f"{double(4)}");
```

```output
8
```
