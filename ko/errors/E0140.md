# E0140: 스트림보다 오래 쓴 스트림 뷰

`r.lines()`, `bytes`, `split`, `take`, 그 async 스트림, `incoming`은 `r`을 거쳐 읽으므로 `r`을 가진 쪽의 스코프 안에 머뭅니다. 그런 뷰를 반환했거나, 그 스코프 밖까지 저장했거나, 호출한 함수가 간직했거나, `r`을 닫거나 옮긴 뒤에 썼습니다. 스코프 안에서 쓰고 필요한 것을 모으거나(`try r.lines().collect()`), 소유하는 형태(`r.into_lines()`)를 쓰세요. 소유하는 형태는 `r`을 가지며, 자신이 닫힐 때 `r`도 닫고, 반환하거나 task로 옮길 수 있습니다.

```rok norun
use rok::std::fs::File;
use rok::core::io::{BufReader, IoError, Lines};

fn lines_of(path: str) throws (IoError) -> Lines<BufReader<File>> {
    using r = BufReader::new(try File::open(path)) {
        return r.lines();
    }
}
```

```text check=checks/E0140.rok
error[E0140]: this returns a view of `r` out of `r`'s scope
  --> main.rok:6:9
   |
 6 |         return r.lines();
   |         ^^^^^^
   |                --------- a view of `r` made here
   |
   = help: `r.lines()` reads through `r` and stays in its scope; use it there (`try r.lines().collect()`), or take the owning form `r.into_lines()`, which owns `r` and closes it with itself
```

소유하는 형태를 반환하세요. 이 값은 `io::Owned`로, 리더를 가지며 이것을 닫으면 리더도 닫힙니다.

```rok
use rok::std::env;
use rok::std::fs;
use rok::std::fs::File;
use rok::std::process;
use rok::core::io::{BufReader, IoError, Lines, Owned};

fn lines_of(path: str) throws (IoError) -> Owned<Lines<BufReader<File>>, BufReader<File>> {
    BufReader::new(try File::open(path)).into_lines()
}

fn main() throws (IoError) {
    let p = env::temp_dir() / f"rok_e0140_{process::id()}.txt";
    try fs::write(p, "one\ntwo\n");
    let ls = try lines_of(p.as_str());
    try for l in ls {
        println(l);
    }
    try ls.close();
    try fs::remove_file(p);
}
```

```output
one
two
```

`r`을 옮겨도 그 뷰는 끝납니다. `let kept = r;`, `r`을 값으로 넘기는 호출, `[move r]` 캡처, 구조체에 담기 뒤에는 그 전에 `r`에서 만든 뷰를 쓸 수 없습니다.

```rok norun
use rok::std::fs::File;
use rok::core::io::{BufReader, IoError};

fn count(path: str) throws (IoError) -> usize {
    let r = BufReader::new(try File::open(path));
    let ls = r.lines();
    let kept = r;
    let n = 0usize;
    try for l in ls { n += 1; }
    try kept.close();
    n
}
```

```text check=checks/E0140-moved.rok
error[E0140]: `ls` is a view of `r` (made at line 6), used after `r` was moved at line 7
  --> main.rok:9:18
   |
 6 |     let ls = r.lines();
   |              --------- a view of `r` made here
 7 |     let kept = r;
   |                - `r` moved here
 ...
 9 |     try for l in ls { n += 1; }
   |                  ^^
   |
   = help: `ls` reads through `r`, so it ends where `r` moves; finish with `ls` before moving `r`, or take the owning form `r.into_lines()` and move that instead
```

`r`을 옮기기 전에 뷰를 다 쓰거나, 소유하는 형태를 만들어 그것을 옮기세요.

```rok
use rok::std::env;
use rok::std::fs;
use rok::std::fs::File;
use rok::std::process;
use rok::core::io::{BufReader, IoError};

fn count(path: str) throws (IoError) -> usize {
    let r = BufReader::new(try File::open(path));
    let n = 0usize;
    try for l in r.lines() { n += 1; }
    let kept = r;
    try kept.close();
    n
}

fn main() throws (IoError) {
    let p = env::temp_dir() / f"rok_e0140m_{process::id()}.txt";
    try fs::write(p, "one\ntwo\n");
    println(f"{try count(p.as_str())}");
    try fs::remove_file(p);
}
```

```output
2
```
