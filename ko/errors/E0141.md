# E0141: 자리가 아닌 값에 대입

`=`나 복합 대입(`+=`, `-=`, ...)의 왼쪽이 자리(place)가 아니라 값입니다. 호출 결과(`f()`, `d.entry(k).or_insert(0)`), 연산자 결과, 튜플이 그 예입니다. 여기에 대입하면 곧 버려지는 임시 값만 바뀝니다. 변수나 그 필드(`s.x += 1`), 원소(`xs[i] += 1`)에 대입하세요. 호출 결과를 간직하려면 먼저 묶으세요: `let v = f(); v += 1;`. 딕셔너리로 세려면 기본값이 있는 인덱스를 쓰세요: `d[k, default: 0] += 1;`.

```rok norun
let counts = Dict::new();
for w in ["a", "b", "a"] {
    counts.entry(w).or_insert(0) += 1;
}
```

```text check=checks/E0141.rok
error[E0141]: cannot use `+=` on `counts.entry(w).or_insert(0)`: a call result is not a place, so the change would be lost
  --> main.rok:3:5
   |
 3 |     counts.entry(w).or_insert(0) += 1;
   |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
   |
   = help: index with a default: `counts[w, default: 0] += 1;`
```

`or_insert`는 딕셔너리 안의 칸이 아니라 개수 값을 돌려주므로 `+= 1`은 복사본에 더합니다. 항목을 읽은 다음 새 개수를 저장하세요.

```rok
let counts = Dict::new();
for w in ["a", "b", "a"] {
    counts[w, default: 0] += 1;
}
println(f"a={counts["a"]} b={counts["b"]}");
```

```output
a=2 b=1
```

호출 결과의 필드(`p().x += 1`)와 호출이 돌려준 고정 배열의 원소(`arr()[0] = 5`)도 같습니다. 값을 변수에 묶고 그 변수를 바꾸세요. 호출이 돌려준 `List`나 `Dict`의 원소는 컬렉션이 공유되므로 자리입니다. `rows()[0] += 1`은 `rows()`가 돌려준 리스트를 바꿉니다([3.4.1](../spec/refs-lang/003-expressions/304-assignment.html#341-단순-대입)).
