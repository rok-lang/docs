# E0142: impl의 것과 이름이 같은 메서드 제네릭 매개변수

`impl` 블록에 쓴 메서드가 impl의 매개변수와 같은 이름의 제네릭 매개변수를 선언했습니다. 메서드 안에서 그 이름은 둘 중 어느 것인지 모호하므로 에러입니다.

```rok norun
struct Wrap<K> { k: K; }

impl<K> Wrap<K> {
    fn pick<K>(self, x: K) -> K { x }
}
```

```text check=checks/E0142.rok
error[E0142]: generic parameter `K` of `pick` is already a parameter of its `impl`
  --> main.rok:4:5
   |
 4 |     fn pick<K>(self, x: K) -> K { x }
   |     ^^
   |
   = help: rename the method's (`fn pick<K2>`), or drop it to use the impl's `K`
```

메서드의 매개변수에 다른 이름을 주세요.

```rok
struct Wrap<K> { k: K; }

impl<K> Wrap<K> {
    fn pick<U>(self, x: U) -> U { x }
}

println(Wrap { k: "s" }.pick(5));
```

```output
5
```

트레잇의 기본 메서드는 impl이 아니라 트레잇에 쓰므로, 그 매개변수는 구현하는 impl의 같은 이름 매개변수를 에러 없이 가립니다([2.10.1](../spec/refs-lang/002-types/210-generics.html#2101-매개변수-선언-위치)).
