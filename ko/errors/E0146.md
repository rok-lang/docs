# E0146: 모듈이 정의하지 않은 이름 있는 `some` 타입

`type X = some Tr;`은 구체 타입 하나이고, X의 모듈에서 `X`를 반환하는 함수(`fn make() -> X { .. }`)가 본문으로 그 타입을 정합니다. 모듈에 그런 함수가 없거나, 함수들이 서로 다른 타입을 내거나, 하나가 제네릭입니다. 그 모듈에 `X`를 반환하는 함수를 두거나, 모든 함수가 같은 타입을 반환하게 하거나(나머지는 첫 함수를 부르게), 타입 매개변수를 빼세요. 제네릭한 불투명 결과는 `fn f<T>(..) -> some Tr`로 씁니다.

```rok norun
type Evens = some Iterator<Item = i64>;

println("no evens yet");
```

```text check=checks/E0146.rok
error[E0146]: `Evens` has no defining function
  --> main.rok:1:1
   |
 1 | type Evens = some Iterator<Item = i64>;
   | ^^^^
   |
   = help: a function in this module that returns `Evens` gives its type: `fn make() -> Evens { .. }`
```

그 타입을 반환하는 함수를 두세요.

```rok
type Evens = some Iterator<Item = i64>;

fn evens(n: i64) -> Evens {
    (0..n).filter(|x| x % 2 == 0)
}

println(evens(7).count());
```

```output
4
```
