# E0147: 구체 타입으로 쓴 이름 있는 `some` 타입

`type X = some Tr;`을 선언한 모듈 밖에서 `X`는 `Tr`만 가진 따로인 타입입니다. 구체 타입은 이름 붙일 수 없고, 다른 타입의 값은 `X`가 아닙니다. 값은 `X`로 두고(필드, `let x: X`, `List<X>`, 매개변수 모두 담을 수 있음) `Tr`로 쓰며, 새 값은 X의 모듈 함수에서 얻으세요. 구체 타입이 필요한 코드는 그 모듈에 둡니다.

```rok norun
mod shapes {
    pub type Count = some Display;

    pub fn count() -> Count { 3 }
}

let n: i64 = shapes::count();
```

```text check=checks/E0147.rok
error[E0147]: mismatched types: `let n` expects `i64`, found `Count`: outside `shapes`, `Count` is opaque
  --> main.rok:7:14
   |
 7 | let n: i64 = shapes::count();
   |              ^^^^^^^^^^^^^^^
   |
   = help: only `shapes` sees what `Count` is: keep the value as `Count` and use it through its bounds, get one from `shapes::count`, or move this code into `shapes`
```

`Count`로 두세요.

```rok
mod shapes {
    pub type Count = some Display;

    pub fn count() -> Count { 3 }
}

let n: shapes::Count = shapes::count();
println(f"{n} shapes");
```

```output
3 shapes
```

관련: [E0040](E0040.html) 타입 불일치, [E0146](E0146.html) 모듈이 정의하지 않은 이름 있는 `some` 타입
