# E100: 이름을 찾을 수 없음

값, 타입, 트레잇을 쓰지만 그 이름의 항목이나 변수가 스코프에 없습니다. 비슷한 이름이 있으면 rokc가 그것을 제안합니다. 다른 모듈에 그 이름의 항목이 있으면 help가 그것을 들여오는 `use` 줄을 알려 줍니다 ([9.9.4](../spec/refs-lang/009-tools/909-debug-tools.html#994-진단--에러-메시지)).

```rok norun
let count = 1;
println(f"{coun}");
```

```text check=checks/E100.rok
error[E100]: cannot find value `coun` in this scope
  --> main.rok:2:12
   |
 2 | println(f"{coun}");
   |            ^^^^
   |
   = help: did you mean `count`?
```

철자를 고치거나 항목을 가져옵니다.

```rok
let count = 1;
println(f"{count}");
```

```output
1
```

``cannot find type `T` in this scope``와 ``cannot find trait `T` in this scope``도 같은 코드입니다. `let`으로 선언한 적 없는 이름에 대입하는 것은 E100이 아니라 [E200](E200.html)입니다.
