# E102: 모듈, 가져오기, 가시성 에러

모듈 쪽에 문제가 있습니다. 항목이 그 모듈의 비공개 항목인 경우, `use`가 없는 경로를 가리키는 경우, 이름을 지정한 가져오기가 같은 이름의 항목과 충돌하는 경우, `mod name;`에 해당하는 파일이 없는 경우입니다.

항목은 `pub`을 붙이지 않으면 그 모듈의 비공개 항목입니다([5.6 가시성](../spec/refs-lang/005-modules/506-visibility.html)).

```rok norun
mod geo {
    fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```text check=checks/E102.rok
error[E102]: function `geo::area` is private to module `geo` and cannot be used from `<root>` (spec 5.6 - add `pub` to expose it)
  --> main.rok:4:12
   |
 4 | println(f"{geo::area(2, 3)}");
   |            ^^^^^^^^^^^^^^^
```

`pub`을 붙이세요.

```rok
mod geo {
    pub fn area(w: i32, h: i32) -> i32 { w * h }
}
println(f"{geo::area(2, 3)}");
```

```output
6
```

이 코드를 쓰는 다른 메시지로 ``unresolved import: `a::b` does not exist`` ([5.5 use](../spec/refs-lang/005-modules/505-use.html)), 모듈에 정의된 항목과 부딪치는 가져오기([11장](../learn/11-modules-packages.html) 참고), ``module `util` body not found at `util.rok` `` ([5.4 모듈](../spec/refs-lang/005-modules/504-modules.html))가 있습니다. 마지막 메시지의 help는 파일을 만들거나 `mod util { .. }`을 쓰라고 알려 줍니다.
