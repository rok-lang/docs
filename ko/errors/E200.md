# E200: 타입 에러

프로그램이 타입 검사를 통과하지 못합니다. 가장 흔한 코드입니다. 다른 타입을 기대하는 곳에 온 값, 인자가 틀린 호출, 경우를 빠뜨린 `match`, `unsafe` 밖의 unsafe 호출, `let`으로 선언한 적 없는 이름에 대한 대입이 여기에 듭니다. Rok에는 암묵적인 숫자 변환이 없으므로 `i32`를 기대하는 곳에 `f64`를 받지 않습니다 ([2.14 캐스트와 변환](../spec/refs-lang/002-types/214-cast-and-conversion.html)).

```rok norun
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3.0)}");
```

```text check=checks/E200.rok
error[E200]: mismatched types: argument `x` of `half` expects `i32`, found `f64`
  --> main.rok:2:17
   |
 2 | println(f"{half(3.0)}");
   |                 ^^^
```

`i32`를 넘기거나 `as`로 명시적으로 변환합니다.

```rok
fn half(x: i32) -> i32 { x / 2 }
println(f"{half(3)}");
```

```output
1
```

이 코드를 쓰는 다른 메시지로 ``non-exhaustive match on `Light`: `Light::Yellow` not covered`` ([3.12.5](../spec/refs-lang/003-expressions/312-match-expression.html#3125-완전성-검사-exhaustiveness)), ``mismatched types: `let n` expects `i32`, found `str` ``, `` `fn main`: must return `()` or `i32` `` ([4.16](../spec/refs-lang/004-functions/416-entry-point.html)), `` `coutn` is not declared; a variable is created only by `let` `` ([5.1](../spec/refs-lang/005-modules/501-variable-declaration.html))가 있습니다. 대부분의 메시지는 자신이 적용하는 규칙의 명세 절을 밝힙니다.
