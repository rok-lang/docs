# E202: 넘긴 뒤의 사용

다른 소유자에게 넘긴 값을 그 뒤에 썼습니다. `Mutex::new(xs)`, `RwLock::new(xs)`, `tx.send(xs)`, `task::spawn`은 `xs`를 다른 스레드가 닿을 수 있는 무언가에 넘깁니다. Rok에는 move 의미론이 없으므로 `xs`는 여전히 같은 객체를 가리킵니다. 그 뒤에 쓰면 새 소유자와 경쟁하게 됩니다. 이 검사는 복사, 필드, 컬렉션 원소, 클로저 캡처, 호출을 따라갑니다 ([stdlib 2.13.9](../spec/refs-standard-libraries/200-core/213-marker.html#2139-send--sync---스레드-경계-marker)).

```rok norun
let xs = [1, 2, 3];
let m = Mutex::new(xs);
xs.push(4);
```

```text check=checks/E202.rok
error[E202]: `xs` was moved into the `Mutex` at line 2
  --> main.rok:3:1
   |
 2 | let m = Mutex::new(xs);
   |         -------------- `xs` moved into the `Mutex` here
 3 | xs.push(4);
   | ^^
   |
   = help: it belongs to the `Mutex` now; use it through the lock: `using g = m.lock() { g.get().push(4) }`, or hand over `xs.clone()` to keep a separate copy (stdlib 2.13.9)
```

락을 거쳐 값을 쓰거나, 따로 복사본이 필요하면 `xs.clone()`을 넘깁니다.

```rok
let xs = [1, 2, 3];
let m = Mutex::new(xs);
using g = m.lock() { g.get().push(4) }
using g = m.lock() { println(f"{g.get().len()}") }
```

```output
4
```
