# E300: 속성 또는 메타 에러

속성, derive, 메타 블록, `#[lang]`, `#[literal]`, `#[keyword]`, 연산자 등록을 잘못 썼습니다. 흔한 경우는 내장 속성도 아니고 스코프 안의 메타 블록이 정의하지도 않은 속성 이름입니다 ([6.1.6 알려지지 않은 속성](../spec/refs-lang/006-meta-system/601-attribute-syntax.html#616-알려지지-않은-속성)).

```rok norun
#[inlin]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```text check=checks/E300.rok
error[E300]: unknown attribute `#[inlin]`: not built in and no meta block defines it (spec 6.1.6)
  --> main.rok:1:1
   |
 1 | #[inlin]
   | ^^
```

[6.2 내장 속성](../spec/refs-lang/006-meta-system/602-built-in-attributes.html)에 있는 철자로 씁니다.

```rok
#[inline]
fn twice(x: i32) -> i32 { x * 2 }
println(f"{twice(2)}");
```

```output
4
```

derive할 수 없는 트레잇을 derive하는 것도 E300입니다. ``cannot derive `Frobnicate` for `P`: `Frobnicate` is not a derivable trait`` 메시지는 derive할 수 있는 트레잇을 나열합니다 ([6.2.1](../spec/refs-lang/006-meta-system/602-built-in-attributes.html)).
