# E503: 린트

컴파일은 되지만 실수일 가능성이 큰 코드를 린트가 찾았습니다. 쓰지 않는 변수, 죽은 코드, 헷갈리는 식별자 같은 것입니다. 린트는 기본으로 경고입니다. `rok.rokon`이나 명령줄의 `-D`, 소스의 `#[deny(..)]`에서 `deny`로 정하면 에러가 됩니다. 마지막 note는 린트 이름과 그 수준을 정한 곳을 알려 줍니다([6.2.9](../spec/refs-lang/006-meta-system/602-built-in-attributes.html#629-allow--deny--warn-린트-제어)).

```rok norun
fn main() {
    let total = 10;
    let unused = 1;
    println(f"{total}");
}
```

```text check=checks/E503.rok
warning[E503]: unused variable `unused`
  --> main.rok:3:9
   |
 3 |     let unused = 1;
   |         ^^^^^^
   |
   = note: if this is intentional, prefix it with an underscore: `_unused`
   = note: `#[warn(unused_variables)]` on by default
```

변수를 지우거나, 일부러 둔 것이면 이름 앞에 `_`를 붙이세요.

```rok
fn main() {
    let total = 10;
    let _unused = 1;
    println(f"{total}");
}
```

```output
10
```

`rokc lint --list`는 모든 린트를 기본 수준, 추가된 릴리스와 함께 출력하고, 이어서 그룹을 보여 줍니다. Rok 0.1.5까지의 린트에서 빌드를 실패시키려면 `warnings` 그룹을, 모든 린트에서 실패시키려면 `all`을 deny하세요. 수준을 정하는 방법은 [16장](../learn/16-tools.html#rok-lint와-rok-check)에 있습니다.
