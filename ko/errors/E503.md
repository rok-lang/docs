# E503: 린트

컴파일은 되지만 실수일 가능성이 큰 것을 린트가 찾았습니다. 쓰지 않는 변수, 죽은 코드, 헷갈리는 식별자 같은 것입니다. 린트는 기본으로 경고이고, `deny`로 에러가 됩니다 (`rok.rokon`에서, 명령줄의 `-D`로, 소스의 `#[deny(..)]`로). 마지막 note는 린트 이름과 그 수준을 정한 곳을 알려 줍니다 ([6.2.9](../spec/refs-lang/006-meta-system/602-built-in-attributes.html#629-allow--deny--warn-린트-제어)).

```rok norun
fn main() {
    let total = 10;
    let unused = 1;
    println(f"{total}");
}
```

```text check=checks/E503.rok
warning[E503]: unused variable `unused`
  --> main.rok:3:5
   |
 3 |     let unused = 1;
   |     ^^^
   |
   = note: if this is intentional, prefix it with an underscore: `_unused`
   = note: `#[warn(unused_variables)]` on by default
```

변수를 지우거나, 일부러 둔 것이면 앞에 `_`를 붙입니다.

```rok
fn main() {
    let total = 10;
    let _unused = 1;
    println(f"{total}");
}
```

```output
10
```

`rokc lint --list`는 모든 린트와 그 그룹, 기본 수준을 출력합니다. 수준을 정하는 방법은 [16장](../learn/16-tools.html#rok-lint와-rok-check)을 보십시오.
