# 에러 코드

rokc의 모든 진단은 `error[E0040]: mismatched types: ...`처럼 코드로 시작합니다. 코드는 에러 종류마다 하나이므로 한 코드가 여러 메시지를 덮습니다. 무엇이 잘못되었는지, 대개는 대신 무엇을 써야 하는지도 메시지가 직접 알려 줍니다. `rokc --explain E0040`(또는 `rok --explain E0040`)은 코드의 뜻을 짧게 출력합니다. 여기 페이지는 같은 내용에 예제를 더해 보여 줍니다. `--message-format=json`에서는 코드가 `code` 필드에, 영역이 `kind` 필드에 들어갑니다([9.9.4 진단](../spec/refs-lang/009-tools/909-debug-tools.html#994-진단--에러-메시지)).

코드는 추가된 순서대로 E0001부터 번호가 붙고, 한 번 쓴 번호는 다시 쓰지 않습니다. 이 목록은 rokc 0.2.0 기준입니다. 대부분의 페이지에는 문서를 빌드할 때 실제 컴파일러 출력과 대조하는 예와 그 고침이 있습니다.
