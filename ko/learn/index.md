# Rok 배우기

Rok을 처음 접하는 사람을 위한 가이드입니다. 설치부터 에러 처리, 동시성, FFI, ROKON, 도구, stone, 암호, 쿡북까지 다룹니다. 각 장은 짧은 설명과 바로 실행할 수 있는 코드로 이루어집니다.

이 가이드의 모든 코드 블록은 사이트를 빌드할 때 실제 toolchain 으로 컴파일하고 실행하며, 그 출력이 페이지에 보이는 출력과 같은지 검사합니다. 아무 블록이나 복사해 `rok run file.rok` 로 실행해 보세요.

전체 규칙은 [언어 레퍼런스](../spec/refs-lang/index.html) 와 [표준 라이브러리 명세](../spec/refs-standard-libraries/index.html) 에 정의되어 있고, 함수와 타입은 [표준 라이브러리 API](../../std/index.html) 에 정리되어 있습니다. 작고 완전한 프로그램은 [예제](../examples/index.html) 에 모아 두었습니다. 파일 읽기, 시간 재기, 스레드, JSON, HTTP 같은 일상적인 작업의 빠른 답은 [어떻게 하나요](20-cookbook.html) 를 보세요.
