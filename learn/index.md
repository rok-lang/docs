# Learn Rok

A guide for newcomers to Rok, from installation through error handling, concurrency, FFI, ROKON, tools, stones, cryptography, a cookbook, and arrays and numerics. Each chapter has a short explanation and code you can run right away.

Every code block in this guide is compiled and run with the real toolchain when the site is built, and its output is checked against the one shown. Copy any of them and run it with `rok run file.rok`.

Coming from Python? [Rok for Pythonistas](rok-for-python.html) maps Python idioms and standard library modules to Rok.

Coming from Rust? [Rok for Rustaceans](rok-for-rust.html) shows what to unlearn about ownership, errors and `Option`, and where Cargo's commands live.

The complete rules are defined in the [language reference](../spec/refs-lang/index.html) and the [standard library specification](../spec/refs-standard-libraries/index.html); functions and types are listed in the [standard library API](../std/index.html). Small complete programs are collected in [Examples](../examples/index.html). For quick answers to everyday tasks (reading a file, timing, threads, JSON, HTTP), see [How Do I...](20-cookbook.html). When the compiler stops you, look its code up in the [error code index](../errors/index.html).
